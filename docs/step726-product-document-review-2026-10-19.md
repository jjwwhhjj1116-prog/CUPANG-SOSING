2026-10-19. 기준 커밋 `524335a2e89720449dfb76dcbc5bba0de054fa21`.

원본 정적 대조에서 확인한 상품/분할 그룹당 전체 `jsonDocument` 배열과 문서 하나의 관계에 맞춰, 준비된 모든 포함 옵션을 묶는 읽기 전용 구성기와 실제 검토 화면을 추가했다. 기존 상품·회사 설정·원문·이미지는 변경하지 않았다. 이 변경은 실제 Supplier Hub 등록 완료를 뜻하지 않는다.

`app/supplier-hub-product-document.ts`는 현재 견적 입력의 포함 옵션 ID·이름·순서와 준비된 본문의 문서 배열을 정확히 연결한다. 상품명·모델명·가격·수동 공란·0·false·안전한 미지의 양식 값은 그대로 보존한다. 전체 원본문 SHA와 모든 문서의 알려진 동의 필드만 보류한 별도 SHA, 회원·회사·선택 카테고리·소스 버전·포함 옵션 목록을 묶는 검토 SHA를 계산한다. 결과는 불변 객체이며 전송 packet이나 접수 기록이 아니다.

읽기 함수는 현재 회사 조회 → 저장 자료 조회 → 구성 → 저장 자료 재조회 → 회사 재조회 순으로 GET만 실행한다. 전후 회원·회사와 전체 저장 자료가 같아야 결과를 채택한다. 쿼리가 없는 수집 당시 카테고리는 그대로 유지한다. 화면도 명시적인 ‘포함 옵션 전체 문서 확인’에서만 시작하고, 취소·화면 이동·입력 변경·이전 응답·이전 닫기 동작이 새 결과를 덮어쓰지 못하도록 한다.

실제 React·로컬 API·SQLite·이미지 저장소로 포함 2개와 제외 1개인 합성 상품을 확인했다. 옵션별 다른 상품명·모델명·공급가·판매가·권장소비자가와 수동 공란을 그대로 구성했다. 전체 본문 SHA가 일치하고 전후 DB·이미지 저장값이 같았다. 브라우저 API 쓰기 0회, 확장 호출 0회, 외부 요청 0회, 실제 Hub 쓰기 0회다. 처음 실행은 최종 동결 전 검사였고, 최종 동결 뒤 다시 실행한 결과를 별도로 보관했다.
