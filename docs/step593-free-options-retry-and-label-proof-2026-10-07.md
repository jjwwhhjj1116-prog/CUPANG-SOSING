# Step 593 — 무료 옵션 번역 재시도와 표시사항 신선도

## 사용자 흐름

기존 자동 초안은 무료 Google 번역의 429 실패/부분 결과를 재사용하고 종료해, 자동 재개만으로 빈 옵션을 다시 작성할 수 없었습니다. 기존 번역·SEO 화면에 **미번역 옵션 다시 작성** 동작을 추가했습니다. 사용자가 누른 경우에만 현재 수집 원문과 미번역 포함 옵션을 다시 준비하고 무료 GTX 요청을 실행합니다.

- 새 요청의 고정 UUID를 저장하고 준비·실행·적용 응답이 유실되면 같은 작업을 조회합니다. 불확실한 실행이나 저장을 자동으로 다시 호출하지 않습니다.
- Google에는 선택한 옵션값만 보냅니다. 상품명·설명·키워드를 다시 번역하지 않으며, 서버 적용 범위도 `options`로 제한합니다.
- 수동값·수동 공란·제외 옵션·SEO·표시사항·가격·이미지를 유지합니다. 삭제, 옵션 수정 버전, 원문 변경, 다른 실행 중/불확실 작업과의 경합은 중단합니다.
- 한 번에 무료 번역 한 묶음만 처리합니다. 부분 실패를 완료로 표시하거나 다음 묶음을 자동으로 재요청하지 않습니다. 새 옵션 작업은 기존 SEO 상태와 증빙으로 사용하지 않습니다.

## 표시사항 PNG

새 9행 표시사항 PNG 업로드에는 서버에서 현재 저장된 생성 계획과 대조한 인쇄 계획 증빙을 기록합니다. 저장된 상품명·재질·제조원 등 실제 인쇄 문구가 바뀌면 이전 PNG를 그대로 보내지 않도록 최신 검토·공식 XLSX·패키지 준비에서 불일치를 표시합니다.

이 증빙은 인쇄 계획의 신선도 검사이며 PNG 픽셀의 OCR·실상품 증명은 아닙니다. 기존 불투명 증빙·수동 업로드·다른 종류의 라벨을 9행 자동 라벨로 추정하지 않습니다. 파일과 참조를 자동 삭제하지 않으며, 새 PNG 생성 후 최종 견적에서 오래된 생성 라벨을 명시적으로 제외해야 합니다. 가격·일반 상품 시계·인쇄하지 않는 옵션명만 바뀌면 불일치로 판정하지 않습니다.

## Chrome 확장

0.2.56은 설치된 manifest 버전과 검증 중 결과 복구·SKU 관측 저장 기능을 PING에 응답합니다. 기존 연동 설정을 열면 실제 응답 버전을 확인하며, ZIP 파일명의 버전을 설치 증거로 사용하지 않습니다. 신규 직접 전송은 결과 조회 기능을 업로드 전에 확인합니다. 기존 보관 결과 조회와 첨부 후 검증 재개는 유지합니다.

권한·허용 호스트·유료 서비스·DB 마이그레이션은 추가하지 않습니다. 이전 0.2.55 배포 ZIP은 유지합니다.
