직전 실제 브라우저 검수에서 무료 편집 저장은 POST 200으로 성공했지만, 부모의 정상 상품 갱신이 완료 안내를 ‘상품 저장본이 변경됐습니다’로 덮는 문제를 확인했다. API가 이미 검증한 저장·복구 응답과 정확히 같은 다음 버전·파일·편집 범위에만 완료 안내를 한 번 유지하도록 수정했다. 견적 값이나 전송 계약의 변경은 없다.

## 수정과 보호 범위

- 검증된 `FreeImageApplyReply`의 상품 버전·결과 키와 당시 편집 범위 token·epoch를 사용한다. API의 원본·파일·저장 응답 검증을 새로 만들거나 생략하지 않는다.

- 다른 버전·결과 파일 누락·계정/상품 또는 활성 단계·옵션/카테고리/원본 전환·ABA·새 요청·취소에서는 안내 연결을 폐기한다. 적용 응답이 불확실하면 기존 미리보기와 읽기 복구를 유지하며, 정확한 적용 완료 응답을 받은 뒤에만 성공 안내를 만든다. 상세 작업 사진의 별도 workspace 저장 계약은 이번 대상이 아니다.
