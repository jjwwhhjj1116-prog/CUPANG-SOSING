# 단일 옵션 라벨 연결의 저장 응답 유실·재시도 (2026-10-01)

일괄 라벨 작업의 부분 실패 복구(529)는 단일 미리보기 연결에는 적용되지 않았다. 선택 옵션 PNG 업로드·상품 이미지 연결·견적 저장 중 응답이 유실되면 서버에 변경이 남아도 편집 화면이 이전 revision/fingerprint를 유지했다. 업로드 키가 자식 패널의 ref에만 있어 저장본 갱신·가격 수정으로 재마운트되면 재시도할 파일을 잃을 수도 있었다.

실제 부모/자식·업로드/API를 실행한 수정 전 6개 회귀에서 저장 실패 후 상위 미리보기 갱신 callback이 `0 !== 1`로 실패했다.

## 변경

- 단일 연결과 일괄 연결이 동일한 `onFailed` 복구 callback을 사용한다. 실패 후 이전 출력 미리보기를 무효화하고 실제 최신 견적을 다시 읽으며, 확인되지 않은 저장 건수나 완료를 추정하지 않는다.
- 최신 GET 실패 시 529의 입력/저장/재연결 잠금과 원래 오류 보존, 기존 '기본값 다시 반영'의 재조회·해제를 단일 연결에도 적용한다. 읽기가 끝날 때까지 공유 잠금을 유지한다. 재시도나 Hub 전달은 자동으로 실행하지 않는다.
- 마지막 단일 미리보기의 PNG Blob·크기·업로드 키를 부모 폼의 ref에 보존한다. 상품/endpoint/카테고리/선택 옵션 ID/실제 PNG 계획을 signature로 비교한다. 같은 계획으로 미리보기를 다시 열면 조판과 업로드를 반복하지 않는다.
- 저장본 revision/fingerprint 변경이나 가격처럼 PNG에 나오지 않는 값을 수정한 뒤에도 같은 계획은 재사용한다. 모델·법적 표시값·카테고리·옵션 등이 달라지면 새 미리보기와 파일을 만들며 기존 라벨은 임의 삭제하지 않는다. 옛 비동기 결과는 다른 계획의 캐시 키를 교체하지 못한다.
- 캐시는 폼 세션에서 마지막 단일 계획 한 개만 유지한다. 다른 계획을 생성하면 이전 캐시를 교체하며 전체 페이지 재접속의 영구 재개는 아니다. 파일 업로드 응답 자체가 유실되어 키를 모르는 경우의 복구나 단일/일괄 경로 간 모든 중복 판정을 완료한 것으로 해석하지 않는다.

## 검증

와이홉 A01464742, 유앤채 A01526306 각각 네 상황을 검사했다.

1. 옵션 라벨 PUT이 실제 저장된 뒤 응답 유실.
2. 상품 이미지 POST가 실제 저장된 뒤 응답 유실. 옵션 라벨 참조는 아직 미저장.
3. PNG 업로드는 성공했지만 상품 이미지 POST가 503으로 거절됨. 서버 견적 revision/fingerprint가 바뀌지 않았음을 확인함.
4. 옵션 라벨 PUT 응답 유실 후 최신 GET이 두 번 실패함. 원래 오류와 잠금 유지, 명시적 재조회 성공 후 해제를 확인함.

실제 QuotationFieldsEditor/QuotationLabelPanel, hook/effect 및 key 재마운트 모델, 실제 수집·콘텐츠·견적 입력·파일 업로드·상품 첨부·Excel·ZIP API와 임시 SQLite를 실행했다. 기록된 813724060928 원문에서 6옵션 초안을 만들고 위 오류를 주입했다. 오류 후 첫 옵션 가격 20,000원 수정 저장에 409가 없으며, 미리보기 재열기·연결은 PNG 조판/업로드 각 1회만 사용한다. 상품 첨부 거절 시험의 POST 재시도는 성공 업로드를 재사용한다.

이어서 모델명을 수정하면 조판/업로드 각 2회가 되어 옛 PNG를 새 계획으로 재사용하지 않는다. 첫 옵션의 기존 라벨과 두 검토 버전 PNG는 보존하고, 다른 다섯 옵션은 변경하지 않는다. 같은 마지막 계획으로 다시 연결해도 조판/업로드가 늘지 않는다. URL 재시도에 원문/AI 추가 요청이 없고 최종 6행 Excel 라벨 파일명/JSON 매핑, 검토 ZIP과 로컬 포착 전송 XLSX 및 3개 라벨 이미지의 바이트, 회사와 옵션 수가 일치한다.

80719는 관찰된 폼의 시험 계약이며 선글라스의 실제 판매 분류가 아니다. 인증/AI/PNG 조판/이미지 바이트/Excel 양식/최종 Hub 전달은 시험 자료다. 실계정에 쓰지 않았으며 시험 상품 상태는 미전송이다. 시험 helper는 단일 첨부에도 실제 요청 함수를 연결하고, 부모뿐 아니라 자식의 조판 중 상태도 기다리도록 했다.
