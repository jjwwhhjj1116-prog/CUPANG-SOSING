# 등록전송 직전 저장본 대조 — 2026-09-30

## 수정한 문제

앱이 견적서 ZIP을 받은 직후와 확장이 준비된 ZIP을 실제 첨부하는 사이에 최신 저장본을 검사하지 않았다. 사용자가 다른 화면에서 상품정보·옵션·견적서 또는 양식을 수정해도, 이미 준비한 파일을 전달할 수 있었다. 확장의 기존 15분 만료와 ZIP 내부 일관성 검사로는 이 변경을 확인할 수 없다.

## 적용 범위

- 앱의 `등록 전송`과 `확장에 첨부 파일 준비`는 ZIP 응답을 받은 뒤 기존 읽기 전용 `action:source` API로 저장 지문·상품·카테고리·양식·파일명을 다시 대조한다. 다르면 미리보기를 무효화하고 Chrome 전달 전에 중단한다.
- 업로드 목록에 실제 선택한 `profileId`를 포함한다. 앱에서 준비한 패키지는 신뢰한 런타임 발신자의 원래 앱 탭 ID와 Chrome 창 ID를 함께 보관한다.
- 확장 0.2.27은 원래 앱 탭의 최상위 콘텐츠 스크립트에만 저장본 확인을 요청한다. 해당 탭이 같은 창·허용 출처에 있는지 요청 전후 확인한다. 탭을 검색하거나 다른 Chrome 창/프로필을 선택하지 않는다.
- 콘텐츠 스크립트는 같은 출처의 기존 로그인 상태로 읽기 전용 API를 요청한다. 재출력·이미지 다운로드·쿠키/토큰 판독을 하지 않는다. 상품·카테고리·프로필·지문·파일명·회사코드/회사명과 확인 시각만 반환한다. ZIP 바이트와 API의 행/전체 보고서는 메시지에 복사하지 않는다. API 10초 제한, 리다이렉트 거부와 응답 출처 확인을 적용한다.
- 직접 등록전송은 사전 검사 전, 전송 기록 점유 직전, 업로드 완료 후 파일 검증 요청 직전에 확인한다. 사전 변경은 첨부하지 않으며, 업로드 중 변경은 자동 재첨부 없이 검증 요청을 중단한다. 기존 영구 전송 기록과 부분 전달 보호를 유지한다.
- 준비된 파일의 팝업 전달도 회사 확인 전후 저장본을 대조하고, 모두 통과한 뒤에만 준비 파일을 한 번 소비한다. 원래 앱 탭/창 정보가 없는 이전 패키지는 새로 준비해야 한다.

현재 소스 확인은 시점별 대조이며 앱 저장과 외부 업로드의 원자적 트랜잭션이나 잠금은 아니다. 팝업에서 직접 선택한 ZIP은 앱 상품에 연결되지 않는 기존 수동 경로로 유지한다. 이 수동 경로에 최신 앱 저장본 확인이 적용된다고 주장하지 않는다. 권한·호스트 허용 목록과 DB 스키마는 변경하지 않았다.

## 검증

- 관련 검사 68/68, 전체 회귀 검사 1,418/1,418, TypeScript와 운영 빌드·산출물 검사 통과. 변경 코드 lint 오류 0. 변경하지 않은 기존 `onBusy` 의존성 경고와 테스트의 미사용 변수 경고 각 1개를 확인했다.
- 실제 저장 API/SQLite, React 컴포넌트, ZIP 판독기, 확장 소스 확인과 콘텐츠 스크립트 API 요청을 연결했다. 와이홉 `A01464742`와 유앤채 `A01526306` 각각 6개 옵션·실제 출력 XLSX·상품 이미지 3개·라벨 1개·필수 선택값이 연결된다. 확인 안내가 남아도 오류 0이면 전달 버튼이 활성화되며, 필수 포장 무게를 지우면 두 전달 버튼이 비활성화된다. 모의 최종 전달을 실행해도 DB의 `미전송` 상태는 유지한다.
- ZIP 반환 중 수정, 준비 후 수정, 업로드 중 수정, 앱 탭 종료/창 이동, 회사/프로필/카테고리/파일명 변경, 오래된 응답, 다른 확장 발신자, API 인증 실패/잘못된 출처/시간 초과를 검사했다.
- 통합 시험은 기록된 1688 공개 원문과 합성 인증·AI·이미지·라벨·Excel 양식을 사용한다. 원문의 선글라스에 80719를 연결한 것은 양식 계약 시험이며 실제 판매 카테고리가 아니다. 최종 Hub 전송은 테스트에서 캡처만 하며 실계정 견적서를 생성하지 않는다.
- 확장 ZIP 0.2.27의 27개 파일 각각이 소스와 SHA-256으로 일치하고, 운영 빌드의 ZIP도 동일하다. ZIP SHA-256: `20E29A1CCCB03B777615DE38C38CC9208EBBE3AE46A068387BB9AEF2720B0E53`.

전체 카테고리의 Couplus 자동 기본값/공식 양식 일치, 운영 실 AI·이미지 번역·공개 상세 HTML·필수 법적 서류 첨부와 실제 Supplier Hub 최종 접수 검증은 남아 있다. 입력 검사나 파일 전달 테스트 통과는 실계정 등록 완료의 근거가 아니다.
