# Step677 — 상세 일괄 번역의 설정 배너 보호

기준 커밋은 b485625311b1b1afb06cae025bda779732b96a22다. Step676에 보관한 쿠플러스 정적 증거 ev_8ec3fd01351174fefebdc0fccae8f936ebf1c20201f4c59c76aff551e848ec3c를 재사용했다. 원본의 상세 영어 번역과 AI 일괄 처리는 상단·하단 설정 이미지를 제외한다. 원본 실행과 기존 작업 상품 수정은 하지 않았다.

## 구현

- 종전에는 최종 상세 목록 전체를 인식·번역해 설정 배너도 처리 대상이 됐다. 이제 기존 조회 응답의 protectedDetailImageKeys로 역할을 확인한다. 첫·마지막 위치, 파일명, 수동 입력 여부로 배너를 추측하지 않는다.
- detailBatchTranslationSlots는 전체 목록과 원래 슬롯을 보존하고 처리할 위치만 분리한다. 배너는 skipped 상태로 표시하며 원본 읽기·OCR·번역·렌더 의존성을 호출하지 않는다. 화면에는 배너와 원본 유지 안내를 표시하고 검토 체크박스는 표시하지 않는다.
- 역할 증거가 없거나 손상되면 상세 일괄 준비를 중단하고 최신 목록 조회를 안내한다. 명시적인 빈 배열이면 배너가 없는 본문이다. 추가 이미지 단계는 기존처럼 명시 선택한 전체 항목을 처리한다.
- 상세의 ‘영어→한국어 번역’과 ‘모든 이미지 AI 처리’는 각각 en/zh를 직접 전달한다. React 언어 상태의 비동기 갱신에 의존하지 않는다. 본문/배너 개수를 나누어 표시하며 진행률은 처리 순번, 저장은 원래 슬롯으로 연결한다.
- 캐시된 배너 결과를 새로 적용하지 않는다. 이전 저장의 응답 유실은 읽기로 확인할 수 있다. 이미 저장됐다면 해당 결과를 확인하고, 미저장 보호 항목이면 재시도 자료를 지운 뒤 skipped로 바꾼다. 충돌은 미확정 상태를 보존하며 중복 업로드하지 않는다.
- 독립 검수에서 과거 준비 작업의 후속 호출과 오래된 검토 체크 문제를 발견해 수정했다. 준비 전용 요청만 세대/소스/잠금 변경 시 취소하며, 체크는 현재 batch·item·rendered·준비 세대와 일치해야 한다. 진행 중인 적용·복구 쓰기를 임의 중단하지 않는다.

DB 테이블, 확장 버전, 외부 API 설정, 유료 자원 변경은 없다. 수동 HTML·미선택 결과·다른 옵션·원본 파일은 보존한다. 원본 requestId에 대응하는 완전한 기처리 AI 증거는 아직 없으므로 파일명이나 필드 출처로 건너뛰지 않는다. 원본처럼 모든 옵션의 견적 HTML을 지우는 저장 방식은 같은 트랜잭션의 수동 HTML 백업·검토가 먼저 필요해 이번에 기존 값을 덮어쓰지 않았다.

## 검증

서로 다른 4개 파일의 56개 검사 통과: 기존 핵심 20 + 신규 배너 핵심 12 + 기존 화면 10 + 신규 화면 14. 초기 추적 인자 위치와 검사 PNG 오류는 장치만 수정했다. 재실행 결과를 중복 합산하지 않는다. 타입, 수정 코드/검사 린트, Worker 빌드와 공백 검사도 통과했다. 로그와 집계는 ignored outputs/step677-*.log 및 step677-detail-banner-checks.json에 보관했다.

같은 Chrome3에서 실제 React·비공개 원본 API·Canvas·임시 SQLite로 두 회사를 검수했다. 와이홉은 영어, 유앤채는 중국어를 사용했다. 원래 슬롯 1만 고정 OCR 영역·번역 응답으로 처리하고 슬롯 0/2의 배너 4개는 유지했다. 준비에서는 저장하지 않고 검토 뒤 회사별 1회만 명시 적용했다. 실제 PNG 320×100에 검은 글자·흰 배경이 생성됐으며 편집 영역 밖 픽셀은 원래 색과 일치했다. 수동 HTML, 다른 옵션·필드, 원본 파일 바이트와 출처 자료는 불변이다.

최종 API 34회 중 번역 POST 2회와 multipart 적용 POST 2회다. 최초 검수 집계가 multipart를 JSON action으로 읽어 0회로 판정한 문제는 집계만 고쳤으며 적용을 재전송하지 않았다. 임시 서버의 URL과 브라우저 Origin 불일치는 실제 동일 사이트 검사를 통과하지 못했으므로 서버의 요청 URL을 유지하도록 어댑터만 수정했다. 애플리케이션 검사를 완화하지 않았다. 초기 서버 구문/CSS 조건 오류도 최종 검수 전에 수정했다.

근거는 outputs/step677-native-verification.json, step677-native-dom-proof.json, 최종 DOM과 실제 생성 PNG 2개다. OCR 줄과 Google 응답은 로컬 고정 입력이므로 실제 OCR 정확도·외부 번역·1688 수집 성공의 증거가 아니다. 원생 화면 캡처 두 상태는 timeout으로 실패했으며 성공 PNG로 보고하지 않는다.
