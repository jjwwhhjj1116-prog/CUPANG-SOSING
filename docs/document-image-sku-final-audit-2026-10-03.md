## 재현한 문제와 수정

- 6단계 표시사항·사이즈표 PNG의 상품 첨부는 저장됐지만 응답 또는 JSON 본문이 유실되면, 같은 PNG를 재시도할 때 이전 저장 버전으로 충돌했다. 이제 이미 업로드한 정확한 키가 해당 상품의 원본 목록과 해당 이미지 역할에 연결됐는지 읽어 복구한다. PNG 생성 계획·콘텐츠 revision·사이즈표 옵션 revision·상품 저장 버전을 대조하며, 변경된 자료는 재첨부하거나 완료로 표시하지 않는다. 닫힌 편집기와 더 최신 화면에 늦게 도착한 응답도 적용하지 않는다.
- Supplier Hub 견적서 ID 검색이 결과 표 자체를 교체하면 새 표를 인식하지 못해 SKU 조회가 끝나지 않았다. 반대로 결과와 무관한 표를 포함한 영역이 추가되면 이전 SKU 행을 새 결과로 오인했다. 현재 정확한 결과 헤더를 가진 표 자체 또는 그 표를 포함하는 영역의 변경만 조회 갱신 근거로 사용한다. 정확한 회사·창·견적서 ID·검색 조건과 조회 기록 검사를 유지한다.
