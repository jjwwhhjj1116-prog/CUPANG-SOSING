# 64497 Supplier Hub 대조

## 확인
- Chrome의 로그인된 Supplier Hub 개별상품등록에서 카테고리 구조로 선택: 생활용품 → 욕실용품 → 욕실수납/정리 → 양치용품 정리 (64497). 쿠플러스의 띄어쓰기 없는 표시와 동일 코드임을 직접 확인했다. 기존 저장 경로와 표시명은 유지한다.
- 상품정보: 노출 속성 색상/수량 필수, 공급가/판매가 필수, 판매가는 공급가 이상. 옵션 최대 100개. 검색태그는 별표 없는 선택 항목.
- 바코드 도움말: 6~14자, 영문 대문자/숫자/하이픈/공백, 앞뒤/연속 공백 불가. 바코드가 없으면 쿠팡 바코드 선택.
- 쿠플러스에서 관찰한 비노출 속성 33개와 일치. 22개 선택형 항목의 option label/value를 DOM에서 대조했다. ‘해당사항없음’은 value=""이며 ‘해당없음’이라는 별도 실질 선택지는 문자열 값 그대로 유지한다.
- 미리보기 상품고시 5개 이름이 쿠플러스와 일치한다. 인증/허가의 실제 필수조건은 법적정보 입력 화면에서 추가 대조해야 한다.
- fill/type 후 사라지던 상품명은 textbox.press('A') 및 Tab으로 입력 상태를 유지했고 다음 단계 진입에 성공했다. ‘다음’ 후 마지막 저장 시각이 표시됐다. 저장하기/최종 등록은 누르지 않았으나 임시저장 가능성이 있다. 해당 A는 관찰용 입력이며 실제 상품 등록이 아니다.

## 구현
- 64497에 필수 속성/가격, 가격 역전 검사, 옵션 한도와 바코드 검사를 연결한다. 해당사항없음 선택은 공식 빈 값으로 저장/출력한다.
- 기존 수동값을 DB에서 마이그레이션하거나 덮어쓰지 않는다. 이전 리터럴 ‘해당사항없음’ 저장값은 새 선택지 검사에서 재검토 대상이 될 수 있다. 직접 선택한 빈 값은 manual 출처를 보존한다.
- 코드 증거는 Supplier Hub로 갱신하되 전체 양식 접수 완료를 뜻하지 않는다. submissionReady=false 유지.

## 추정 / 미확인
- 쿠플러스가 이 카테고리의 옵션/검색 속성을 Hub 메타데이터에 맞춰 구성한 것으로 추정된다. 내부 호출 방식은 미확인.
- Hub 상품정보 기본 라디오는 제조사/과세/수입대상아님이었다. 쿠플러스 저장 상품의 수입상품 등 값과 구분하며 이를 신규 상품의 자동 사실로 복제하지 않는다.
- 공식 Excel, 이미지/법적정보/물류 입력, 자동 기본값 생성 출처, 최종 접수, 실제1688 수집/AI 번역/전송 adapter는 미완료.
