# 1688 상품조회 연결 설정

## 현재 상태

URL 등록의 `POST /api/collection-jobs/[id]/collect`에 공식 API 수집 경로를 연결했다.
운영에는 아직 자체 API 키와 조회 권한이 없으므로 이 경로는 활성화하지 않았다.
테스트는 합성 응답이다. 실제 1688 응답, 모든 가격 유형, 모든 상품 지원을 검증한 것은 아니다.

서버 설정이 활성화되면 기존 수집 요청의 원본 URL로 서명된 조회를 실행하고,
상품번호·옵션·가격·이미지를 검증한 원문을 저장한다. 기존 클라이언트가 이 원문을
상품 초안 및 이미지로 반영한다. 이 요청은 Supplier Hub 전송을 실행하지 않는다.

## 필요한 서버 바인딩

| 이름 | 내용 |
| --- | --- |
| `ALIBABA_PRODUCT_API_ENABLED` | 문자열 `true`만 활성화. 미설정/빈 문자열/`false`는 기존 공개 페이지 수집 |
| `ALIBABA_APP_KEY` | 이 배포 소유자의 앱 키 |
| `ALIBABA_APP_SECRET` | 해당 앱 비밀키 |
| `ALIBABA_ACCESS_TOKEN` | 상품상세 API 조회 권한이 있는 토큰 |

비밀키와 토큰은 Cloudflare Worker Secrets로 설정한다. 공개 vars, Git,
클라이언트 환경변수, 채팅, 상품 데이터에 넣지 않는다. 발급된 값은 보안 입력으로
등록하며 본 문서에는 값을 기록하지 않는다. 활성화 스위치도 Worker Secret로
설정하면 현재 빌드의 vars를 수정하지 않고 사용할 수 있다.

예: `npx wrangler secret put ALIBABA_APP_SECRET --config dist/server/wrangler.json`

자체 권한을 발급받고 테스트용 환경에서 실제 응답을 검증한 뒤 활성화한다.
쿠플러스 설치 코드에 포함된 다른 주체의 키는 사용할 수 없다.

## 실패 처리와 남은 검증

- 활성화했으나 설정이 불완전하면 503이며 외부 요청이나 원문 저장을 하지 않는다.
- 조회·응답 변환 실패는 422다. 공개 페이지 수집으로 자동 전환하지 않는다.
- 원문이 있으면 기존 값을 반환한다. 재시도가 원문·수동 편집을 교체하지 않는다.
- 현재 변환기는 명시적 SKU `price`와 `minOrderQuantity`를 요구한다. 가격 구간,
  프로모션·대행 가격 해석과 단일 옵션 없는 응답은 추가 검증이 필요하다.
- 대표/추가/상세 이미지 배치는 보존하지만 이미지 번역은 실행하지 않는다.
- 토큰 발급·갱신 자동화와 Supplier Hub 제출 어댑터는 아직 구현되지 않았다.

## 수집 후 SEO 준비 (334)

상품과 이미지 반영이 끝나면 저장된 원문·카테고리·특징·키워드·미번역 옵션으로
`translation`의 `prepare-collected` 요청을 보낸다. 번역 서버 설정이 있어야 준비된다.
이 단계는 AI 호출 없이 검토 요청만 저장한다. 실제 실행은 SEO 화면에서 한다.
동일 버전의 같은 원문은 기존 요청을 재사용하며, 수동 수정 후 버전이 바뀌면 새 검토가 필요하다.
SEO 준비 실패는 이미 저장된 상품을 삭제하거나 수집을 다시 실행하지 않는다.
