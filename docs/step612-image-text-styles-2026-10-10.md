# Step612 이미지 문구 스타일 편집

## 쿠플러스 편집 동작 대조

Step611에서 읽기 전용으로 기록한 쿠플러스 이미지 편집창에는 글꼴, 굵게, 기울임, 왼쪽·가운데·오른쪽 정렬과 행간이 있었다. YOOFAM PLUS는 글자색·크기·위치만 수정할 수 있어 이 부분을 보완했다. 실제 운영 상품의 문구·이미지·저장 상태는 수정하지 않는다.

각 문구 영역에 글꼴 선택, 굵게·기울임, 정렬, 행간 0.8~3을 추가한다. 변경하면 이전 미리보기를 폐기하고 다시 검토한 PNG만 적용할 수 있다. 지우기 모드에서는 스타일을 비활성화하고 값을 유지하므로 모드를 끄면 다시 사용할 수 있다. 저장 응답이 불확실하거나 재시도를 준비한 상태, 작업 중·닫힌 편집기·다른 옵션이나 견적 슬롯의 오래된 콜백은 기존 보호를 유지한다.

## 실제 글꼴과 렌더링

기존 스타일 없는 초안은 같은 고딕 font 문자열·일반 굵기·왼쪽 정렬·행간 1.2를 사용한다. 고딕·명조·고정폭은 고정된 로컬 font stack만 허용하며 임의 CSS를 받지 않는다. 모든 선택 영역을 먼저 검사한 뒤 글꼴 로딩과 렌더링을 시작한다.

쿠플러스 참조 화면의 Gmarket Sans Medium도 선택할 수 있다. [G마켓 공식 글꼴 배포 페이지](https://corp.gmarket.com/fonts/)의 TTF ZIP에서 원본 Medium·Bold 파일을 그대로 보관한다. 원본 저작권·이용허락과 배포 URL·SHA256은 같은 폴더에 포함한다. 운영 브라우저는 자체 앱의 정적 파일을 사용하며 외부 글꼴 서비스·API 키·유료 작업은 추가하지 않는다.

Gmarket 선택 시 FontFaceSet.load의 실제 face 반환과 check를 확인한 뒤 측정·렌더링한다. 로딩 실패·10초 초과·취소는 원본과 입력을 보존하며 다른 글꼴로 대신 저장하지 않는다. timer·abort listener를 정리하고 늦은 결과를 무시한다. 정상 문구 영역만 글꼴을 로드하고 지우기 영역은 제외한다.

굵기와 기울임을 적용한 font로 줄바꿈·자동 축소를 계산한다. 정렬 기준점과 모든 문구는 지정 사각형의 clip 안에 그린다. 행간이 1보다 작아도 마지막 줄에 최소 1em 높이를 확보하며 기본 1.2의 기존 계산값은 바꾸지 않는다. 스타일은 PNG에 렌더링되고 저장된 원본·소유권·CAS·정확한 재시도·최종 옵션 및 견적 슬롯 연결은 기존 경로를 사용한다.

## 검수 범위

실제 Chrome에서 합성 원본으로 실제 애플리케이션 renderer를 실행했다. 기존 고딕, Gmarket Medium, Gmarket 굵게·기울임·가운데, Gmarket 굵게·오른쪽의 네 PNG를 만들었다. 실제 Gmarket face 로딩, 지정 영역 밖 픽셀 및 원본 보존 확인 결과를 기록했다. 실제 상품이나 원격 상품 URL을 사용하지 않는다.

회귀는 기본 출력 유지, 범위·타입 검사, 글꼴 로딩·취소, 자동 축소·정렬, 공란·지우기 보존, 미리보기 무효화, 저장 실패·응답 유실 복구, 옵션·견적 대상 보호와 실제 PNG/API/SQLite/R2 연결을 포함한다. 새로운 Supplier Hub 접수, 모든 카테고리 동일성, 자유 브러시·드래그·레이어·undo/redo 및 공유 원본의 생성 결과 역할 적용은 이번 완료 범위가 아니다.

검사 결과: 편집·원본 보존 129개, 견적·옵션·파일 전송 준비 118개로 **247/247 통과**. 실패·취소·건너뛰기 0개, TypeScript·ESLint 오류 0개(기존 경고 8개), 운영 빌드 및 실제 정적 글꼴 바이트 검사 통과. 17개 마이그레이션과 기존 확장 0.2.57/0.2.58은 그대로 유지한다.

운영 Worker `01c66e5b-de28-4542-9322-2db64445bb81` 배포 후 기존 Chrome에서 새 `dashboard-client-DPZjCcwW.js`와 글꼴 등록 CSS `index.CIj8US6f.css`가 로드됐다. 기존 사용자 탭·배포 확인 탭의 입력·상품 행과 쿠플러스 등록 표를 보존했다. 합성 로컬 검수 서버는 검수 후 종료하고 원래 앱으로 복귀했다.
