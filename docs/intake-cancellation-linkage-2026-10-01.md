# 취소된 URL 수집의 늦은 응답과 초안 복구

2026-10-01, 545단계.

상품 추가 창을 닫아 요청을 취소한 뒤 새 카테고리·URL을 입력하면, 이전 수집의 늦은 진행 메시지와 상품 ID가 새 행에 반영될 수 있었다. 서버에 상품 또는 이미지 저장이 완료된 직후 취소하는 경우도 포함해 기존 코드에서 여섯 회귀 검사의 실패를 확인했다.

대기열·수집 함수·화면 콜백에서 취소 여부를 검사하고, 화면은 현재 실행의 컨트롤러도 대조한다. 종료된 실행은 행 상태·작업 목록·상품 ID·편집 화면 이동을 갱신하지 않는다. 상품 저장 응답이 늦게 도착하면 SEO 요청도 새로 시작하지 않는다.

이미 서버에 저장된 원문·상품·이미지를 삭제하거나 취소 완료로 가장하지 않는다. 같은 요청을 재시도하면 보관된 수집 결과와 상품 ID로 이어서 처리한다. 상품 중복 생성, 완료 상태 오표시, 다른 카테고리·URL의 덮어쓰기를 방지한다. 수집은 편집 가능한 초안 작성이며 Supplier Hub 전송을 실행하지 않는다.
