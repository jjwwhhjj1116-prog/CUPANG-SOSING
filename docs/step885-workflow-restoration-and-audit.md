## 자동 작업과 전송

- 표시사항 API의 `PRODUCT_LABEL_DRAFT_RESPONSE`는 이미 받은 응답의 형식 거절이다. 이를 미확정으로 잘못 남겨 다음 견적 단계와 명시적 재시도까지 영구 차단하던 오류를 고쳤다. 이 코드 한 종류만 확정 실패로 분류하며 제공자 오류·시간초과·통신 유실은 계속 미확정이다. 실제 adapter→orchestration 검사에서 기존 입력·수동 공란 보존, 텍스트/PNG 저장 0, 견적 작업 1회, 자동 재호출 0을 확인했다. 관련 89개 검사·타입·린트 통과.
- 공식 SR Next는 비동기 저장→검증→이동이고 최종 Submit도 비동기 저장→검증이다. 단계 이동을 8초만 기다리거나 최종 클릭 직후 접수행을 한 번만 읽던 차이를 수정했다. 각 실제 Next 클릭은 1회, 각 단계의 독립적인 최대 30초 관찰을 사용한다. 최종 1회 클릭 뒤 정확한 문서 행이 아직 없는 경우만 최대 30초 GET 조회한다. HTTP·잘못된 형식·문서 불일치는 즉시 중단한다.
- 매 조회 전후 checkpoint·원본·회사·문서·취소 상태를 확인하고, 취소/만료 후 늦은 응답은 반영하지 않는다. 미이동을 반려나 저장 실패라고 단정하지 않는다. 원래 `currentReadRecovery`의 marker/load/click 이전 차단은 유지한다.
- 신규 네이티브 관찰 12개, 기존 관련 104개 통과. 별도 stale VM fixture 6개는 현재 실제 export 주입만 보완한 후 신규 12개와 함께 18/18 통과했다. 한 번에 110/110을 실행했다고 보고하지 않는다. 타입·린트·독립 검토 통과.
