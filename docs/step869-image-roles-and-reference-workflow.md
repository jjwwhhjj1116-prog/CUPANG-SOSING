# 이미지 처리 역할과 등록 흐름 보완

2026-10-30. 사용자 제공 RS 설명 영상의 자동자막과 수집 목록·옵션 편집·반려 결과 화면을 대조했다. 미공개 영상 주소와 전체 자막은 로컬 outputs에만 보관한다. Couplus의 기존 REA 관측 자료와 영상의 사용 설명, YOOFAM 실동작 결과는 서로 다른 근거로 취급한다.

## 반영한 변경

- 대표·추가 이미지 자동 작업은 상세 이미지 번역과 분리했다. 안전하게 확인된 단색 배경의 외국어 문구를 지우며, 한국어 식자를 추가하지 않는다. 복잡한 배경·겹침·불확실한 영역·제거하지 못한 외국어 영역이 있으면 완료로 처리하지 않는다. 원문과 편집 문서는 보존한다.
- 상세 이미지의 번역·부분 결과 처리와 기존 요청 UUID, 미확정 응답, 수동 편집 및 원본 변경 검사는 유지했다. 대표·추가 이미지도 기존 Vision 인식·번역 추론은 사용한다. 별도 번역과 한글 식자만 생략하며, 추론 비용이 없다는 뜻은 아니다.
- 이 제거 방식은 주변 픽셀을 이용한 단색 채움이다. 고급 인페인팅이나 상품 위 문구/제품 자체의 글자를 자동 구별하는 기능으로 보고하지 않는다.
- 삭제 확인을 브라우저 기본 확인창에서 앱 내부 창으로 바꿨다. 상품명·등록번호·전체 상품 ID를 표시하며 취소/Escape, 실행 중 중복 클릭, 선택·회원·원본 변경 검사를 적용했다. 기존 복원 가능한 삭제 API를 그대로 사용한다.
- 보관된 상품의 native-assets 요청은 파일을 읽기 전에 정확한 보관 상태 오류를 반환한다. 인증·소유자·원본 검사와 마지막 CAS 검사는 유지했다.
- 공식 견적서의 문자형 노출 수량에만 판매 단위 확인 안내를 추가했다. 숫자형이나 별도 단위 필드는 바꾸지 않고 값을 자동 보정하지 않는다.

## 영상 비교 결과

수집 후 한국어 상품명, 회원별 기본값, Hub 연결을 이용한 카테고리 추천, 옵션 가져오기, 이미지 선택·크롭·저장, 등록 뒤 결과 확인 흐름을 확인했다. 현재 기능과 대조했으며, 영상의 등록 시연은 뒤에 중복 노출속성 반려로 이어졌다. 이를 접수 성공 근거로 사용하지 않는다.

현재 원문 옵션 전체 반영 후 제외·삭제·복제는 가능하다. 가져오기 전에 원문 옵션 일부만 고르는 편의 기능은 별도 보완 대상이다. 영상의 환율·마진·배너 수치는 예시이며 기존 회원 설정을 덮어쓰지 않는다. 후반의 별도 상세페이지 제작 설명을 RS 내장 생성 기능으로 해석하지 않는다.

## 검증과 배포

- 이미지 처리·번역 회귀·배치·보관 원본 API의 고유 7개 테스트 파일 188/188 통과.
- 등록 보드·견적 편집기 고유 2개 파일 152/152 통과. 앞 7개와 중복되지 않아 총 340개다. 실제 서비스 성공률을 뜻하지 않는다.
- TypeScript, 변경 파일 ESLint, 분리 Cloudflare 빌드 통과. 최종 Worker `571b866e-f44b-4c74-9a92-7a840dbc81d5` 배포.
- 이번 변경에 확장 버전·권한·호스트·AI 모델·과금 설정 변경은 없다. 준비된 통합 확장은 2.1.61이며 마지막 Chrome 관측은 2.1.59다.
- 운영 UI에서 새 삭제창의 등록번호/전체 ID 표시, 삭제 후 목록 제외와 복원 목록 포함을 확인했다. 이미지 제거의 실제 성공 품질은 이번 배포에서 아직 확인하지 못했다.

## 원래 상품 복원과 접수 상태

원래 요청 `f29491bd-1882-456a-8a63-eec8586db6c6`, 상품 `e2f8037c-294e-45a8-b06d-58cc5909683c`, 문서 `2347603`을 유지한다. 정확한 등록번호는 **261024001001**이다.

복원 대조 과정에서 동명 상품 261029001001을 먼저 복원하는 오류가 있었다. 사용자에게 알렸으며 이 상품은 정상 UI를 통해 다시 보관했다. 보관 시각은 새로 기록됐으며 이전 시각을 복제하지 않았다. 승인된 원래 261024001001만 복원 상태로 남겼다. 두 상품의 내용 updated_at은 변경하지 않았다.

최종 원래 범위 D1 읽기 대조는 35개 테이블 47행이며 이전 48행과의 차이는 승인된 복원의 product_removals 한 테이블뿐이다. 나머지 상품·견적·옵션·회원 설정·파일 참조 hash는 일치했다. 이 비교는 R2 바이트나 Hub 서버 상태를 검증하는 것은 아니다.

원래 초안의 3옵션, 공급가 3420/판매가 6220/권장가 8090, 옵션별 대표1·추가4·표시사항1·상세2 연결과 현재 필수 미입력0/입력 오류0을 읽기로 확인했다. 포장 크기100×100×5mm와 10g에는 기존 추정 출처가 표시되며 실측으로 보고하지 않는다.

저장된 앱 접수 이력은 빈 배열이다. 현재 전체 문서 연결은 CHECKPOINT_MODE에서 중단되어 원래 요청 UUID/초안 모드의 정확한 연결을 추가로 확인해야 한다. 원래 문서의 실제 접수는 미완료다. 신규 문서 생성, 파일 저장, 본문 업데이트, 최종 제출을 이번 검수에서 실행하지 않았다. 기존 미확정 요청을 새 요청으로 바꾸거나 해시만으로 본문/실행 권한을 복원하지 않는다.
