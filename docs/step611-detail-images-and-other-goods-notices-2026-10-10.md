# Step611 상세 이미지 편집과 기타 재화 고시 연결

## 상세 단계 저장 범위

기존 자료에서 같은 파일이 대표 이미지와 상세 이미지에 함께 배치된 상태를 재현했다. 이전 상세 단계 저장은 이미 선택돼 있던 파일까지 새로 이동한 것으로 처리해, 설명이나 순서만 저장해도 대표 이미지 역할을 제거했다.

현재 단계의 각 역할에 새로 추가한 파일만 다른 역할에서 이동시킨다. 같은 역할의 순서 변경·상세 설명 저장·직접 공란 저장은 기존 공유 배치를 유지한다. 사용자가 대표에서 사이즈표로, 상세 본문에서 상단으로 역할을 직접 옮긴 경우는 명시적인 이동으로 처리한다. 다른 단계의 미저장 입력도 함께 저장하지 않는다.

서버는 동일 파일에 이미 저장돼 있던 역할 조합의 유지·축소만 허용한다. 새 파일의 공유 역할, 새로운 역할 조합, 같은 역할 내부 중복, 총 50개 초과, 상품 이미지 풀 밖의 파일 및 다른 회원 쓰기는 계속 거부한다. 기존 파일·저장소·이미지 풀은 삭제하거나 교체하지 않는다.

두 회사의 임시 SQLite/API에서 설명과 순서를 수정한 뒤 최종 견적 필드, 실제 XLSX 셀, ZIP 이미지 바이트까지 확인한다. 직접 입력한 옵션 HTML과 공란은 보존한다. 실제 편집 컴포넌트의 저장 요청에도 대표 이미지를 비우는 patch가 포함되지 않는 것을 검증한다.

## 기타 재화 고시의 정확한 원천 연결

기록된 64455 Single 양식의 `legalPage.notices`는 일부 고시를 `live_*` 필드로 유지한다. `인증/허가 사항`, `제조국(원산지)`, `소비자상담 관련 전화번호`는 기존 원천 연결에서 빠져, 6단계에 값을 저장해도 7단계·견적 출력에서는 양식 기본값으로 남았다.

정확한 세 고시명과 named notice wire가 모두 일치할 때 각각 저장 인증/허가, 원산지, 상담 연락처를 읽는다. 같은 제목의 다른 제어·속성·인증 배열, 비슷한 이름은 연결하지 않는다. 기존 정적·canonical 고시는 그대로 유지하고 실제 원산지나 인증 사실을 추정하지 않는다.

6단계 직접 공란, 견적서 공통 수정, 옵션별 수정의 우선순위를 유지한다. 두 회사의 실제 로컬 수집·저장 API에서 6개 옵션으로 연결하고 XLSX 셀을 대조한다. 수정으로 자동값 또는 그 원천 의미가 달라진 경우에만 새 원천 연결 지문을 넣어 이전 준비 파일의 재사용을 막는다. 원천이 없는 기존 기본값, 기존 canonical 고시, 직접 견적 수정은 지문을 유지하며 과거 접수 기록을 다시 쓰지 않는다.

## 문구 없는 지정 영역 지우기

같은 기존 Chrome의 쿠플러스 이미지 편집창을 읽기 전용으로 기록했다. 단색 직사각형 편집에 대응해 무료 이미지 편집에 명시적인 `영역 지우기 · 배경색만 적용` 선택을 추가한다. 기존 번역 공란은 계속 오류이며, 사용자가 지우기 모드를 켠 영역만 문구 없이 배경색으로 덮는다.

지우기 영역은 번역 요청에서 제외한다. 원문·번역 문구는 보존하고 모드를 끄면 다시 편집할 수 있다. 모드·좌표·색상 변경은 이전 미리보기를 무효화한다. 렌더링은 선택 사각형의 clip과 fillRect만 수행하며 다른 픽셀은 유지한다. 원본 지문·소유권·저장 버전·응답 유실 복구와 최종 견적서 연결은 기존 경로를 사용한다. 자연스러운 배경 복원이나 자유 브러시를 구현한 것으로 표시하지 않는다.

## 검수와 실제 자료 보호

오래된 테스트의 제한된 import/hook loader와 변경 불가능한 저장 양식 PUT 기대값, 견적 원본 template 지문 누락을 현재 계약에 맞게 보수했다. 실제 모듈·훅과 새 양식 분기를 사용하며 원본 자료 불변·수동값 보존 검증은 유지한다. 운영 코드의 보호를 테스트에 맞춰 낮추지 않는다.

실제 쿠플러스 자료는 화면만 읽고 저장 없이 닫았으며 등록 표가 이전과 같은 것을 확인했다. 운영 상품·기존 사용자 입력을 수정하지 않는다. 신규 실제 1688 수집 → 새 Supplier Hub 접수 완료와 모든 카테고리의 완전한 동일성은 이번 검수의 완료 범위가 아니다. 자유 브러시·드래그·풍부한 글자 스타일·레이어 편집 및 기존 공유 이미지의 생성 결과 역할 적용은 추가 검수 대상으로 남는다.

최종 검사: 이미지·저장 연결 217개, 고시·견적 편집 359개, 전송 파일 준비 159개, 무료 이미지 편집 62개로 **797/797 통과**. 실패·취소·건너뛰기 0개, TypeScript 오류 0개, ESLint 오류 0개(기존 경고 8개), 운영 빌드 검사 통과. 변경 전 실패 재현과 독립 코드 검토를 포함한다. 17개 마이그레이션과 확장 0.2.57/0.2.58 파일은 그대로 유지한다.

운영 Worker `03513653-626c-4c75-bd4d-f7d74b0b6e1a` 배포 후 기존 Chrome에서 새 `dashboard-client-gdFkkTS1.js` 로딩을 확인했다. 원래 사용자 탭의 입력·행과 배포 확인 탭의 입력·행은 이전과 같다. 다른 회사로 수집된 기존 자료는 현재 로그인 회사에서 열어 수정하지 못하는 기존 보호를 유지한다. 실제 자료의 지우기·저장·번역·전송은 실행하지 않았다.
