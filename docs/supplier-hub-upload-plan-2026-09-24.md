# Supplier Hub 첨부 영역별 준비 목록 — 2026-09-24

## 확인
Chrome 로그인된 https://supplier.coupang.com/qvt/registration 화면을 다시 읽었다. 견적 Excel, 상품 이미지, 제품 필수 표시사항(라벨/도안), 법적 필수서류가 별도 업로드 영역이다. 이미지 파일명과 견적서 파일명이 일치해야 한다. 가격 데이터 동의와 라벨 업무용 연락처/공개 동의는 별도 체크박스이며 미선택 상태다. 법적 서류 해당함이 초기 선택되어 있다. 파일 검증하기는 입력 전 비활성이다. 업로드/동의/검증/최종등록을 실행하지 않았다.

## 구현
최종 견적 resolver의 포함 옵션에서 mainImage/additionalImages/detailImages를 상품 이미지, labelImages를 표시사항 영역으로 분류한다. 참조 순서·옵션·필드·첨부 파일명을 보존하고 같은 영역 내 파일을 중복 전송하지 않도록 목록을 중복 제거한다. 같은 파일이 두 영역에 쓰이면 각각 기록한다. 미사용 원본 이미지와 제외 옵션은 계획에서 제외한다. 누락 참조·파일명 충돌·안전하지 않은 경로는 생성 오류다.

ZIP supplier-hub-upload-plan.json에 fingerprint 및 상품 ID를 동봉한다. 파일명은 최종 견적 셀과 동일하다. 공식 템플릿 검증, 법적 서류 해당 여부와 파일, 가격/연락처 동의는 미확인 상태로 남긴다. 모든 목록은 준비 자료이며 브라우저 실행 명령이 아니다.

## 미확인
업로드 요청/응답과 접수번호, 실제 파일 내용·이미지 번역 품질, 최신 공식 Excel 바이너리, 카테고리별 법적 서류 적합성은 미확인이다. Couplus의 실제 전송 경로가 이 대량등록인지도 확정하지 않았다. 전송 API 501 상태를 유지한다. 다음 작업은 공식 Excel 확보 및 검증 후 실제 업로드 연결이며, 이 목록을 전송 성공 증거로 사용해서는 안 된다.
