# 검토한 수정값과 수집 회사 연결

가격·포장 무게의 내부 필드와 Supplier Hub 필드에 연결된 수정 초안이 있을 때, 한 항목에서 저장본을 선택해도 다른 항목의 초안이 다시 값을 덮어쓸 수 있던 문제를 수정했다. 같은 옵션의 연결 항목에 검토 결정을 함께 적용한다. 다른 옵션·일반 항목·독립적인 공식 판매처 가격은 유지하며, 카테고리가 바뀌어 기존 연결 항목이 없어져도 이전 연결을 검토 대상으로 유지한다.

포장 무게의 단일 항목 수정 해제는 기존 규칙을 유지한다. 연결된 두 항목을 함께 복원할 때는 전체 복원 계획을 기준으로 미리보기 값을 계산하여 저장 후 결과와 일치시킨다. 공식 판매처 가격은 권장소비자가격과 별도로 유지하면서 가격 정보 구역에 표시한다.

수집 요청은 상세 양식이 없는 카테고리에서도 당시 승인된 회사 코드와 이름을 별도로 기록한다. 저장된 수집 회사와 현재 계정 회사가 다르면 당시 기본설정을 적용하거나 다른 회사로 견적서를 준비하지 않는다. 기존 상세 양식에 기록된 회사는 읽기 전용으로 사용할 수 있으며, 회사가 전혀 기록되지 않은 기존 초안에 현재 회사 정보를 소급해서 넣지 않는다.

## 검증 범위

연결된 가격·무게의 검토 결정 33건, 회사 기록·계정 회사 변경 11건, 견적서 편집 97건, 포장 무게 연동 18건, 수집·기본설정·환율 45건, 전송 준비·접수 기록 76건, 확장·공개 상품 수집 48건, 총 328건이 통과했다. 타입 검사에 오류가 없었고 정적 검사는 오류 0건과 기존 경고 8건이었다. 기존 마이그레이션 17개도 유지했다.

배포 후 와이홉의 기존 선글라스 상품을 읽기 전용으로 확인했다. 72개 입력값과 수정 없는 저장 버튼 상태가 유지됐으며, 별도 공식 판매처 가격을 포함한 4개 가격 입력이 가격 정보 구역에 표시됐다. 비공개 검사·배포·스크린샷 기록은 `outputs/step598-*`에 보관했다. 기존 상품을 저장·삭제하거나 신규 Supplier Hub 전송을 실행하지 않았다.

회사 비교는 서버 모듈로 분리하여 공개 상품 파서와 별도로 검증한다. 공통 수집 모듈의 생성 파일과 맞춘 새 다운로드 패키지 0.2.58을 제공하며, 기존 0.2.57 패키지를 보존했다. 이미 설치된 0.2.57의 회사 정보·전송 기능 계약은 유지되므로 이번 수정에 재설치가 필수인 것은 아니다.

현재 열린 쿠플러스의 유앤채 기본설정을 읽기 전용으로 대조했다. 환율·마진 계산식과 이미지 설정을 확인했으며 쿠플러스의 설정·기존 상품·설치 프로그램은 변경하지 않았다. 모든 카테고리의 실제 기본값 동등성과 신규 Supplier Hub 최종 접수 완료는 이 검사만으로 입증하지 않는다.
