# 상단 도구 정리와 자동 작업 재개

상단 연결·작업 이력·CLI·운영관리·수집함·멀티계정·설정을 같은 SVG 아이콘과 작은 라벨로 정리했다. 설정 메뉴는 실제 계정 관리, 비밀번호 변경, 계정별 연결 설정, 로그아웃 화면에 연결한다. 기존 전송·편집 중 이동 보호와 메뉴 바깥 클릭/Escape 닫힘을 유지한다. 세 수집 도구는 기본 목록 아래에서 숨기고 수집함 아이콘의 창으로 옮긴다. 창을 닫아도 입력 컴포넌트는 유지하고 회원 변경 때는 별도 범위를 쓴다.

늦게 완료된 이미지 Vision 요청은 원래 요청·원본·모델과 현재 저장 버전을 대조한 후 기존 결과를 적용한다. 새 추론을 요청하지 않는다. 포장 작업의 요청 전 사전검사 실패는 재시도할 수 있으며, 실제 변이 전송 후 응답이 불명확하면 재전송 잠금을 유지한다.

원래 문서의 예상 밖 인증서 진단은 파일명과 S3가 같은 이미지 descriptor에 함께 일치하는지, 공식 certN- 접두 행, LABEL 본문 참조, 원래 법적 본문 일치를 구분한다. 민감한 파일명·키·본문은 노출하지 않는다. 비어 있어야 하는 법적 첨부 목록의 차이를 자동 통과시키거나 삭제하지 않는다. 상세 원문 근거는 step876-retained-certificate-association.md다.

## 검증과 배포

- 자동 작업 118개, 상단·계정·이동 UI 112개, 문서 읽기 48개: 서로 다른 8개 파일의 278개 검사 통과. 초기 UI 가짜 DOM의 focus 함수 누락은 방어적 호출로 보완했고 전체 112개를 다시 통과했다. TypeScript·변경 ESLint·확장 생성물·최종 운영 빌드 통과.
- 최종 Worker: `32be2e46-3882-4b39-9c53-4c1f1fecb8a0`. 26개 동결 파일의 SHA 대조 완료. 빌드 접합점의 Windows EPERM은 기존 동결본을 확인한 뒤 접합점만 생성해 해소했다.
- 확장 2.1.64: 111개 파일, 1,618,076바이트, ZIP SHA-256 `68896525452f8c5a09e4e3dd4acf6ab2305b571cc4ca8fb5e4f167c04129f115`. 실제 설치 폴더를 백업 후 갱신하고 전 파일 SHA를 확인했다. 권한·호스트 변경 없음. 사용자 적용 완료 회신을 받았다.
- 운영 DOM에서 상단 메뉴 항목과 계정 설정의 네 실제 링크, 바깥 클릭 닫힘, 기본 화면 수집 창의 숨김/비활성 대화 역할을 확인했다. 브라우저 스크린샷 두 번은 CDP 시간 초과였다. Windows 캡처 대체도 현재 URL을 확정하지 못해 도구가 중단했으므로 UI 캡처 성공으로 보고하지 않는다.
- 원래 886 상품·설정 범위 35개 표 47행 SHA는 `39f1f5b9ff48173e6d68b0e8d9689aac8eb587f2fb469a0ed6b2984913a3455d`로 Step875와 같다. 더 오래된 Step863과의 product_removals 차이는 이전 승인 복원이며 이번 상품 변이가 아니다.

## 승인된 로그인 관문 전환

사용자의 실행 시점 승인 후 SourceFlow 단일 호스트 앱에 `YOOFAM native approved membership` Bypass/Everyone 정책 `074a8ada-4292-4ff5-b46c-fa70d17672d0`을 추가하고 앱 저장을 완료했다. 기존 owner-only 정책은 남겼으며 다른 Worker는 바꾸지 않았다. 외부 `/login`, `/recover` 200과 익명 계정·상품 API 차단을 확인했다. 상품·설정 API의 기존 503 안내 문구는 별도 UX 과제이며 네이티브 세션 실패 때 Cloudflare로 우회하지 않는다. 인증 생산 코드 변경은 없다. SOLAPI 실제 키·발신번호는 아직 관리자 입력 대기다.

## 남은 실제 접수

원래 상품 `e2f8037c-294e-45a8-b06d-58cc5909683c`, 등록번호 261024001001, 요청 `f29491bd-1882-456a-8a63-eec8586db6c6`, 문서 2347603을 유지한다. 공식 별도 읽기 화면에서 같은 상품의 중간저장 한 건을 불러와 미리보기·가격·법적 고시를 확인했다. 원래 전용 읽기에서 certificate 1건, 파일명 계획 이미지 일치/S3 불일치로 중단했다. 2.1.64의 추가 진단은 적용 회신 뒤 이번 다음 검수에서 읽어야 한다. 공식 다음/저장은 본문 업데이트와 파일 대기 처리를 하므로 재전송 금지 상태에서 누르지 않는다. 새 문서 생성·파일/본문 재전송·삭제·단계 검증·최종 제출은 하지 않았다. 실제 접수는 미완료다.
