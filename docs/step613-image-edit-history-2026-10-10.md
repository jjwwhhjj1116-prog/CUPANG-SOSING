# Step613 — 이미지 영역 편집 되돌리기와 레이어 순서

## 결과

이미지 문구 편집에서 원문·한국어·사각형 위치·크기·색상·글꼴·굵게·기울임·정렬·행간·선택·지우기 변경, 영역 추가·삭제, 레이어 앞뒤 이동을 되돌리고 다시 실행할 수 있다. 마지막 영역을 삭제한 뒤에도 복구 버튼을 사용할 수 있다. 배열에서 뒤에 오는 영역을 마지막에 그리므로 `앞으로`는 배열의 다음 위치로, `뒤로`는 이전 위치로 이동한다. 목록의 순서와 실제 PNG의 겹침 순서가 일치한다.

같은 텍스트 입력에 포커스를 둔 동안 입력한 문구는 하나의 되돌리기 작업으로 묶는다. 포커스를 옮기거나 흐림, 다른 필드·스타일·선택·삭제·이동 작업은 별도의 작업이 된다. 현재 작업의 번역 응답은 원문과 번역 출처·오류를 포함한 영역 변경 하나로 기록한다. 직접 작성한 공란과 문구를 보존한다. 과거 편집에 되돌아간 뒤 실제 새 변경을 하면 이전 다시 실행 분기를 지우며, 값이 같은 이벤트는 기록과 다시 실행 분기를 유지한다.

## 범위와 보존

- 과거·미래 기록의 합계는 최대 20개다. 배열·영역 객체·사각형을 복사하고 문자열은 공유한다. 편집 중의 `NaN`, `Infinity`, `-0`도 JSON 변환 없이 그대로 복원하며 렌더러가 유효하지 않은 입력을 검증한다.
- 기록은 영역 값만 포함한다. 원본 파일·서버 원본 증명·상품 버전·옵션 선택·최종 견적서 연결 증명·미리보기 PNG·전송 대기 PNG는 되돌리지 않는다. 수동 영역 ID는 계속 증가하여 삭제·복구 뒤 재사용되지 않는다.
- 실제 새 원본 선택, 원문 인식의 기준값 수락, 편집 초안 지우기, 서버의 저장 완료 확인에서 기록을 초기화한다. 같은 바이트의 원본 확인, 저장 버전 변경, 옵션 화면 이동으로 보존하는 초안은 기록도 함께 보존한다.
- 영역 변경과 되돌리기·다시 실행은 미리보기를 폐기한다. 오래된 화면 이벤트, 삭제 후 재인식한 같은 ID의 이벤트, 다른 옵션·역할의 이벤트, 닫힌 편집기, 처리 중·저장 응답 미확인·동일 PNG 재시도 중에는 편집을 허용하지 않는다.
- 오래된 번역 요청 버튼도 현재 편집 세대가 아니면 요청하지 않는다. 일반 입력 수정 이후에는 최신 선택·원문을 읽어 요청한다. 저장 버전 변경 후에는 영역 입력을 비활성화하고 같은 원본 확인 후 다시 활성화한다.
- 렌더링 상태는 React 상태에서 계산하고 실제 이벤트 보호는 최신 참조에서 계산하여 검사 규칙을 끄지 않는다.

기존 Couplus·YOOFAM PLUS·Supplier Hub 작업 상품을 수정하거나 삭제하거나 전송하지 않았다. 신규 1688 접근, 계정·회사 연결 변경, 확장 패키지 변경, 유료 서비스·인증 변경을 포함하지 않는다.

## 검증

`free-image-edit-history` 테스트 10개는 입력 묶음·복구·분기·최대 20개·객체 분리·순서·공란·잘못된 중간 숫자 보존을 검증한다. 실제 편집 컴포넌트 테스트는 모든 수동 변경, 전체 삭제 후 복구, 번역 한 번 복구, 같은 원본 확인, 오래된 콜백, 미확인 저장과 동일 PNG 재시도를 검증한다.

렌더러 테스트는 겹치는 글자·지우기 영역의 순서, 삭제·재추가, 선택 해제, 원본과 영역 밖 픽셀을 검증한다. API 테스트는 실제 PNG 인코딩과 실제 이미지·견적서 경로, SQLite/R2를 거쳐 저장 실패 재시도, 출력 digest, 최종 이미지 읽기 및 직접 작성한 대표·추가·상세·HTML 값을 검증한다. 이 테스트의 Canvas는 모의 구현이며 실제 글꼴 래스터 검증과 구분한다.

별도로 기존 Chrome의 검수 탭에서 실제 React 편집 컴포넌트와 실제 Canvas 렌더러를 사용하는 로컬 합성 이미지로 앞으로 이동 → 되돌리기 → 다시 실행 → 삭제 → 복구를 조작했다. PNG 6개의 겹침 픽셀은 민트 `[104,207,175,255]`와 주황 `[255,189,154,255]`으로 지정 순서대로 변했고, 모두 원본·영역 밖 픽셀을 보존했다. 읽기/OCR은 테스트용 값이고 외부 번역·실제 상품 저장은 사용하지 않았다. 기록은 `outputs/step613-native-render-result.json`이다. 로컬 화면 캡처는 CDP 시간 초과로 확보하지 못했으며 운영 앱 캡처와 검증된 DOM 기록을 별도 보관한다.

최종 코드로 Chrome 검수를 반복했으며 같은 입력에 연속 수정한 한국어 문구를 한 번에 이전 값으로 되돌리고 마지막 값으로 다시 실행하는 동작도 확인했다. 입력 묶음 결과는 `outputs/step613-native-group-result.json`에 보관한다.

편집 회귀 151개와 견적서·전송 회귀 118개, 총 **269/269**가 통과했다. 실패·건너뛰기·취소는 0개다. TypeScript 오류 0개, ESLint 오류 0개와 기존 경고 8개, 운영 빌드 통과를 확인했다. 결과는 `outputs/step613-*-tests.log`, `step613-types.log`, `step613-lint.log`, `step613-build.log`에 보관한다. 운영 산출물·배포 버전·새 번들·기존 입력 보존·Git 푸시 검증은 각각 `step613-artifact-verification.json`, `step613-deployment.json`, `step613-live-verification.json`, `step613-git-push.json`에 보관한다.

## 미완료 범위

이번 검증은 영역 편집·레이어·PNG·최종 이미지 연결의 범위다. Couplus 전체 카테고리 기본값의 실사이트 일치, 새 1688 상품 수집부터 새 Supplier Hub 접수 번호까지의 실거래 전체 경로는 여전히 검증 완료로 간주하지 않는다. 자유 브러시·사진 드래그 편집과 완전한 Couplus 편집 화면 일치도 이 변경의 완료 범위가 아니다.
