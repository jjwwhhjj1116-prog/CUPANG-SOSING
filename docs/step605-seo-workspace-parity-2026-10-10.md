# 1단계 SEO 화면과 초안 작성·수정 연결 — 605

쿠플러스에서 보관한 `01-seo.jpg`의 작업 순서를 기준으로 SEO 초안 작성과 편집을 같은 단계에 배치했다. 기존 화면에서 공통 SEO와 옵션 편집이 여러 영역에 나뉘어 있던 문제를 개선했다. 이 변경을 전체 1~7단계 동등성이나 실제 Supplier Hub 신규 접수 완료로 취급하지 않는다.

## 입력과 수정 화면

상단에는 브랜드·상품 특징·타겟 키워드, 상품명 예시와 초안 작성 버튼을 배치했다. 아래에는 상품명·검색태그 편집과 원본 사진·원문·한국어 옵션명 편집을 좌우로 배치한다. 좁은 화면에서는 세로로 표시한다. 1단계에 생성 이력·원문 확인·남은 옵션 번역 진입도 연결했다.

카테고리·수집 원문 보완은 펼침 영역으로 유지해 기본 편집 화면의 공간을 확보한다. 기존 카테고리 선택·원문 보완·진행 중 검사와 미저장 입력 보호는 그대로 사용한다. 옵션에 대표 이미지가 아직 없어도 연결된 소유 원본 사진이 있으면 미리보기로 표시하며, 사진을 옵션에 자동 지정하거나 저장하지 않는다.

브랜드는 회사 검사를 거친 상품의 등록 설정 조회에서 읽는다. 수집 당시 설정이 있으면 그 값을 쓰며, 현재 회원 설정으로 기존 수집 회사나 브랜드를 바꾸지 않는다. 입력한 브랜드 메모와 상품명 예시는 상품의 등록 브랜드를 자동 변경하지 않는다. 실제 저장할 상품명과 브랜드 접두사는 적용 미리보기에서 확인하고 직접 수정할 수 있다.

상품명 입력은 관측한 100자 표시·입력 한도를 사용한다. 이전의 더 긴 저장값은 화면을 열었다고 자르거나 다시 저장하지 않는다. 검색태그는 견적서 150자 기준을 표시하고 기존 태그 검토 기능을 유지한다. 설명·다른 단계의 미저장 값, 선택 SKU의 개별 상품명·태그와 공통 SEO 저장 경로도 유지한다.

## 초안 작성 버튼

현재 상품 버전·콘텐츠 버전·수집 원문·선택 카테고리·미번역 옵션을 확인한 뒤 기존 번역 API에서 준비→승인→실행을 연결한다. 실행 서비스가 무료 Google이면 ‘한국어 초안 자동 작성’, 실제 AI 설정이면 ‘AI 자동 생성’으로 표시한다. 설정 조회 전에는 중립 제목을 표시한다. Google 번역을 AI SEO 생성과 같은 품질로 주장하지 않는다.

Google에는 저장된 상품 텍스트만 전송한다. 특징·키워드는 원문과 구분한 검토 메모로 보관하며, AI 설정에서는 사실을 새로 만들어내는 근거로 쓰지 않는다. 작성 결과는 먼저 표시하고 기존 통합 미리보기에서 명시적으로 저장한다. 작성 버튼 자체로 상품 콘텐츠·옵션·이미지·견적서를 저장하지 않는다. 적용 전에도 다른 단계의 미저장 입력과 진행 중인 요청을 검사한다.

같은 요청의 키·승인·실행 제출 상태를 보관한다. 준비 응답이 유실되면 같은 키로 준비 상태만 재확인한다. 실행 제출 후의 응답 유실·실행 중·불확실한 상태는 조회만 하며 외부 서비스를 다시 호출하지 않는다. 현재 상품·원문·메모·서비스 설정이 바뀌면 이전 요청을 실행하지 않는다. 세션 복구 자료가 잘못되면 새 요청을 조용히 만들지 않는다. 누락 번역과 HTTP 429·5xx의 부분 결과도 완료된 전체 초안으로 표시하지 않는다.

## 한국어 옵션명 저장

`PATCH /api/products/:id/option-names`는 명시적으로 수정한 옵션 ID와 한국어 이름만 받는다. 소유자·상품 버전·옵션 버전·유일한 옵션 연결을 확인하고 비교 갱신한다. 원가, 포함 여부, 수량, 재질·색상·사이즈, 포장 수치, 사진, 정렬과 다른 항목의 출처는 그대로 유지한다. 가격이나 사진이 미확인 상태여도 이름 수정 때문에 해당 사실을 새로 채우거나 파일을 다시 여는 동작은 없다. 최종 견적서의 필수 검사도 우회하지 않는다.

사용자가 같은 공란을 직접 입력한 경우에도 이름의 출처를 수동으로 기록해 이후 자동 번역으로 채워지지 않게 한다. 저장 응답의 상품·버전·전체 옵션 값과 명시한 이름 출처를 확인한다. 다른 옵션의 비용이 섞인 응답이나 충돌 응답은 입력을 지우지 않고 자동 재저장하지 않는다.

## 검수 경계

회귀검사는 실제 클라이언트 콜백·API 처리와 기록·합성 응답을 사용한다. 준비·승인·실행 중복, 응답 유실, 부분 번역, 회사 불일치, 이름의 명시적 공란, 다른 필드 보존, 단계 이동과 입력 보존을 검증한다. 시험 결과를 실제 Google 운영 호출, 신규 1688 수집이나 원격 Hub 접수 성공으로 계산하지 않는다.

검사 중 발견한 이전 테스트의 가정도 정리했다. 상품명은 예전 500자 속성 대신 실제 SEO 입력으로 찾는다. 두 옵션 편집기는 React처럼 경로별 독립 상태로 검사한다. 회사 변경 테스트는 한 회사로 정상 수집한 뒤 인증 회사만 바꾸며, 허용 사례는 별도 독립 상품으로 만든다. 기존 동결 상품의 회사나 원문을 시험 편의상 다시 지정하지 않는다.

운영 확인과 최종 검사·배포 식별값은 릴리스의 비공개 `outputs/step605-*` 기록에 보관한다. 기존 사용자 탭의 기본설정·등록표와 작업 상품은 보존한다. 확장·권한·DB 마이그레이션은 변경하지 않는다.

최종 회귀검사 148개가 중복 없이 통과했다. 타입 검사와 빌드도 통과했으며 린트는 오류 0개, 기존 경고 8개다. 기존 마이그레이션 17개와 확장 0.2.57·0.2.58 배포 ZIP의 바이트 일치도 확인했다. 운영 Worker 버전은 `399ff6d6-e310-4805-8b9d-31b1a52f8218`이다.

같은 Chrome의 별도 검수 탭에서 최종 SEO 화면과 실제 스크린샷을 확인했다. 원래 사용자 탭의 설정 입력 34개와 등록표 1행, 기존 편집 입력 159개가 모두 유지됐다. 상품명 100자·검색태그 150자 표시, 옵션명 6개, 좌우 편집 배치와 수정 없는 저장 버튼의 비활성화도 확인했다. 확인한 기존 상품은 수집 당시 회사와 현재 인증 회사가 달라 초안 작성을 차단한다. 이 회사 보호 결과를 신규 초안 작성 성공으로 기록하지 않았으며 기존 상품을 다른 회사로 바꾸지 않았다. 운영 Google 호출·신규 수집·상품 저장·Hub 업로드와 실제 신규 접수는 이번 검수에서 실행하지 않았다.

남은 범위는 모든 카테고리의 쿠플러스 기본값 대조, 신규 URL부터의 운영 초안·실제 이미지 처리, 실측 포장값·라벨 확인과 실제 Supplier Hub 최종 접수다. YOOFAM 전용 Codex 플러그인은 이 등록·제안 검수를 마친 뒤 진행한다.
