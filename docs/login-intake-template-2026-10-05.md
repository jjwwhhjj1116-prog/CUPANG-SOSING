# 로그인 유지와 카테고리 → URL 초안 연결

## 로그인

기존 로그인 화면을 YOOFAM PLUS 전용 레이아웃으로 교체했다. 이메일·비밀번호 입력, 비밀번호 표시, 가입 요청, 오류·접수 상태, 모바일 배치를 정리했다. 아이디 저장과 자동 로그인 유지는 최초에 선택되며 사용자가 해제한 선택도 저장한다. 브라우저에는 이메일과 선택값만 저장하고 비밀번호는 저장하지 않는다. 비밀번호 입력은 브라우저의 `current-password` 자동완성을 지원한다.

로그인 시 기본 세션을 30일로 발급하고 자동 로그인을 해제하면 8시간으로 발급한다. 서버 DB 만료와 HttpOnly/SameSite strict 쿠키 만료를 일치시켰다. HTTPS에서는 Secure 쿠키를 사용한다. 계정 관리의 명시적 ‘로그인 설정 저장’은 현재 인증된 본인의 세션만 교체한다. 이전 토큰은 폐기하며 다른 브라우저의 세션과 회원 회사정보는 바꾸지 않는다. Cloudflare Access 정책은 변경하지 않았다.

## 소싱과 견적 양식

카테고리 선택은 현재 회원·회사·정확한 카테고리 schema를 확인한 뒤 바로 URL 입력으로 이어진다. 공식 Excel 다운로드가 초안 작성의 선행 조건이었던 부분을 분리했다. 기존에 연결한 양식과 수동 매핑은 보존한다.

7단계의 ‘공식 견적 양식 준비’는 저장된 전체 경로를 현재 회사의 카테고리 트리에서 정확히 다시 확인한다. 최종 코드와 schema가 같을 때만 파일을 가져와 동일 profile에 연결한다. 이름이 비슷한 다른 분류를 추정하지 않는다. 실패해도 기존 상품 초안과 수동 공란·수정값은 보존한다.

확장 0.2.47은 같은 Chrome 창의 `/dashboard/KR`에서도 회사·카테고리·양식 GET 조회를 지원한다. 기존 탭 이동이나 상품 수정은 하지 않는다. 실제 첨부·전송은 기존 등록 경로 검사를 유지한다. 이미 설치된 확장에는 폴더 업데이트와 새로고침이 필요하다.

## 이미지 편집

3~5단계에 픽셀 크기 조절을 추가했다. 기본 비율 유지, 명시적 비율 해제, 미리보기 후 새 파일 추가를 지원한다. 원본과 다른 단계·옵션별 선택은 보존하고 현재 단계에서 선택된 원본 위치만 편집 초안에 교체한다. 기존 저장 버튼을 눌러 견적에 반영한다. 외부 AI 요청은 하지 않는다.

## 검증 범위

- 실제 앱 API와 임시 SQLite: 30일/8시간 로그인, 현재 세션만 교체, 승인 상태·만료·정지·외부 origin·타인 요청·동시 요청 경계.
- 실제 컴포넌트/API와 임시 SQLite: 카테고리 선택 → 기록된 813724060928 원문 기반 6 SKU 초안 → 수동 수정 → 양식 연결 실패/재시도 → 최종 XLSX. 외부 schema/공식 양식은 통제된 fixture이므로 모든 실제 카테고리 검증이라는 의미는 아니다.
- 이미지: 파일 업로드·첨부 API/SQLite, 원본/수동 선택 보존, PNG 픽셀과 최종 XLSX 확인. Canvas는 시험 어댑터이며 실제 브라우저 편집 실행 증거와 구분한다.
- Chrome4 와이홉의 회사 메뉴 A01464742와 실제 대량등록 화면·공식 양식 검색을 읽었다. 선글라스 양식 다운로드 클릭 후 Hub의 생성 성공 안내를 확인했으나 생성된 XLSX 바이트까지 확인하지는 못했다. 실제 상품 첨부·동의·최종 전송은 하지 않았다.

전체 카테고리의 실제 기본값, 운영 AI·번역, 최종 Supplier Hub 견적 ID/SKU 실검증은 별도 남아 있다. 관리자 회사정보는 미설정 상태를 확인했으며 임의로 배정하지 않았다. 기존 Couplus 작업 상품은 변경하지 않았다.
