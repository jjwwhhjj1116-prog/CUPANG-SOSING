## 자동작성의 구성과 추정

화면에서 확인되는 구조는 ‘선택한 카테고리의 양식 + 기본설정 + 상품/옵션 작업 결과’를 조합한다. 예를 들어 브랜드·제조사·A/S 연락처·박스 입수는 기본설정과 대응하고, 상품명·검색어는 SEO, 공급가·판매가는 가격 단계, 이미지와 HTML은 이미지 단계의 결과와 대응한다. 이 대응 관계와 실제 표시값은 관찰할 수 있지만, 쿠플러스 서버의 모든 내부 우선순위나 카테고리 API를 추적한 것은 아니다.

SourceFlow는 이 원리에 맞춰 공통값을 자동 연결하며 우선순위를 **옵션별 수정 > 상품 공통 수정 > 자동값**으로 명시했다. 수정을 해제하면 최신 자동값으로 돌아간다. 빈 문자열로 지운 값도 의도적인 수정으로 보존한다. 원산지·인증·포장 무게 등 확인하지 않은 사실을 ‘해당사항없음’으로 채우지 않는다.

Excel 연결은 선택 카테고리에서 확인된 필드명과 열 이름의 정확한 일치를 사용한다. 공백·필수 별표만 정규화하고, 중복 열이나 단위가 다른 불명확한 열은 자동 연결하지 않는다. 저장한 연결은 다음 상품에도 재사용한다. 이 동작은 사용자 편의를 위한 구현이며 쿠플러스 내부 매핑 알고리즘을 확인했다는 뜻은 아니다.

## 미확인

- 전체 최종 카테고리 목록과 모든 카테고리의 개별 속성·상품고시·인증·물류 규칙.
- 80719의 공식 이미지/법적정보/물류 페이지 입력 검증과 실제 Excel 셀·숨김 시트·목록 제약. 해당 영역의 현재 구현 근거는 사용자 스크린샷이다.
- 다운로드 요청 성공 및 브라우저 download 이벤트는 확인했지만 도구가 파일 경로를 제공하지 않았다. 다운로드 관리 화면은 도구 정책으로 차단됐다. 사용자에게 실제 파일 경로를 요청했으며 파일을 읽은 것으로 보고하지 않는다.
- Supplier Hub 제안 생성·첨부 업로드·최종 접수 및 접수번호 회수. 운영 전송 API는 아직 501이다.
- 지정 실상품의 원문 자동수집과 실제 AI 처리 결과. 로컬 테스트는 합성 상품으로 수행한다.

## 외부 상태와 다음 확인

Supplier Hub 개별 등록 양식을 열기 위해 조사 전용 탭에서 `양식 구조 확인용 바스켓`이라는 제목과 80719를 입력하고 ‘다음’을 눌렀다. 상품정보 페이지에서 ‘마지막 저장’ 시각이 표시됐다. 사이트가 초안을 자동 저장했을 가능성은 있으나 저장 위치나 지속성은 확인하지 않았다. ‘저장하기’, 약관 동의, 상품 최종 등록은 실행하지 않았다. 원래 사용자의 상품과 탭은 보존했다.

다음에는 공식 Excel 파일을 읽어 개별 등록 코드와 대량 양식의 실제 열·선택값을 대조한다. 분류 코드를 확인한 것과 해당 견적서가 접수되는 것을 별도로 검증한다.
