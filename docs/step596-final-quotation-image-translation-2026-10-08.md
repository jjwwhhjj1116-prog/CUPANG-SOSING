# 선택 옵션 견적 이미지 번역 연결

3·4·5단계에서 선택 옵션의 최종 대표·추가·상세 이미지에 중국어/영어 번역 편집 버튼을 연결했다. 저장된 원본을 읽고 문구를 한국어로 번역·수정한 뒤 미리보기를 확인하고 적용한다. 단계 이동이나 번역 편집 진입만으로 이미지가 적용되지 않는다.

적용은 선택한 SKU의 선택 이미지 위치만 바꾼다. 카테고리 정규 필드와 실제 Supplier Hub 양식 필드를 같은 변경으로 저장하고, 번역 PNG를 해당 상품의 이미지 목록에 추가한다. 원본 이미지·공통 자료·다른 SKU·가격·직접 작성한 HTML은 보존한다.

회사의 상품·상세 양식·옵션·이미지 위치를 원본 조회 때 확인한다. 적용 전에 상품·콘텐츠·옵션·견적·설정·카테고리 버전을 다시 대조한다. 응답이 유실되면 같은 PNG와 전체 견적 변경값을 읽기 전용으로 확인한다. 적용되지 않았고 원본도 그대로인 경우에만 사용자가 같은 결과를 다시 적용할 수 있다. JSON 속성 순서가 달라도 같은 이미지 식별값을 사용한다.

3단계의 선택 옵션 최종 대표이미지는 공통 원본 이미지 작업 목록에 가려지지 않도록 공통 작업을 접을 수 있게 했다. 단계 이동 중 작성한 입력과 번역 편집 상태는 유지한다.

## 검증

두 회사와 추가·상세 이미지, 실제 SQLite·R2 fixture, canonical/양식 필드 연결, XLSX·등록 manifest, stale/CAS·응답 유실·탐색 변경, 직접 수정 문구와 공란 보존을 검사했다. 기존 이미지·견적·공식 양식·카테고리·수집 회귀 검사도 수행했다. 상세 검사 수와 배포 파일 확인값은 비공개 `outputs/step596-*` 기록에 남긴다.

실제 와이홉 Chrome에서 Supplier Hub의 16개 대분류와 패션의류잡화 → 유니섹스/남녀공용 패션 → 공용 잡화 → 선글라스의 하위 연결을 조회했다. 최종 `남녀공용패션선글라스 69900`은 기존 상품의 카테고리 코드와 일치했다. 신규 상품 추가·견적 등록은 하지 않았다.

지정 1688 페이지의 추가 포장 정보 접근은 브라우저 제어 도구의 사이트 안전 정책으로 거절됐다. 우회 수집이나 확인되지 않은 포장 무게·사이즈 입력은 하지 않았다. 이 구현·회귀 검증은 이미 저장된 상품·이미지 자료로 수행했다. 모든 카테고리 대조와 실상품의 최종 Supplier Hub 접수 완료는 별도 검수 범위로 남는다.
