# 사용자 지정 Google 텍스트 번역 — 2026-10-05

사용자가 제공한 C# `TranslateWithFreeEndpointAsync`의 GET 방식을 현재 TypeScript/Workers 앱에 연결했다. 기본 서비스는 `google-free`이며 모델 식별자는 내부 표시용 `google-translate-gtx`, AI 출력 토큰은 0이고 Workers AI 바인딩은 만들지 않는다. 비밀 키와 유료 AI 호출이 필요하지 않다. 이 주소의 가용성이나 무제한 이용을 보장한다는 뜻은 아니다.

## 요청과 실패 처리

- 고정 주소 `https://translate.googleapis.com/translate_a/single`, `client=gtx`, `dt=t`. `q`는 URLSearchParams로 정확하게 인코딩한다.
- 원문 언어 기본 `auto`, 목표 언어 기본 `ko`. helper는 명시 언어 코드도 받으며 쿼리 삽입값은 거절한다.
- 공란 및 원문 5,000자 초과는 요청하지 않고 null을 반환한다. 원문을 잘라 성공으로 보이지 않는다.
- 개별 텍스트 제한시간은 기본 10초, 옵션은 3~30초로 제한한다. 이 제한은 상품 전체 묶음의 10초 완료 약속이 아니다.
- 배열 응답의 각 번역문을 합치고 HTML entity를 한 번만 복원한다. 감지 언어도 보관한다. JSON/HTTP/네트워크/취소 오류는 null이며 자동 재시도하지 않는다.
- 응답은 512KiB까지 읽으며 리디렉션·잘못된 UTF-8·형식 오류를 거절한다. Workers가 지원하는 `redirect:manual`을 사용하고 3xx 상태를 실패로 처리해 다른 주소로 상품 원문을 보내지 않는다. 반환값은 일반 텍스트로 표시하고 HTML로 실행하지 않는다.

## 상품 초안 연결

상품명·설명·속성명·속성값·옵션값을 번역한다. 원문 순서의 sourceIndex와 option ID를 유지하며 같은 텍스트는 한 번 요청한다. 이미 한국어인 값과 순수 숫자/단위/코드는 보존한다. 검색어는 번역한 상품명에서만 구성하며 카테고리와 SEO 메모로 새로운 상품 사실을 만들지 않는다.

상품명을 먼저 확인하고 실패하면 후속 속성 요청을 시작하지 않는다. 그 외 텍스트는 동시 최대 3개, 한 번의 서버 실행에서 최대 49개만 요청하며 옵션을 우선한다. [Workers Free의 외부 요청 제한](https://developers.cloudflare.com/changelog/post/2026-02-11-subrequests-limit/)을 지킨다. 누락·실패·초과 항목은 원문을 보존하고 검토 필요로 표시한다. 속성이 많은 상품 전체를 번역했다고 간주하지 않는다.

새 결과는 v6 한국어·숫자 검증과 현재 상품/콘텐츠 버전 검사를 거쳐 저장한다. URL 수집 초안과 직접 검토하는 번역 패널 모두 같은 서비스로 연결했다. 재조회로 동일 작업을 다시 호출하거나 수동값·공란·제외 옵션을 덮지 않는다. 기존 Workers AI/OpenAI 이력은 유지하며 기존 승인을 Google 요청에 재사용하지 않는다.

## 검증 범위

전체 2,209개 검사가 통과한 뒤 실패 진단과 Workers 호환 수정에 대해 Google helper/provider/config 집중 23개, TypeScript 및 변경 lint를 추가 통과했다. 기록된 지정 1688 상품 6SKU를 사용하는 실제 API/임시 SQLite 검사는 양사에서 Google 호출·편집 가능한 제목/옵션·19개 원본 이미지·수동 수정 보존·재조회 시 중복 호출 방지를 확인했다. 이 테스트의 Google 번역 응답은 fixture이며 실제 외부 번역 성공을 의미하지 않는다.

실제 로컬 workerd에서 초기 `redirect:error`가 HTTP 전 TypeError를 발생시키는 것을 재현했다. `manual`로 수정한 exact helper는 정상 JSON 번역과 308 차단을 통과했다. 재현 스크립트 `scripts/check-google-translation-runtime.mjs`는 합성 서비스 요청 2개만 실행하며 외부 요청과 사용자 자료를 사용하지 않는다. 고정 사유·HTTP 상태·허용된 오류 분류만 보관하고 원문·응답 본문·예외 문자열은 진단에 넣지 않는다.

운영에 호환 수정본을 배포하고 같은 와이홉 Chrome의 새 검수 상품에서 21:13 새 요청을 실행했다. Google이 **HTTP 429**를 반환하는 것을 화면에서 확인했다. PC의 앞선 GET도 429였다. 실제 외부 번역 성공은 미확인이다. 실패한 응답을 번역 완료로 적용하지 않았으며 기존 원문과 초안은 유지했다. 자동 재시도와 다른 유료 서비스 전환은 하지 않았다. 최종 배포와 범위는 HANDOFF의 574절을 확인한다.

이미지 OCR·이미지 안 번역문 재합성은 이 서비스 범위가 아니다. Supplier Hub 최종 접수 완료나 모든 카테고리 검증 완료로 보고하지 않는다.
