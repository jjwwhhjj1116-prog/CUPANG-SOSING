# 쿠플러스 가격 기본설정 대조 — 2026-09-24

## 확인

기존 supplierChrome의 새 settingsCompareTab에서 로그인된 `/AIRocketReg` → 기본설정을 읽었다. 설정 저장이나 값 변경은 하지 않았다.

가격 화면: 적용환율350, 공급 마진50%, 쿠팡 마진40%, 가격 반올림 단위10원, MSRP배수1.3, 최소 공급 마진 보장 켜짐/3000원. 공급가=매입가/(1-공급마진), 판매가=공급가/(1-쿠팡마진) 안내를 확인했다. 이 값은 해당 계정의 현재 설정이며 전체 서비스 공통 기본값으로 간주하지 않는다.

이미지 화면: 상단 이미지 사용/이미지 번역/카피라이트 켜짐, 하단 이미지/누끼 자동적용/비노출속성 자동생성/번들링 꺼짐. 상단 이미지 변경 버튼이 존재한다. 현재 SourceFlow의 전역 상하단 이미지 연결은 아직 구현되지 않았다.

## 코드 대조 및 반영

SourceFlow는 단위별 올림만 지원했다. 선택 가능한 반올림을 추가했다. 사용자 첨부 화면의25.6CNY 사례에 위 가격값을 적용하면17920/29870/38830으로 일치한다. 기존 올림에서는MSRP38840이므로 차이가 있었다.

기존 저장 정책에서 방식이 생략되면 올림을 유지한다. 기본설정과 상품별 가격 화면에서 반올림을 명시적으로 선택·저장할 수 있다. 옵션 가격과 견적 resolver는 저장된 동일 정책을 사용한다. 최솟값 보장은 반올림보다 우선한다. 계정 설정값이나 기존 상품 가격을 일괄 변경하지 않았다.

## 미확인

쿠플러스 내부 구현의 경계값 반올림 순서·최소마진 처리·번들링 전체 동작은 미확인이다. 관찰한 사례 일치는 모든 가격 조건의 동등성을 보장하지 않는다. 유료 AI 작업/상품 추가/운영등록은 실행하지 않았다.
