2026-10-15 구현·검수, 2026-10-16 배포. 기준 커밋 `382efe286846e22672b1663702b79064703d458c`. 대상은 견적서에서 선택한 옵션의 대표·추가·상세·표시사항 이미지다. 기존 작업 상품을 변경하지 않는 격리 자료로 검수했다.

## 대조한 동작과 구현 범위

`step684-edit-session-parity-audit.md`에 보관된 Couplus 클라이언트의 실제 편집 버튼, requestId/iframe bridge, 저장 callback의 유지 필드를 기록했다. 외부 편집기 서버의 내부 문서 형식이나 실제 세션 복원은 확인하지 않았다. 자체 구현은 원본 파일과 저장 결과를 분리하여 사용자가 검토한 편집값을 다시 여는 기능이다. 외부 업체의 전체 편집기와 같은 코드·서비스라는 주장은 하지 않는다.

- 최초 원본 key/SHA/치수와 현재 견적서에서 교체할 결과 key/SHA를 분리한다. 다시 열 때 최초 원본 캔버스에 같은 편집값을 한 번 그린다. 자른 결과를 원본으로 사용하여 문구를 중복 적용하지 않는다.
- `free-image-edit-v1` 문서에 원본의 표시 방향, 중국어/영어 선택, 영역 순서·원문·번역문·선택 여부·출처·서식·색·박스, 지우기/브러시의 경로·지름, 원본 좌표의 crop을 저장한다. 선택을 해제한 영역과 수동 공란도 보존한다. Undo/redo의 지난 세션 기록은 저장하지 않으며 재편집 시작부터 기록한다.
- 검증기는 선택 여부와 관계없이 모든 영역·서식을 검사하고 독립된 정규 문서를 만든다. 100개 영역, 원문/번역문 각각 20,000자, 개별 5,000자, 1,200만 픽셀, 브러시당 2,048점/전체 8,192점, 512KiB UTF-8 한도다. 폰트는 기존 enum만 허용한다.

## 저장과 재열기

결과의 결정적 번호는 기존 원천 증거와 crop/옵션 범위, 새 문서 SHA, PNG SHA에 묶인다. 문서가 없는 기존 경로의 번호는 바꾸지 않는다. 같은 PNG라도 저장할 편집값이 다르면 다른 결과다.

1. 원본·현재 선택 옵션/필드/슬롯·저장 버전·카테고리를 다시 확인한다.
2. 소유 상품, 승인 회사, 정확한 카테고리 context, 원본 증거, 정규 편집 문서, 실제 결과 증거를 불변 R2 sidecar에 보관하고 실제 바이트를 다시 읽어 확인한다.
3. PNG에 문서 SHA와 전체 sidecar SHA를 연결하여 저장한다. 파일 응답 손실은 같은 바이트/메타데이터 조회로 확인하며 덮어쓰기·삭제하지 않는다.
4. 새 문서 경로는 기존 견적/이미지풀 변경과 함께 승인 회원·회사, 견적 원문, 원천 CAS 및 SQL 최종 상태를 검증한다. 충돌 시 파일이 미연결 상태로 남을 수 있으나 성공으로 표시하지 않는다.
5. 응답 미확인 시 같은 문서·PNG의 읽기 복구만 수행한다. 자동 재전송은 없다.

수동 편집으로 다시 열면 현재 결과가 그 슬롯에 있는지 확인하고 원본/결과/문서의 실제 바이트와 해시를 대조한다. 과거의 적용 권한을 복사하지 않고 최신 버전의 원천 증거를 발급한다. 같은 상품의 다른 옵션·회사·카테고리나 별도 가족 상품으로 문서가 승계되지 않는다. 현재 연결과 무관한 다른 옵션의 수정값은 보존한다.

일반 파일 API로 sidecar를 받지 못하도록 제한했다. 모든 새 문서 증거와 sidecar가 없는 구형 이미지에만 구형 이미지 열기를 허용한다. 일부 증거만 빠지거나 바이트가 바뀐 새 결과는 손상으로 처리한다.

## 화면

견적 이미지의 기존 수동 편집 진입을 사용한다. 저장된 편집 문서가 있으면 원본 사진과 편집값을 복원한다. OCR·번역·미리보기·적용은 자동 실행하지 않는다. 같은 카드 재선택은 현재 문구·서식·언어·crop을 덮어쓰지 않는다. 새 영역은 기존 manual/brush ID와 겹치지 않는다. 저장 상태 새로 확인은 현재 초안을 유지하며 원본/적용 위치만 다시 검증한다. 옵션·버전 변경, 취소·닫기, 늦은 응답과 중복 클릭은 기존 잠금과 함께 검사한다.

서버가 보증하는 것은 검토한 편집 문서와 PNG의 저장 연결이다. 브라우저 폰트/Canvas를 서버에서 재실행하여 픽셀이 같음을 검증했다는 뜻이 아니다.
