# Step636 이미지 설정과 사이즈표 견적 연결

## 변경한 동작

Couplus 공개 번역 코드에서 이미지 스타일 지침을 마케팅 카피와 레이아웃 요청에 전달하는 것을 확인했다. 기존 YOOFAM PLUS는 `addCopyright`를 법적 저작권 표시로 해석하여 항상 미적용했다. 이제 저장된 이미지 번역과 카피라이트 설정이 켜진 경우, 원본 이미지 AI 가공 요청에 원문 판매 문구를 간결한 한국어로 다듬는 지침을 반영한다. 기존 `translationPrompt`를 사용하며 새 설정 필드나 계정 설정 이관은 없다. 문구 정리 목적과 번역 설정이 꺼진 경우 카피를 적용하지 않는다. 기존 상품 인쇄·라벨·상표·워터마크·숫자·단위를 유지하고 새로운 사양이나 소유권 문구를 만들지 않는다.

기본설정 화면은 Couplus처럼 이미지 번역을 끄면 카피라이트 제어를 숨기면서 저장된 선택과 지침을 유지한다. 처리 방식이 변경되었으므로 새 검토 요청은 recipeVersion 2를 사용한다. 이전 대기·승인 요청은 재검토가 필요하며, 완료 결과의 조회·무료 첨부와 역할 적용은 유지한다. 서버와 SQLite 승인·실행 조건에서 버전을 확인한다.

생성된 PNG는 이미 형식과 크기 검사를 통과했지만 R2에 해당 기록을 저장하지 않아 견적 검수에서 검사 기록이 없다고 표시되었다. 생성 시 기존 업로드와 같은 `imageValidation`, `dimensionValidation`, `imageWidth`, `imageHeight`를 기록한다. 실제 픽셀 크기 권장 경고와 과거 파일의 기록 누락 경고는 유지한다.

기록된 Supplier Hub Single 69900 v188에는 `imagePage.images.sizeChartImage`가 존재하며, Couplus 사이즈표 저장도 이 항목을 갱신한다. 이 정확한 선택 항목을 사이즈표 이미지에 연결했다. 기존 동적 항목 ID를 유지하고, 저장한 사이즈표를 7단계·옵션별 XLSX·상품 이미지 첨부 목록에 반영한다. 수동 옵션별 지정·명시적 공란은 우선하며, 사용하지 않는 사이즈표는 공란을 유지한다. 최대 5장, 중복·외부 소유 이미지 거절, 교체된 사진은 원본 보관하면서 최종 첨부에서 제외한다. 항목이 없는 과거 양식이나 유사한 이름의 다른 항목을 임의로 연결하지 않는다.

## 검증

- 서로 겹치지 않는 21개 테스트 파일의 240개 검사 통과: 기본설정 23, 이미지 요청·검수·역할·견적 99, 사이즈표·공식 항목·XLSX 회귀 118.
- 양사 격리 시험 데이터로 실제 API·SQLite·R2 모형·XLSX/ZIP을 검증했다. 유료 이미지 공급자는 합성 PNG 응답으로 대체하여 실제 과금이나 외부 이미지 요청을 하지 않았다.
- 지정된 기존 Chrome에서 격리한 실제 React 편집기로 이미지 4·5를 사이즈표로 저장했다. 7단계의 6개 옵션과 XLSX 6개 행, 파일명·SHA를 가진 첨부 목록에 모두 반영되었다. 원문·옵션·가격·원본 파일·표시사항은 유지되며 외부 요청과 신규 접수는 0건이다.
- 기록된 유앤채 69900 Single v188과 공식 2624 Excel v191 원본에서 사이즈차트 열 AB9~AB14의 두 파일명과 첨부 SHA·옵션별 참조를 확인했다. 실제 최신 와이홉 원본 또는 Hub 접수 증명은 아니다.
- 카피라이팅 변경 전 신규 초기 8개 중 6개 실패, 생성 이미지 검수 변경 전 양사 2개 실패, 사이즈표 변경 전 6개 옵션과 XLSX 셀·전송 첨부 누락 증거를 보관했다.
- 기존 역할 테스트의 모듈 로더와 문구 정리 테스트의 R2 본문 스트림을 실제 구현에 맞춰 보완했다. 검증 조건을 완화하거나 실제 이미지 적용 검사를 제거하지 않았다.
- 타입 오류 0, 린트 오류 0. 기존 경고 8개 유지. 운영 빌드는 sourceflow/sourceflow-db/ASSETS와 18개 기존 마이그레이션, 발행된 확장 패키지를 유지한다.

## 범위와 남은 검수

무료 OCR·Google 이미지 번역은 원문 의미를 번역하는 기존 경로를 유지한다. 이번 카피라이팅 연결은 원본 이미지 AI 가공 경로이며, 무료 번역만으로 동일한 AI 판매 카피가 생성된다고 표시하지 않는다. Couplus 서버 내부의 토글 처리와 실제 모델 출력 품질까지 일치한다고 입증한 것은 아니다.

양사 테스트는 동일하게 기록한 카테고리 계약을 격리하여 사용한 검증이며 모든 회사·모든 카테고리의 실제 최신 양식을 조회한 결과가 아니다. 기존 실상품·복구 대기열·Couplus 작업 데이터·계정별 기본설정을 수정하거나 전송하지 않는다. 실상품 신규 1688 수집부터 Supplier Hub 신규 접수·SKU 확인까지의 최종 실전 검수는 별도 확인이 남아 있다.
