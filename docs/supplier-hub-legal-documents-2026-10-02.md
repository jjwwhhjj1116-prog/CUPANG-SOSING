# 법적 필수서류 원본과 견적서 전송 연결

기존 앱 전송은 법적 서류 ‘해당없음’만 허용했다. 인증서·증빙 원본이 필요한 상품도 사용자가 직접 검토한 자료를 같은 견적 패키지와 함께 전달하도록 보완했다. 인증서의 진위·법적 적합성을 판정하거나 AI로 인증서를 생성하지 않는다.

## 확인한 화면 계약과 근거의 범위

- 공식 공개 화면: https://supplier.coupang.com/qvt/registration
- 인증 없는 공개 프런트엔드 `/qvt/resources/20261001171235/dist/main.js`: 7,139,840바이트, SHA-256 `946350c602452505d1ce84ddeaf99a81991980033a8065d71b5b2da21cf23862`. 550에서 확보한 로컬 근거를 읽었으며, 공급자 코드를 실행하거나 저장소에 복사하지 않았다.
- 화면 제목 ‘상품 개별법령에 따른 필수 서류’, `kcFileUpload` 해당 여부, `kcFiles` 첨부 그룹, 해당함일 때 파일 입력이 표시되는 조건을 확인했다. 전송용 비공개 API를 호출하거나 URL을 추측하지 않았다.
- 기존 실제 화면의 읽기 기록 `supplier-hub-legal-selection-2026-09-28.json`에는 해당없음 라디오 `undefined-N`, 두 선택지와 한 개의 파일 입력이 있다. 해당함 `undefined-Y`는 공개 컴포넌트와 쌍 ID에 따른 구현이며 이번에 로그인한 실제 화면에서 다시 관찰한 증거는 아니다. 실행 시 ID만 믿지 않고 정확한 표시 문구·구역 제목·고유 입력·회사코드를 함께 확인한다.
- 별도 `MandatoryDocumentForm` 같은 카테고리별 추가 서류 영역은 이번에 지원·검증했다고 주장하지 않는다. 그 영역의 필요 서류와 최종 접수는 실제 계정에서 대조해야 한다.

## 저장·검토·전송

1. 견적서 단계에서 원본 목록을 불러오고 해당함/해당없음을 선택한다. PDF·PNG·JPEG 원본은 회원과 상품에 묶인 인증 API에서 저장·다운로드한다. 파일당 5MiB, 10개, 합계 8MiB는 앱의 제한이며 공식 허용 한도로 보고하지 않는다.
2. 기존 SEO·가격·이미지·표시사항·수동 수정·공란을 보존하고 revision으로 저장 충돌을 확인한다. 다른 편집이 먼저 저장되면 새 첨부의 미등록 객체만 제거한다. DB 응답이 불확실하면 이미 커밋됐을 수 있는 원본은 보존한다. 첨부 제외는 참조만 제외하고 원본을 삭제하지 않는다.
3. 원본 SHA-256와 크기를 검증해 `documents/legal-001.pdf` 등의 ZIP 항목과 전송 계획에 연결한다. 공개 이미지 URL로 발행하지 않는다. 해당함인데 파일이 없으면 견적 검토 오류로 표시한다. 서류 편집은 기존 견적 지문과 검토를 무효화한다.
4. 직접 전송은 가격/연락처 동의와 해당 여부를 명시적으로 검토한 값만 전달한다. 해당함 전송에는 확장 0.2.38의 서류 기능을 요구한다. 해당없음과 해당함을 동시에 선택하거나 패키지와 다른 선택을 하면 파일을 보내지 않는다.
5. 같은 Chrome 창의 회사코드를 확인하고 기존 작업 폼/첨부를 보호한 뒤, 해당함 라디오와 고유 서류 입력에 원본을 전달한다. 파일명이 해당 서류 구역에 표시돼야 동의와 파일 검증 버튼을 실행한다. 기존 회사·상품·카테고리·저장본·접수 기록 확인과 중복 전송 방지는 유지한다.

## 검증과 남은 실연결

두 승인 회사의 실제 함수·API·임시 SQLite, 기록된 813724060928 상품 자료와 합성 AI/이미지/인증/견적 양식/PDF/Hub DOM을 사용해 6옵션 초안 → 수동 수정 → 원본 보관 → 견적 ZIP → 확장 파일 전달 → 선택/동의 → 검증 요청을 검사했다. 파일 변조, 이전 지문, 잘못된 회사/상품 경로, 동시 편집, DB 응답 유실, 기존 폼 보존, 파일 표시 누락, 재전송도 검사한다.

합성 PDF는 인증서가 아니며 합성 양식/DOM은 실제 카테고리·접수 증거가 아니다. 실제 Chrome과 기존 Couplus 작업 상품을 수정하지 않았다. 운영 로그인 상태에서의 실제 서류 업로드와 두 회사의 최종 접수번호/SKU 대조는 남아 있다. 전체 카테고리 복제·최종 접수 완료·추정 완료율로 보고하지 않는다.
