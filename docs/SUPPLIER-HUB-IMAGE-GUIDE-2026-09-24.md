# Supplier Hub 이미지 크기 안내 대조

## 확인

2026-09-24 로그인된 Chrome의 [대량 상품 등록](https://supplier.coupang.com/qvt/registration)에서 ‘상품 이미지 준비를 도와드릴게요’를 펼쳐 읽었다.

- 대표 이미지: 1,000 × 1,000px 이상 권장.
- 상세 이미지: 개당 가로 780px, 세로 1,500px 이내라는 안내.
- 픽셀 깨짐·노이즈 없는 고해상도 이미지 요구.
- 이미지 파일명은 견적서의 파일명과 일치해야 함.
- 대표·상세 이미지가 동일하면 반려로 등록이 지연될 수 있음.
- HTML 견적서 이미지의 GIF·PSD·PDF·동영상은 지원 불가.
- 제품 필수 표시사항 이미지 별도 첨부 요구.

이번 관찰에서는 안내 펼치기와 DOM 읽기만 수행했다. 파일 업로드, 약관 동의, 파일 검증, 등록은 실행하지 않았다.

## 구현

업로드 API와 수집 이미지 저장 경로에서 PNG·JPEG·GIF·WebP 파일 헤더의 픽셀 크기를 R2 메타데이터로 기록한다. 견적 검사에서는 포함된 최종 행의 대표·상세 이미지 역할에 맞춰 안내와 비교한다. 대표 이미지 권장 크기 미달, 상세 이미지 안내 불일치, 크기 기록 누락은 ‘확인 필요’이며 임의의 등록 불가 판정으로 바꾸지 않는다. 기존 파일·사용자 편집값은 유지한다.

## 추정 및 미확인

안내 문구를 수치 비교로 옮긴 것이며 Supplier Hub 서버의 모든 허용 규칙을 확인한 것은 아니다. 헤더의 크기만 읽으므로 파일 전체 디코딩, EXIF 회전 반영, 픽셀 깨짐·노이즈·화질 또는 실제 접수를 검증하지 않는다. AVIF 등 미지원 크기 파싱 및 기존 파일은 확인 필요로 남긴다. 인증·물류의 카테고리별 기준과 쿠플러스 내부 자동 편집 규칙은 이번 단계에서 확인하지 않았다.
