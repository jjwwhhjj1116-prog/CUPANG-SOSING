# Step 627 — official category connection and reviewed SEO inputs

Selecting an existing Supplier Hub category whose profile had no workbook previously continued with `template: null`. The free translation path also exposed brand, feature and target inputs without applying them to its translated title or tags. This release closes those two concrete gaps in category selection → URL intake → editable SEO → quotation output.

## Category behavior

- An explicit live leaf selection prepares its exact current company, display category code, complete path, Single schema, official Excel bytes and compiled mappings before URL intake. An existing verified Hub profile with no workbook follows the same path after resolving every saved ancestor.
- The official connection is a new profile. Existing profiles, captured collection context, working products and saved intake drafts are not migrated or overwritten. Existing custom workbooks and mappings retain their original path. A saved manual code without Hub evidence retains its manual connection path.
- A response must acknowledge the new profile identity, revision one, exact prepared workbook/mappings, current owner/company and selected schema/code/path. Failed or changed proof keeps the current input and allows retry. A subsequent selection can reuse the unique completed official profile; multiple custom connections remain an explicit choice.
- The existing step-seven action for intentionally preparing a working profile's official workbook remains available. This release does not silently run it on saved work.

## SEO behavior

- The visible Couplus SEO form was inspected read-only: brand, product features, target keywords, generated title/tags, option names and Save. No existing product was edited, regenerated, deleted or transmitted. Private screenshot and DOM evidence are retained under outputs.
- For the requested free Google text-translation mode, provider output remains the translated source. A separate editable composition uses the owner's brand, short features and targets. It is presented with the original translation for review before saving; it is not represented as Gemini generation or an equivalent model result.
- Long feature/specification notes remain intact. Users choose a short title rather than truncating the notes into an invalid product name. Titles are at most 100 characters; target tags obey the existing 20-character item and 150-character total limits. Invalid targets are not silently shortened. Valid targets take priority; excluded translated-title tags are shown.
- Saved titles, tags and explicit blanks remain protected by default, including titles stored by the initial URL intake. Users can explicitly select title and/or tag replacement and review the exact before/after values. Only an existing enabled SEO-to-label name link follows the reviewed title; other label/source/certification facts are preserved.
- All input strings, exact whitespace and replacement choices belong to the preview fingerprint. Changed input invalidates the old application proof. Composition is limited to the ordinary completed Google draft; options-only, option-retry and SEO-retry contracts keep their existing behavior. Translation-only review remains available if the composition is disabled.
- Preparation and application retain the existing content/option/product/source transaction guards. Captured company identity is checked even for an ordinary job that omits category metadata; a legacy manual product without captured source remains supported. During preview or application, the parent inputs and new-request actions are locked. The source job, provider result, original SKU/cost and independent manual option/HTML values are not rewritten.
