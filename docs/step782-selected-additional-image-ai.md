# Step782 — 선택 추가이미지 AI 처리와 최종 견적 반영

쿠플러스의 추가이미지 편집에는 현재 선택한 사진을 AI로 처리한 뒤 해당 위치에 적용하는 흐름이 있다. 기존 대표이미지 AI 연결을 추가이미지에도 연결했다. 원본·결과를 검토하고 명시적으로 적용하면 선택 옵션의 해당 추가이미지 한 장만 바뀐다. 무료 번역과 직접 편집은 그대로 사용할 수 있다.

- 이번 범위는 선택 사진의 처리 진입·결과 검토·한 위치 적용이다. 공급자 자동 실행이나 생성 품질, 모든 화면의 완전한 동등성을 검증했다는 의미는 아니다. 기존 비용 검토·승인·실행 계약을 유지했다.

## 구현

- 저장된 큰 미리보기에서 AI 처리를 연다. 현재 회사·상품·옵션·카테고리·버전·원래 목록·선택 위치를 고정한다. 화면 전환이나 옛 응답으로 다른 사진을 수정할 수 없다.
- 결과의 소유권·완료 상태·원본·PNG 메타데이터·바이트 해시와 상품 이미지 목록의 정확한 한 파일 추가를 확인한다. 기존 순서를 보존하며 선택 위치만 교체하고 같은 Supplier Hub 입력에 연결된 견적 필드를 함께 갱신한다.
- 공통 이미지, 다른 옵션, 대표이미지, 상세이미지·HTML, 원문과 기존 파일을 보존한다. 저장 응답이 불확실하면 같은 저장을 반복하지 않고 읽기 조회로 확인한다.
- 독립 검수에서 정상 기본 프로필 요청 `profileId:null`을 거절하던 P2를 발견해 수정했다. 명시 프로필 불일치 거절과 실제 응답의 카테고리·프로필 비교는 유지한다.
- 브라우저에서 결과 추가로 상품 버전이 바뀌자 결과 패널이 접히는 문제도 수정했다. 같은 현재 대상의 완료 결과는 적용할 때까지 계속 볼 수 있다.
- 공급자 설정이 없거나 확인 중이면 생성 처리만 비활성화한다. 운영 이미지 공급자의 키·모델은 변경하지 않았다.
