# 헬스보호대 견적 대조 (2026-09-23~24)

## 확인

- 같은 Chrome 연결에서 쿠플러스 AI상품등록과 Supplier Hub 개별등록에 로그인된 화면을 읽었다. 설정 저장, AI 실행, 운영 전송은 하지 않았다.
- 쿠플러스 기본설정에 AI 서버 자동 처리(이미지 번역·SEO·등록정보 생성) 안내가 있다. 현재 계정의 비노출속성 자동 생성은 꺼져 있다. 이미지 번역·카피라이트 추가는 켜져 있고 누끼 자동적용·번들링은 꺼져 있다. 이는 현재 계정 설정이며 서비스 전체의 초기값은 아니다.
- 상품 260923003001의 옵션 5개 중 첫 옵션의 견적 대기 버튼을 열었다. 원문 구매 링크는 https://detail.1688.com/offer/1043524119452.html 이며 1688 페이지 자체에 접근하지 않았다.
- 경로: 스포츠/레져 > 헬스/요가 > 헬스기구/용품 > 헬스보호대 (81452).
- 노출 속성은 색상/수량/사이즈, 비노출 속성은 사용부위·패션잡화 사이즈·잠금/고정방식·구성·보호대 사용대상·보호대/교정용품 용도·착용방향·GTIN·Parent Manufacturer Part Number·Manufacturer Part Number의 10개다.
- 상품고시 12개 및 비노출 선택지 전체는 함께 저장한 DOM 기록과 구현 파일에 수록했다. 이 화면에는 KCS 인증번호가 없다.
- 모델명·대표/추가 이미지·포장 무게/사이즈는 공란이다. 표시된 해당사항없음/과세/0 등이 언제 어떤 경로로 입력됐는지는 화면만으로 확인되지 않는다.
- 기본설정의 제조사·거래타입·수입여부·A/S 연락처·박스수량과 견적 값이 일치한다. 첫 옵션 가격은 원가5.5 CNY, 공급가4930, 판매가8220, MSRP10690이다.

## 추정

- 기본설정과 앞 단계의 제목·태그·가격·상세이미지를 조합하고 카테고리별 속성/고시를 구성하는 것으로 보인다. 입력 이력과 서버 코드를 읽은 결과는 아니다.
- 비노출속성 자동 생성 OFF가 다수 미작성 속성과 관련 있을 수 있지만, 설정 ON/OFF 비교나 AI 실행을 하지 않아 원인으로 확정하지 않는다.

## 미확인

- Supplier Hub에서 81452 코드와 세부 선택값의 전송 규격을 독립적으로 검증하지 못했다. 이번 Hub의 바둑 검색에도 최근 카테고리만 표시됐다. 공식 규격이 없다는 뜻은 아니다.
- 공식 Excel, 전체 분류, 자동 기본값의 발생 시점, 실제 수집·번역 호출·등록 접수는 미확인이다.
- Couplus 화면의 등록완료 표시는 Hub 접수 응답을 직접 확인한 근거가 아니다.

## 구현

- 카테고리 선택에 81452와 전체 경로를 추가하고 Couplus 관찰 코드로 표시한다. 공식 검증 상태를 부여하지 않는다.
- 전용 필드/선택지와 고시를 연결했다. 기존 SEO/옵션수량/가격/이미지/표시사항 연결과 수동값 우선순위를 사용한다. 의료용 여부·KC 정보는 상품명에서 추정하지 않는다.
- 전용 필드의 Excel 매핑을 제공하며 다른 카테고리에서 사용하면 거절한다. 노출 색상과 고시 색상처럼 중복되는 제목은 자동 연결하지 않고 수동 선택을 요구한다.
- 저장 사례의 해당사항없음을 다른 상품의 인증·원산지·물류 기본값으로 복사하지 않는다. 실제 기본값을 더 대조해야 한다.
