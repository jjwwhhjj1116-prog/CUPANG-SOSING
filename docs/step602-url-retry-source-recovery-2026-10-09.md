# URL 재시도의 상세 원문 보완과 초안 연결

첫 수집이 SKU 정보만 저장한 상태에서 Chrome 보완을 읽지 못하면, 이후 상품 대기열의 재시도는 이미 받은 원문이라는 이유로 보완 수집을 건너뛰었다. 이 때문에 Chrome에서 상세정보를 읽을 수 있게 되어도 설명·상품 속성·상세 이미지를 추가하지 못했다.

재시도는 같은 작업에 저장된 원문과 수신 시각을 확인하고, 보완 가능한 원문일 때 Chrome 보완을 이어서 받는다. 기존 상품이 있으면 해당 상품·작업·URL 연결과 현재 상품 버전을 확인해 보완 요청에 전달한다. 최초 수신 기록은 보존하며 기존 보완 API의 추가 저장과 버전 검사 규칙을 사용한다. 이미 보완한 원문을 다시 수집하지 않는다.

기존 상품의 원문을 보완한 실행에서는 과거 번역 결과를 다시 반영하거나 Google를 호출하지 않는다. 수동 상품명·공란·표시사항·이미지 선택·구성 수량·제외 옵션·가격·번역 이력을 유지한다. 새 원문은 1단계에서 전체 원문으로 검토한 번역 요청을 준비할 수 있다. 상품 생성 전에 보완한 새 수집 요청은 기존 SEO 초안 작성 경로를 사용한다.

다음 재시도에서도 오래된 완료 번역을 새 원문의 번역 완료로 취급하지 않도록, 완료된 최초 작업의 상품명·설명·수집 연결·카테고리·참고 정보·상품 속성을 현재 유효 원문과 대조한다. 옵션 편집값은 이 대조에서 제외한다. 원문이 추가되거나 변경되면 기존 결과를 읽기 전용으로 반환하고 실행·미리보기·재적용 전에 전체 원문 검토로 연결한다. 처음부터 보완 원문으로 작성한 초안과 옵션만 수정한 경우의 정상 재사용은 유지한다.

## 검수

수정 전에 저장 원문의 재시도가 Chrome 보완을 호출하지 않는 경우와, 보완 후 과거 초안을 재사용할 때 새 원문을 완료로 판단하는 경우를 오프라인 응답으로 재현했다. 수정 후 수집·보완·취소·초안 생성·번역·옵션·적용·XLSX 연결 회귀검사 133개가 통과했다. 기록된 상품 예시는 속성 24개와 이미지 15개를 추가하면서 최초 기록·수동 수정값·옵션·가격·번역 이력을 보존한다. 추가 Google 호출 없이 보완하며 재시도에도 보완 이력은 하나로 유지한다.

타입 오류는 없고 정적 검사는 오류 0개와 기존 경고 8개였다. 운영 빌드, 마이그레이션 17개 및 다운로드 확장 0.2.57·0.2.58의 파일·바이트·해시를 확인했다. 확장 코드나 패키지는 변경하지 않았다.

같은 Chrome에서 쿠플러스 기본설정과 상품추가를 읽기 전용으로 대조했다. 확장 새로고침 후 현재 Supplier Hub 회사와 일치하는 유앤채 앱 계정에서 최상위 분류 16개 및 선글라스의 하위 경로를 확인했다. 최종 코드 69900 선택은 회사의 상세 양식 75개 항목과 URL 입력 행으로 연결된다. 카테고리 설정 선택 외에 상품 수집·생성·번역·저장·전송은 실행하지 않았다. 기존 URL 행의 입력은 보존하고 추가한 빈 검수 행만 정리했다. 쿠플러스의 빈 검수 행도 정리했으며 기존 등록 상품은 수정하지 않았다.

이 카테고리의 상세 입력 양식은 연결됐지만 원본 Excel 파일 연결은 완료되지 않았다. 모든 카테고리의 쿠플러스 기본값 동등성, 신규 1688 수집, 단품 포장 실측값, 원본 Excel 및 실제 Supplier Hub 신규 최종 접수 검수는 남아 있다. 이번 검사 통과를 전체 개발 또는 실제 접수 완료로 표시하지 않는다. 비공개 검수 자료는 `outputs/step602-*`에 보관한다.
