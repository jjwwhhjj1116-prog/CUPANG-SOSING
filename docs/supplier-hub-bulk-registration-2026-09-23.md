# Supplier Hub 대량 등록 화면 관찰 (2026-09-23)

출처: 로그인된 Chrome, https://supplier.coupang.com/qvt/registration 의 표시된 DOM. 파일 업로드·약관 동의·검증·등록은 실행하지 않았다.

## 확인
- 홈의 대량 상품 등록 링크는 별도 탭으로 열린다. 로그인 세션이 유효했다.
- 최신 견적서 Excel 다운로드 버튼, 견적서 업로드, 상품 이미지 업로드, 제품 필수 표시사항 업로드, 법적 필수서류 업로드 영역이 별도로 있다.
- 상품 이미지 파일명은 견적서의 이미지 파일명과 일치해야 한다고 안내한다.
- 대표/상세에 동일 이미지를 첨부하면 반려가 발생할 수 있다고 안내한다.
- 제품 필수 표시사항(라벨 또는 도안 이미지)은 필수 첨부 안내가 있다.
- 파일 검증하기 버튼과 검증 진행상태 확인하기 버튼이 있다. 입력 전 파일 검증 버튼은 비활성화였다.
- 법적 서류 해당 여부, 로켓설치 여부, 가격 데이터 및 라벨 연락처 관련 동의가 존재한다. 값을 변경하지 않았다.

## 추정
- Excel 생성 외에도 파일명 일치, 별도 첨부, 검증 결과 추적이 전송 adapter에 필요하다. 구현 전에 실제 요청/응답과 접수 결과를 추가로 관찰해야 한다.

## 미확인
- 최신 Excel 바이너리/시트 규격, 업로드 API 계약, 검증 이후 등록 절차/접수번호.
- 쿠플러스가 대량 등록과 개별 등록 중 어느 경로를 사용하는지.
- 모든 카테고리 기본값 및 해당 상품의 인증/법적 표시 적합성.

이번 코드 반영은 등록 전 검사에 라벨 누락 오류와 대표/상세 동일 파일 검토 항목을 추가한 것이다. 이미지 내용 자체 비교나 실제 업로드 구현은 아니다.
