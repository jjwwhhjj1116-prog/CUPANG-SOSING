# 공식 대량 견적서 생성 관찰 — 2026-09-24

출처: 로그인된 기존 Chrome의 https://supplier.coupang.com/qvt/registration 표시 DOM.

## 확인
- 최신 견적서 파일 다운로드 → 견적서 파일 다운로드 모달.
- 상품명/칸 카테고리 아이디 검색 탭, 최대6개 분류 선택 안내.
- 코드80719 검색 시 이번 관찰에서는 결과가 나타나지 않았다. 코드 무효의 증거는 아니다.
- 트리에서 주방용품 → 주방수납/잡화 → 건조대/진열대/정리대 → 주방수납바구니/바스켓을 선택했다. 개별등록에서 관찰한 주방수납/정리 경로와 표시 구조가 다르다.
- 선택된 카테고리의 견적서 다운로드 클릭 후 성공/Generating quotation file. The file will be downloaded soon. 안내가 표시됐다.
- 파일 업로드/검증/등록/약관 동의는 실행하지 않았다.

## 추정
다운로드용 분류와 개별등록용 분류는 별도의 표시 체계를 사용할 수 있다. 이름이 같다는 이유만으로 코드·Excel 시트 대응을 확정하지 않는다.

## 미확인
다운로드된 파일명/파일 바이트/시트/열 구조/다운로드 완료는 미확인이다. 생성 성공 안내를 파일 확보나 공식 양식 검증 완료로 보고하지 않는다. 브라우저 정책으로 제한됐던 다운로드 내부 페이지나 외부 경로를 우회하지 않았다.

## 코드 반영
Excel 가져오기에서 제목·공급가를 포함한3개 이상의 고유한 정확한 열 이름을 대조해 유일한 최다일치 후보가 있을 때 작성 시트·머리글 행을 추천한다. 중복/모호 열 또는 동률 후보는 자동 확정하지 않는다. 공식 분류 검증이 아니라 편집 초안이며 수동 선택을 유지한다. 기존 저장 프로필을 자동 변경하지 않는다.
