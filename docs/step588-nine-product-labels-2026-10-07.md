# Step 588 — 6단계 제품 한글 표시사항 9항목

기준 커밋: `cf81d5b4a2eda211120e5232c3d7362d403b8fdb` (step587).

## 구현 범위

- 이전 실제 Chrome 참조에서 확인한 제품명, 제조원, 수입 및 판매원, 제조국, 내용량, 원료명 및 성분명(재질), 상품 유형, 사용 시 주의사항, 사용 기준을 같은 순서로 6단계에 배치했다. 7단계 카테고리별 상품고시와 독립된 제품 표시사항이다.
- 상품 공통값과 옵션별 수정값을 독립 저장한다. 직접 비운 문자열은 공란으로 유지하고, 복원은 해당 옵션의 공통·자동값을 사용한다. 제품명은 저장된 최종 SEO 상품명에서 가져오며, 기존 콘텐츠에 직접 작성한 제품명이 있으면 이를 존중한다. 회원별 설정과 해당 상품의 수집 시점 설정을 기존 견적과 같은 원천으로 사용한다.
- 확인되지 않은 내용량·재질·상품 유형·사용 기준을 수량이나 다른 법적 정보에서 추정하지 않는다. 기존 공통 표시사항·이미지 번역·확장 항목은 펼침 영역에 유지한다.
- 옵션 편집기는 다른 단계에서도 같은 인스턴스를 유지한다. 미저장 입력을 보존하고 닫기·견적 진입 검사에서 원천 단계가 ‘표시사항’으로 표시된다.
- 저장된 9항목을 흰색 배경, 굵은 항목명, 문단 형태의 800px PNG로 생성한다. 표·제목·검토 문구를 덧붙이지 않는다. 긴 문장은 줄바꿈하며 최대 높이를 넘으면 잘라내지 않고 생성을 중단한다.
- 만든 PNG는 저장된 업로드 식별값으로 다시 찾을 수 있다. 카테고리·상품·옵션·9항목·견적 버전을 재검사한 뒤 상품 파일 목록과 해당 옵션의 정확한 라벨 이미지 필드에 연결한다. 공통 연결과 다른 옵션 연결은 분리하며 기존 첨부를 임의로 지우지 않는다.
- 정보 저장만으로 이미 붙어 있는 PNG의 픽셀을 바꾸지는 않는다. 사용자가 수정한 저장본을 다시 생성해 연결한다. 연결 성공 안내는 같은 저장본의 자동 재조회에서도 유지하고 실제 원천이 바뀌면 제거한다.

## 저장·검수 경계

`product_labels`는 별도 owner-scoped 테이블이며 신규 migration `0016_product_labels.sql`은 CREATE TABLE/INDEX만 포함한다. 제품 표시사항 저장은 상품 콘텐츠, 카테고리 고시 또는 다른 옵션 견적을 다시 작성하지 않는다. 저장 버전·회사/카테고리·콘텐츠·옵션·견적·설정·수집 원천을 함께 확인하며 삭제된 상품과 다른 소유자의 데이터는 저장 대상이 되지 않는다.

로컬 파이프라인 검사는 실제 API 핸들러와 임시 SQLite, 합성 PNG 및 XLSX/ZIP 양식으로 두 회사의 옵션별 연결을 확인한다. 이 결과를 실제 Supplier Hub 접수 성공이나 모든 카테고리 검수 완료로 해석하지 않는다.

## 실제 운영 웹 검수

기존 와이홉 Chrome의 앱 탭에서 저장된 작업 공간을 닫은 뒤 새 배포를 갱신했다. 다른 이전 미저장 탭은 그대로 두었다. 로그인 유지와 지정 검증 상품의 6개 옵션·원본 URL·선택 카테고리를 확인했다.

검증 상품 첫 옵션의 6단계에서 9항목과 저장된 SEO 제품명·제조원·수입판매원을 확인했다. 제품명을 비우면 저장 버튼이 활성화되고 PNG 생성은 비활성화된다. 이 상태에서 7단계 진입 시 ‘표시사항에 저장하지 않은 입력’ 안내를 확인했다. 입력 취소로 원래 이름과 저장 버튼 비활성 상태를 복원했고 이 검수용 공란을 저장하지 않았다.

이후 저장된 9항목으로 실제 브라우저 PNG를 생성하고, 검증 상품의 선택 옵션에 업로드·연결했다. 성공 안내가 표시되고 7단계에서 기존 라벨과 신규 라벨 총 2개 참조 및 새 후보 이미지의 라벨 선택 상태를 확인했다. 상품 파일 후보는 25개에서 26개가 됐다. 다시 6단계로 돌아와도 연결 완료 안내가 유지됐다. 다른 옵션의 연결과 공통 라벨은 변경 대상으로 선택하지 않았다.

실제 이미지 픽셀 캡처는 Page.captureScreenshot의 5초 타임아웃으로 파일을 보관하지 못했다. 견적서의 새 후보 썸네일은 화면 밖 lazy-load 상태여서 해당 썸네일의 원본 크기로 저장 파일의 픽셀을 검수했다고 주장하지 않는다. 생성된 PNG 미리보기·업로드 성공·견적 참조 연결의 UI 검수와 합성 캔버스 조판 검사를 구분한다.

이 검수는 YOOFAM PLUS의 전용 검증 상품에 PNG 1개를 추가·연결했다. 쿠플러스 기존 작업 상품 및 Supplier Hub 상품은 수정하지 않았고 최종 등록 전송은 실행하지 않았다. 포장 무게·규격 필수값은 비어 있는 상태를 유지했다.
