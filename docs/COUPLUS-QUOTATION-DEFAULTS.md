# 카테고리별 견적 기본값 대조

## 확인한 범위

- 80719 주방수납바구니/바스켓: 사용자가 제공한 쿠플러스 화면15~23. 과세, 바코드 생성 요청, 유통기간0, 취급주의 해당사항없음, 노출/비노출 속성·인증·고시의 해당사항없음 표시를 확인했다. 화면에 있던 브랜드/제조사/박스 수량은 계정 기본설정 값으로 취급한다.
- 80719 Supplier Hub 선택 항목의 해당사항없음은 빈 문자열 저장값이다. 화면 표시 문자열을 선택값에 그대로 넣으면 호환되지 않는다. 선택 목록의 실제 값을 사용하고 출처를 couplus-default로 표시한다.
- 77442 완구/취미 > 보드게임 > 바둑/체스/윷놀이 > 바둑 > 바둑알+바둑판: 2026-09-23 로그인된 쿠플러스 기존 상품 견적 조회. 노출 속성은 색상/수량, 고시는 품명 및 모델명/인증·허가 사항/제조국(원산지)/제조자(수입자)/소비자상담 전화번호. 80719와 다르다. 등록완료된 상품의 최종값이므로 자동 생성·수동 수정 여부는 미확인이다. 해당 상품의 포장무게100, 포장치수100*100*100을 카테고리 기본값으로 사용하지 않는다.

## 구현 우선순위

옵션별 수동 수정 > 공통 수동 수정 > 저장된 단계별 실제 값 > 해당 카테고리에서 관찰한 양식 기본값 > 공란.

80719에만 관찰 기본값을 적용한다. 다른 카테고리로 일반화하지 않는다. SEO 상품명/키워드, 옵션 가격, 대표/추가/상세/라벨 이미지 참조, 표시사항 재질/치수/제조국 등은 기존 저장 자료 연결을 유지한다. 수동으로 비워둔 값도 기본값으로 덮어쓰지 않는다. 인증/과세 등의 기본값은 상품 사실 확인이 아닌 양식 초안이며 검토 표시를 유지한다.

모델명·포장 무게·포장 치수·이미지 파일을 임의로 생성하지 않는다. 이미지 URL 공개화와 실제 Supplier Hub 접수 검증은 별도 미완료다.

## 남은 확인

전체 카테고리별 초기 견적서와 작성 후 견적서 차이, Supplier Hub 공식 Excel 입력열/선택값, 77442 등 추가 카테고리의 공식 대조, 모든 단계 변경 후 실제 파일·전송까지 일치 검증. 현재 모든 카테고리의 기본값을 복제했다고 볼 수 없다.
