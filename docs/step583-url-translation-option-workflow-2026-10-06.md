## 요청한 무료 번역 방식 유지

`google-free-translation.ts`는 변경하지 않았다. 동일 `https://translate.googleapis.com/translate_a/single`, `client=gtx`, `sl`, `tl`, `dt=t`, `q` GET,5,000자 제한, 시간 제한 및 JSON segment 결합/HTML decode를 유지한다. 새 provider·유료 자원·API key·다른 client/domain/IP·자동 재시도는 추가하지 않았다.

상품명을 먼저 번역한 뒤 서로 다른 나머지 텍스트를5,000자 이하 plain text 묶음으로 요청한다. 각 원문에 `[[YFTR000001]]` 형태의 식별자를 붙이고 정확한 ID로 결과를 연결한다. 결과 줄의 순서가 바뀌어도 원문/번역이 섞이지 않는다. 중복·누락·알 수 없는 ID·훼손된 marker는 해당 묶음을 적용하지 않는다. 원문 줄바꿈이나 marker 같은 문자열, 너무 긴 문자열은 개별 요청으로 보존한다. 한 항목만 남은 묶음에는 marker를 붙이지 않는다.

호출은 순차 실행하고49회 subrequest 한도를 유지한다.429/5xx는 이후 요청을 중단한다. 이미 성공한 필드는 부분 초안으로 유지하고 나머지 원문을 보존한다. 기존 한글/Han 검사와 동일 항목의 숫자 근거 검사를 유지한다. marker는 필드 적용·숫자 검사 전에 제거한다.

## 상품·옵션 목록과 편집 연결

1차 상품 목록은 기존14개 데이터 열을 유지한다. 제목·사진·옵션 표시와 단계 셀은 옵션 선택 목록을 먼저 연다. 구매링크는 독립된 원본 URL 새 탭 링크이며, 상품 휴지통은 기존 복원 가능한 삭제 경로를 유지한다. 실제 Hub 접수 상태 표시는 이번 릴리스에서 변경하지 않았다.

옵션 목록은 관찰한12개 데이터 열인 옵션번호, 옵션명, SEO설정, 가격설정, 대표이미지, 추가이미지, 상세이미지, 사이즈표, 한글표시사항, 견적서, 재고/가격, 관리를 표시한다. 체크박스는 별도 열이다. 각 단계는 선택한 옵션 ID와 정확한 편집 단계를 전달한다. 견적서는 선택 옵션의 상품명 필드를 대상으로 연다. 관리 휴지통은 해당 옵션을 선택한 삭제 검토 창을 연다.

옵션 삭제는 진입 자체로 실행하지 않는다. 기존 일괄 도구에서 변경 미리보기 → 적용 → 명시적 저장 경로를 사용하며, 적용 후 되돌리기도 유지한다. 마지막 옵션을 임시로 제거해도 되돌리기 도구가 남는다. 다른 옵션, 원본 파일, 외부 Hub 상품을 삭제하지 않는다. PATCH는 기존 상품 버전과 옵션 리비전을 비교한다.

옵션·콘텐츠·견적 응답의 상품/리비전·가격/이미지 구조를 검사한다. 이미지 존재 여부는 현재 견적 응답의 `imageKeys`로 판단하며, 오래된 부모 상품 목록의 이미지 목록을 기준으로 쓰지 않는다. 원본 미리보기는 대표이미지 설정 완료로 표시하지 않고, 직접 지운 SEO/견적 가격 공란도 자동 계산값으로 덮어 표시하지 않는다.

선택 단계에 들어갈 때는 해당 상품을 `no-store` GET 한 번으로 다시 읽어 소유자·상품 ID를 확인하고 최신 이미지 목록/버전을 편집기에 전달한다. 옵션 목록 닫기·교체·새 상품 열기는 pending GET을 취소하고 늦게 온 응답을 무시한다. 중복 단계/관리 호출은 한 번의 GET만 보낸다. 기존 수집/이력 조회의 늦은 응답도 새 옵션 선택 화면을 덮지 못한다. 미저장 수정, 저장 중, 원문 보완, 업로드/수집의 전역 busy 상태에서는 화면 전환을 막으며 busy ref는 재렌더 전에 동기 갱신한다.

SEO·추가/상세 이미지·표시사항·사이즈표는 현재 상품 공통 자료를 편집한다. 선택 옵션 ID를 전달했다고 이들 자료가 옵션별로 독립 저장되는 모델을 완성한 것은 아니다. 관찰한 쿠플러스의 미사용 사이즈표→SEO 동작과 달리 우리 사이즈표는 실제 기존 옵션·사이즈표 편집기를 연다. 활성 사이즈표와 옵션별 개별 적용 범위의 완전 동등성은 남아 있다.
