# Step 772 — 옵션 축 전달과 견적 검토 연결

## 변경

- DOM 옵션을 수집할 때 명시적으로 관찰한 축 이름과 값을 `axisValues`에 보존한다. 정확한 색상·사이즈 축이 하나일 때만 기존 옵션 번역 경로에 전달한다. 합친 옵션명에서 추정하지 않는다. 기존 v1 자료의 필드 부재와 핑거프린트는 호환된다.
- 수집 원문 검토 ACK는 축의 추가·제거·변경을 허용하지 않는다. 기존 작업 상품을 다시 작성하지 않는다.
- 7단계의 저장 버튼 옆에 ‘견적 검토·전송’을 둔다. 현재 저장 버전의 기존 검토 영역을 열고 이동·초점만 처리한다. 미저장·비활성·충돌·진행 중 상태에서는 진입하지 않는다. 파일 준비·동의·전송은 별도 명시 동작이다.
- 헤더 등록전송과 7단계 내부 전송의 원본 보호 잠금을 부모로 전달한다. 진행 중·응답 미확정·접수 결과 미저장 상태에서 카테고리·원본 편집·새로고침·분할·닫기로 복구 기준을 바꾸지 않도록 한다. 검토 자식에게 자체 잠금을 비활성 상태로 되먹이지 않는다.
- 저장된 정확한 접수 관찰에 따른 닫기 허용과 원본 보호는 분리한다. accepted 중복 방지 예약은 삭제하지 않는다. 긍정적으로 저장하고 예약을 해제한 rejected 경로만 원본 보호를 해제한다.
- 확장 2.1.13과 생성 수집 번들·다운로드 링크를 함께 갱신한다. 기존 권한·호스트·실전송 검증 gate를 유지한다.
