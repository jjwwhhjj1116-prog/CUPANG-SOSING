기존 자체 전체 작업은 이미지 초안·가격 준비 뒤 이미지 화면으로 이동했다. 최초 URL 수집과 상품별 SEO 화면에는 생성 기능이 있었지만, 전체 작업을 재개할 때 미완료 SEO를 확인·생성하는 경계는 없었다. 이 차이를 보완해 ‘작업 개시’에서 SEO 저장본을 먼저 읽고, 미완료 상품의 기존 `SeoWorkspaceGenerator`와 통합 미리보기·적용 기능을 연결했다. 검토 또는 명시적인 나중 검토 결정 뒤 기존 가격→이미지→표시사항 초안→PNG 연결 흐름을 진행한다.

계획·새로 확인은 현재 회원·회사, 저장 원문·카테고리·브랜드와 상품/내용/옵션 버전을 확인하는 GET 작업이다. 이미 번역/생성된 저장값과 수동값·수동 공란은 재생성 대상으로 선택하지 않는다. 부분 미완료 상품의 기존 비수동 번역값은 새 제안과 달라질 수 있으며, 미리보기에서 보여준 뒤 사용자가 통합 저장을 명시할 때만 반영된다. 수동 상품명·태그를 바꾸려면 기존의 교체 체크를 직접 선택해야 한다.

이 재개 화면은 무료 초안 작성 버튼을 사용자가 누르는 방식이다. 원본 전체 작업의 자동 생성·재시도와 완전히 같아졌다고 주장하지 않는다. 자동 공급자 호출·숨은 내용 저장·유료 AI 자동 승인·Supplier Hub 전송을 추가하지 않았다. 이 미완료 SEO 재개 기능과 최초 URL 수집의 자동 SEO 생성은 서로 다른 경계다.

조회·생성·검토 대기·적용 중에는 이전 상품/화면의 콜백으로 이동하거나 저장하지 못하게 했다. 적용 응답이 유실되거나 비정상이면 같은 적용 요청을 다시 보내지 않는다. 현재 저장본 GET으로 값과 버전을 보여준 후 사용자가 나중 검토를 선택할 수 있지만, 이 선택을 이전 저장의 성공 ACK나 SEO 완료로 표시하지 않는다. 구성안을 바꿔 새 하위 화면이 생겨도 미확정 적용 잠금을 우회할 수 없다.

독립 검수는 초기 조회 실패 후 잠금이 풀리지 않는 실제 결함을 재현했다. 현재 owner/product/version/brand/재조회 범위에 묶인 조회 종료 상태를 추가해 실패한 GET은 정상적으로 잠금을 해제하고, 다른 버전의 첫 조회는 계속 잠그도록 수정했다. 실패 로그와 수정 전 SHA를 보존했다. 최초 통합 검사의 기존 탐색 테스트 3건은 새 SEO 결정 대기열을 종료하지 않는 예전 fixture였고, 실제 대기열 경계를 명시적으로 거친 뒤 기존 가격/탐색/지연 응답 단언을 모두 유지했다. 첫 실행 중 추가된 회귀 테스트 때문에 동결 SHA가 달라진 기록도 최종 검사와 분리했다.
