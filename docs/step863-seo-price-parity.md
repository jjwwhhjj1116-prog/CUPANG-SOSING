## 구현

- SEO의 기본 동작을 AI 생성 → 편집 → SEO 설정 저장으로 연결했다. 생성만으로 상품명·태그·옵션을 저장하지 않는다. 회원·상품·원본 revision이 달라진 늦은 결과는 버리고, 저장하지 않은 입력은 생성 결과보다 우선한다. 대상 키워드는 비어 있는 최초 입력에만 선택 카테고리의 끝 항목을 제안한다.
