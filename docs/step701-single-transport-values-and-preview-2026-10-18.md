## 자동 숨김 속성의 전송값

원본은 `productPage.unexposedAttributes`의 초기 값을 `null`로 만든다. 자체 편집 모델은 이를 빈 텍스트와 `couplus-default` 출처로 표현한다. 선택지가 있는 nullable 항목은 이미 `null`로 전달됐지만, 선택지가 없는 `string/null` 자유 텍스트는 일반 문자열 변환을 거쳐 `''`로 전달됐다. 보관 81452 양식의 GTIN·Parent Manufacturer Part Number·Manufacturer Part Number 3개에서 차이를 재현했다. 원본의 정확한 구간·digest·전송 경로와 한계는 `docs/step701-transmission-parity-audit.md`에 기록했다.

정확한 비노출 named-array의 자동 기본 공란이고, 원문 자료형이 정확히 `string/null`이며 선택지가 없는 경우에만 `null`로 복원한다. 이름을 보고 추측하거나 다른 nullable 항목까지 바꾸지 않는다. 수동 공통/옵션 공란, 실제 부품번호 문자열, 공급/번역/옵션 출처, 모델명·노출 속성·법적 고시·다른 배열은 기존 값을 유지한다. 기존 enum 7개와 모호한 선택지·자료형 차단은 그대로다. 편집 UI의 저장 텍스트·provenance와 원본 schema는 변경하지 않는다.

## 전송 시작 전 자료 확인 닫기

기존 화면은 옵션 하나의 자료를 미리 확인하면 session이 남아 자료 재검토·옵션 선택을 계속 잠갔다. 실제 등록 요청을 시작하지 않은 preview 상태에서도 다른 옵션을 확인하려면 전체 편집창을 다시 열어야 했다. 전송 전 자료 확인만 로컬에서 닫아 준비 자료·옵션·보관 이력을 유지하면서 다른 옵션을 선택할 수 있게 했다. 이는 자체 사용성 결함 수정이며 원본 팝업의 모든 동작을 관찰한 동일 구현 증거는 아니다.

현재 session과 렌더 당시 session이 같고, 요청 중이 아니며, 원격 문서 상태·불확실한 응답·접수 저장 대기가 없을 때만 닫는다. 실제 등록 시작 뒤에는 닫지 않으며 원래 요청의 동의·복구·접수 확인을 유지한다. 닫은 후 다른 옵션을 확인하는 동안 이전 버튼 콜백이 새 옵션을 시작하거나 해제하지 않도록, 시작/복구/계속/조회/동의 동작 모두 렌더 당시 session에 묶었다. 이미 생성한 문서나 접수 완료 후 다음 옵션으로 자동 전환하는 기능은 이번 변경에 포함하지 않는다.

신규 UI 검사는 실제 React callback·클라이언트·기존 실제 dispatch preview를 사용한다. API·시계·window bridge는 합성이다. 두 회사×gate false/합성 true의4개 미리보기에서 두 번째 옵션의 별도 패킷을 확인했으며 닫기 자체의 API/bridge 요청은0이다. 옛 닫기·시작 버튼, 진행 중 요청·유실 ACK, 동의 단계, disabled/원문 변경/언마운트 경계도 검사했다. 합성 true 응답은 운영 live gate를 켰다는 뜻이 아니다.
