# 수집 결과 수신 계약 (v1)

인증된 동일 작업공간의 공급원 연결용 API입니다. 현재 실제 1688 공급원은 연결되지 않았습니다. 수신은 데이터 구조 검증이며 공급원 신뢰성·실상품 일치의 독립 검증이 아닙니다. provider 값은 송신자가 제공한 이름입니다.

- POST /api/collection-jobs/{id}/result: JSON, 최대 512KiB. 운영은 검증된 Access 인증 필수. 수집 요청 소유자와 일치해야 합니다.
- GET 같은 경로: receipt 또는 null, productCreated:false. 취소된 요청의 기존 원문도 소유자는 읽을 수 있습니다.
- 동일한 정규화 결과 재전송은 한 건으로 유지합니다. 다른 결과 재전송·취소된 요청은409, 타 소유자/없는 요청404, 내용 오류400, 크기 초과413입니다.
- 원문에는 schemaVersion:1, sourceUrl, provider, collectedAt(UTC), title, description, options, images가 필요합니다. 임의 필드/로그인 토큰/쿠키를 보내지 마세요.
- options: 1~200개, 고유 sku, 원문 name, 양수 unitPriceCny, 정수 minimumOrder≥1, stock은 정수≥0 또는 미확인 null.
- 옵션에 구조화된 원문 `color`, `size`를 선택적으로 보낼 수 있습니다. 각각 최대200자 텍스트이며 미확인은 생략하거나 공란으로 보냅니다. null/숫자/제어문자는 거절합니다. 이름에서 임의로 분리하거나 번역한 값을 원문으로 표시하지 않습니다. 기존 v1 수신 형식과 호환됩니다.
- 상품 반영 시 색상·구매 사이즈는 같은 SKU의 옵션에 수집 출처로 저장하고 원문 화면에서 조회할 수 있습니다. 옵션 편집 화면에서 한국어로 수정할 수 있으며, 색상/사이즈 필드가 있는 견적에 연결합니다. 헬스보호대 색상 고시에도 연결합니다. 견적 수동 수정값이 우선하며, 일반 치수나 포장 크기를 구매 사이즈로 추정하지 않습니다. 수집원 값은 번역 완료를 의미하지 않으며 검토가 필요합니다.
- 옵션별 이미지가 확인된 공급원은 선택 필드 `imageIndex`를 보낼 수 있습니다. `images` 배열의 0부터 시작하는 정수 번호입니다. 미확인은 필드를 생략하며 null/음수/범위 밖 번호는 거절합니다. 여러 SKU가 같은 번호를 참조할 수 있습니다. 기존 v1 자료는 그대로 유효하며 기존 수신 원문을 새 값으로 덮어쓰지 않습니다.
- images: 최대200개, {url,role}. HTTPS alicdn.com 하위 호스트만 허용하며 인증정보·포트·fragment·중복 주소는 거절합니다. role은 main/additional/detail이고 main은 최대1장입니다.
- 가격은 CNY 단가이며 구간 가격 선택이나 SKU 매핑은 공급원 어댑터에서 검증해야 합니다. 자동 번역·SEO·인증값을 원문과 혼합하지 않습니다.

현재 저장 위치는 collection_results이며 요청 당시 category/settings 문맥은 기존 collection_context에 보존됩니다. 수신만으로 상품 생성, 수집완료 표시, 결제, 등록전송을 수행하지 않습니다. 외부 사이트에 접근하지 않는 합성 API/SQLite 테스트를 실수집 성공으로 해석하면 안 됩니다.

## 상품 반영

- POST /api/collection-jobs/{id}/product: 본문 없이 수신 원문을 상품·가격 정책·옵션·콘텐츠로 원자적으로 저장합니다. 동일 작업공간 소유권과 운영 Access 인증이 필요합니다.
- collection_products가 요청과 상품을 일대일 연결합니다. 재시도는 기존 productId를 반환하며 수동 수정값을 덮어쓰지 않습니다. 중간 실패는 전체 롤백됩니다.
- 요청 당시 기본설정으로 가격을 계산하고 원문 제목·설명·SKU·옵션명·단가·최소 주문량을 보존합니다. 원문 재고는 수신 자료에서 조회합니다. 최소 주문량을 번들 수량으로 간주하지 않습니다.
- 상품 반영 후 요청 취소는 차단하여 카테고리 문맥을 보존합니다. 요청의 내부 상태는 awaiting_connector를 유지하며 product_id로 반영 여부를 구분합니다.
- 번역 완료, 이미지 다운로드, 인증값, Supplier Hub 등록 완료를 생성하지 않습니다. 목표가 transmit이어도 이 API는 등록 전송이나 유료 작업을 시작하지 않습니다.
- 이미지 다운로드/R2의 운영 검증과 실제 공급원 인증/실행은 남은 작업입니다. result GET의 productCreated:false는 해당 조회/수신 API 자체가 상품을 생성하지 않는다는 의미이며 반영 상태는 대기열의 product_id에서 확인합니다.

## 원본 이미지 저장

- 해당 이미지 저장 시 `imageIndex`가 일치하는 SKU의 옵션 대표 이미지도 같은 DB 트랜잭션에서 연결합니다. 원본에서 수집한 SKU가 정확히 일치하고, 옵션 이미지가 미작성일 때만 적용합니다. 수동으로 비운 이미지·직접 편집한 SKU·수동/번역/생성 이미지·기존 연결은 보존합니다. 삭제된 옵션을 다시 만들지 않습니다.
- 옵션 revision과 상품 버전을 확인하고 충돌하면 이미지 연결 기록/콘텐츠/옵션을 함께 롤백합니다. 재시도는 기존 완료 기록을 재사용합니다. R2 객체 저장과 D1 트랜잭션은 별도이므로 DB 실패 시 R2에 미연결 원본 객체가 남을 수 있습니다(기존 정책).
- 수집 원문 화면에서 SKU별 원본 이미지 번호와 저장 선택 여부를 표시합니다. 선택에서 제외한 이미지는 저장·연결하지 않습니다. 연결된 파일은 기존 견적 resolver의 옵션 대표 이미지로 사용됩니다. 파일이 자동 번역되거나 Supplier Hub에 전송됐다는 뜻은 아닙니다.

- POST /api/collection-jobs/{id}/images: JSON {index:0}. 요청 소유자·상품 연결·수신 원문을 확인한 후 해당 번호의 이미지만 다운로드한다. 임의 URL을 요청 본문으로 받지 않는다.
- HTTPS Alibaba CDN만 허용, 로그인 쿠키 없이 요청, 리디렉션 거절, 15초 제한, 스트림10MB 제한, PNG/JPEG/WebP/GIF/AVIF 헤더 검사. 현재 검사는 전체 디코딩이나 이미지 번역 검사가 아니다.
- 이미지 내용 SHA-256 기반 비공개 R2 키에 저장한다. collection_images의 요청/번호 고유키로 재시도 시 다운로드와 저장을 생략한다. D1에서 상품 이미지 목록·콘텐츠 역할·반영 기록을 단일 트랜잭션으로 저장한다.
- UI는 수신 순서대로 한 장씩 처리하며 오류 시 중단한다. 재시도는 완료된 항목을 재사용한다. 상품50장, 대표1장/추가·상세 각30장 제한. 수동/번역/가공 역할 선택은 덮어쓰지 않으며 자동 역할 배정이 안 된 파일도 이미지 목록에서 선택할 수 있다.
- R2와 D1 사이 분산 트랜잭션은 없다. R2 저장 후 D1 충돌/실패가 나면 미연결 객체가 남을 수 있다. 사용자 객체를 잘못 삭제하지 않도록 자동 삭제하지 않는다. 같은 내용의 재시도는 같은 키를 사용한다. 미연결 객체 정리 및 운영 사용량 관리가 남아 있다.
- 번역·AI 가공·공개 이미지 URL 생성·Supplier Hub 전송을 이 API에서 실행하지 않는다. 실제 공급원 연결과 실제 외부 이미지/R2 운영 검증은 아직 남아 있다.

## 옵션 속성 번역 검토

- 미번역 옵션 불러오기는 빈 한국어 옵션명과 수집 출처의 색상·사이즈만 대상으로 삼는다. 최대50개는 옵션 행 수가 아니라 요청 항목 합계다. 직접 입력한 속성과 공란은 번역 대상으로 넣지 않는다.
- 연결 키는 기존 option:<ID>와 option-color:<ID>, option-size:<ID>다. 결과 sourceIndex를 검토 원문의 키/값과 대조하며 모델 출력 이름이나 응답 순서로 연결하지 않는다.
- 완료된 동일 상품·버전의 결과만 적용한다. 수집 원문 변경·옵션 삭제·중복 연결·200자를 넘는 속성 번역은 거절한다. 수동 수정/삭제 속성은 유지하며 오류 시 원본 객체를 변경하지 않는다. 실제 저장은 기존 revision/상품 버전 검사를 사용한다.
- 사용자가 검토 후 적용한 변경값은 기존 저장 경로에서 직접 입력 출처로 저장된다. 자동 번역 출처로 저장했다고 주장하지 않는다. 원문 receipt와 견적 수동 공통/옵션값 우선순위는 유지된다.
- 이 연결은 번역 요청 준비와 검토 결과 적용 기능이다. 유료 실행 승인·실제 공급원 연결을 대체하지 않으며 합성 결과 테스트는 실제 번역 성공이 아니다.
