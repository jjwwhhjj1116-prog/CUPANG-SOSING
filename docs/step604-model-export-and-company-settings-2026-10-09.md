# 공식 모델명 출력과 회사별 기본설정 — 604

## 실제 양식에서 확인한 견적서 차단 오류

유앤채의 실제 `69900` Single 원문과 연결한 공식 XLSX로 초안·수정·출력 흐름을 오프라인 검수했다. 6단계에서 수정한 모델명은 Single의 `productPage.modelNumber`와 공식 비노출 `모델명/품번`에 같은 값으로 해석됐고, XLSX 12열에도 정확히 기록됐다. 그런데 출력 연결 검사에서 공통 모델명만 `EXCEL_FIELD_UNMAPPED`로 판정해 전송 준비를 잘못 차단했다.

공통 모델명의 정확한 경로, 비노출 필드의 정확한 경로·이름·이름키·값키·`contentField`, 유일한 대상 필드, 실제 열 매핑을 확인하고 모든 포함 옵션의 두 값이 동일할 때만 출력된 항목으로 인정한다. 값을 자동 변경하거나 매핑을 새로 작성하지 않는다. 포함 옵션의 독립 수정·공란·누락 셀·다른 경로·모호한 대상은 계속 미연결로 처리한다. 직접 공통 모델명에 연결한 기존 설정도 유지한다.

수정 전 검수에서는 공식 12열에 모델명이 들어가 있어도 오류 43개 중 모델명 미연결 오류가 하나 존재했다. 수정 후에는 해당 오류만 사라져 42개가 남았다. 무게·치수·라벨 미첨부와 의도적으로 비운 색상 오류를 성공으로 바꾸지 않았다.

## 실제 회사 설정 대조·저장

같은 Chrome의 Supplier Hub에서 유앤채 `A01526306`, Couplus에서 `yooandchae` 계정을 확인했다. Couplus 기본설정은 읽기만 했으며 기존 등록 상품과 Couplus 설정을 저장·수정하지 않았다.

YOOFAM PLUS 관리자 계정의 유앤채 설정에서 제조사를 `유앤채 협력업체`로 맞추고 통합통관 환율 사용·290원, Couplus에 표시된 이미지 번역 지침, 누끼 설정을 저장했다. 이미 일치하는 공급마진 50%, 쿠팡마진 40%, 최소 공급마진 3,000원, 10원 반올림, MSRP 1.3배, 박스 SKU 50은 유지했다. 일반 환율 350원과 통합통관 환율은 별도로 저장된다. 290원은 이때 확인한 계정 설정값이며 모든 회원의 고정 환율이나 자동 실시간 환율이 아니다.

현재 Couplus 기본설정에 표시된 유앤채 공통 상단 PNG를 원본 그대로 같은 회사의 앱 설정에 업로드하고 상단 이미지 사용을 저장했다. 원본은 1110×1417, 1,685,520바이트이며 SHA-256은 `b6099796bb7a45a1dfa0f13eebbe6f7aa51a337a6c60589938df3d861c8b350f`이다. 하단 이미지 미사용, 이미지 번역·카피라이트 사용, 비노출속성 자동 생성 미사용은 현재 Couplus 화면과 일치한다. 이미지 설정 저장은 실제 상품의 이미지 번역·가공이 실행됐다는 의미가 아니다.

설정을 다시 열어 서버의 저장값과 이미지 연결을 확인했다. 원가 3.6위안의 화면 미리보기는 `(3.6×290+200+100)×1.1`을 원 단위 반올림한 매입가 1,478원에서 공급가 4,480원, 판매가 7,470원, MSRP 9,710원을 계산했다. 미리보기 원가는 저장하지 않는다.

설정 변경은 현재 관리자 작업공간에만 적용했다. 다른 회원의 설정·회사 배정은 변경하지 않았다. 기존 상품·기존 대기열의 URL·특징·키워드·카테고리와 선택 상태는 유지됐다. 배포 후 다시 조회해 기존 입력 행이 전후 동일함을 확인했다.
