# 카테고리 선택·고시 설정·접수 ID 릴리스 감사 — 2026-10-06 (step578)

제조년월·출시년월과 `세탁방법 및 취급시 주의사항` 설정은 이름이 정확히 일치하는 `legalPage.notices`의 공통 고시에만 연결한다. 같은 제목의 scalar 필드나 certificates에는 넣지 않는다. 수동 수정과 명시적 공란은 우선한다. 고시 연결 수정과 정확한 g 단위 포장 무게 별칭 수정으로 **포함된 출력값이 실제로 달라지는 경우에만** 지문에 해당 변경 표식을 추가한다. 정상 고시나 수동 공란 등에서 출력이 바뀌지 않으면 이전 지문을 유지하며, 이전 접수 기록의 원문을 다시 쓰지 않는다. 영향을 받는 이전 입력 지문의 PUT, 출력/패키지, 접수 저장은 409로 거절한다. 양사의 실제 앱 API·임시 SQLite로 이 경계를 검사했으며 포장 g/mm와 접수 결과는 fixture다.

접수 결과는 정확한 파일명의 행에서 화면에 보이는 복사 버튼의 전체 ID를 읽는다. 표시 ID가 전체 값이거나 전체 값의 첫 8자+`...`와 일치할 때만 사용한다. 숨긴 버튼에서 ID를 가져오지 않으며 중복 행·중복된 표시 복사 버튼·표시값 불일치·풀리지 않은 생략 ID로 다른 접수를 추정하지 않는다. 앱의 공용 결과 검증도 `...`·`…`가 남은 ID를 거절한다. 파일 검증과 상품별 조회에서 같은 전체 ID를 사용하며, 실제 Hub 접수 완료를 새로 확인한 것은 아니다.
