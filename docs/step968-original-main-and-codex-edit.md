# Original representative image and optional Codex editing

The collected representative image is a valid default for a quotation. Toolbar work must not automatically OCR, translate, regenerate or upload it. An existing explicit selection remains selected. Additional/detail translation remains a separate stage. Old uncertain image attempts retain their recovery fence.

The saved-stage projection accepts an exact, owned, current collected main/option reference. Foreign, missing, duplicated, mismatched or invalid references remain blocked. Unresolved generated image reviews still take precedence. A previous failed automatic main translation no longer defeats the current original-image selection.

The stage 3 editor has a separate Codex request button. Its open editor retains the full version/category/quotation upload basis; only a one-time request ID, source image and prompt cross the same-origin channel to the locally paired CLI. `main-image/next` claims one request. `main-image/complete` accepts a local PNG/JPEG file, then the original editor uses the existing private image upload and option-specific atomic link API. Scope changes, stale source clocks and uncertain writes never select a fresh upload automatically. There is no Supplier Hub write in this flow.

CLI 0.1.3 is packaged without runtime dependencies/install scripts. It runs on each member's own PC, with existing 15-minute pairing and no app password or cookie. A running Codex task must process the MCP image tools; connecting an MCP alone does not start a Codex conversation or guarantee an image model is running.
