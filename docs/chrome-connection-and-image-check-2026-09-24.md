# Chrome 연결 및 Supplier Hub 이미지 안내 재확인 — 2026-09-24

## 확인

기존 supplierChrome 연결을 재사용했다. 탭 목록은 비어 있었으나 새 탭에서 Supplier Hub 대량등록 화면과 쿠플러스 AI상품등록 화면에 로그인된 상태로 진입했다.

- Supplier Hub `/qvt/registration`: 견적서·상품 이미지·필수 표시사항·법적 서류 업로드 영역, 별도의 약관 체크박스, 비활성 파일 검증 버튼을 확인했다. 대표 이미지와 상세 이미지가 동일하면 반려가 발생할 수 있다는 안내를 확인했다.
- 쿠플러스 `/AIRocketReg`: 화면에 CLI 연결됨, v1.2.12 정상 동작, v1.3.2 업데이트 필요가 표시됐다. CLI 업데이트/설치를 실행하지 않았다.
- 자동수집 버튼 클릭 후 화면에서 추가 안내나 수집 완료 결과는 확인되지 않았다. 오늘 상품 표는 비어 있었다.

## 추정

쿠플러스의 CLI 상태 표시로 웹과 로컬 구성 요소 사이의 연결 가능성은 보이지만, 상태 표시만으로 실제 수집·등록 경로를 확정할 수 없다.

## 미확인

SourceFlow와 해당 CLI/확장의 통신, 실제1688 수집 공급원, 전체 카테고리 양식, 공식 Excel 바이트, 실제 검증·등록 성공은 미확인이다. 쿠플러스 비공개 서비스를 SourceFlow 공급원으로 호출하지 않았다. 파일 업로드/약관 동의/검증/운영 등록/유료 작업은 실행하지 않았다.

## 반영

최종 견적의 대표 이미지 참조가 상세 이미지 목록에도 있으면 검토 안내를 추가했다. 옵션별 수정과 미저장 대표 이미지 변경도 반영한다. 파일 참조 일치만 검사하며 서로 다른 키로 저장된 동일 바이트 이미지나 시각적 유사성까지 판별하지 않는다. 원본 이미지를 삭제하거나 자동 교체하지 않는다. 실제 반려 확정 판정은 아니다.
