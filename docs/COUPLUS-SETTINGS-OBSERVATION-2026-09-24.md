# 쿠플러스 기본설정 재관찰 — 2026-09-24

출처: 로그인된 Chrome의 https://www.couplus.co.kr/AIRocketReg 기본설정. 읽기/화면 펼치기만 수행했으며 설정 저장·CLI 업데이트·상품 작업/등록 전송은 실행하지 않았다.

- 확인: 브랜드 목록(쉼표 구분), 제조사, 수입/판매원, 거래타입, 수입여부, A/S 연락처, 박스 SKU 수량이 표시된다. 가격 설정에는 환율, 반올림 단위, MSRP 배수, 공급/쿠팡 마진율, 최소 마진 보장·금액, 번들링 활성화가 있다.
- 확인: 화면에 공급가=매입가/(1-공급마진율), 판매가=공급가/(1-쿠팡마진율) 공식과 원가/공급마진/쿠팡마진 구성 막대가 표시된다. 사용자 설정 50%/40%에서 표시 막대는10%/50%/40%였다. 이는 실제 판매가 대비 구성으로 검증되지 않았다.
- 확인: 상/하단 이미지, 이미지 번역 지침, 카피라이트, 누끼 자동 적용, 비노출 속성 생성 제어가 있다. AI 기능은 서버 자동 처리이며 별도 API키가 불필요하다는 안내문이 표시된다. 해당 안내는 쿠플러스의 기능 설명이며 SourceFlow 연결이 완료됐다는 의미가 아니다.
- 확인: CLI 상태 화면은 v1.2.12 연결됨 및 v1.3.2 업데이트 필요를 표시했다. 실제 프로그램/통신 성공을 별도로 검증하지 않았고 설치/업데이트하지 않았다.
- 미확인: 번들링 체크를 켜서 조건을 관찰하려 했으나 제어 도구가 상태 변경 실패를 반환했고 재조회에서도 꺼짐이었다. 추가 조건·번들 산식은 확인하지 못했다. 내부 상태나 네트워크를 추출하지 않았다.
- 미확인: 전체 카테고리별 자동작성 기본값, 모든 AI 실제 결과, Supplier Hub 접수 실행.

SourceFlow 반영: 기본설정에 판매 단위 원가를 입력하는 계산 미리보기를 추가했다. 기존 calculatePrice를 그대로 사용하며 최소 마진 설정 해제 시0으로 계산한다. 표시 비율은 계산된 판매가 기준으로 명시한다. 참조 이미지의25.6위안/350/50%/40%/10원 반올림 사례를 운영Chrome에서17,920/29,870/38,830원으로 대조했다. 계산 예시는 저장하지 않았다.
