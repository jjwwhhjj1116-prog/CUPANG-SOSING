# Supplier Hub 80719 상품 페이지 대조 기록

관찰일: 2026-09-22. 관찰 위치: Supplier Hub `/sr/registration/step/productPage`.
원본 필드 기록: [상품 페이지 DOM 선택값](supplier-hub-80719-product-fields-2026-09-22.json).

## 확인한 내용과 반영 범위

- 주방용품 > 주방수납/정리 > 주방수납바구니/바스켓(80719)의 상품 페이지에서 선택 항목 20개의 표시 문구, 실제 값, 순서를 확인했다. `app/quotation-schema.ts`에 그대로 반영했다.
- 선택 항목의 `해당사항없음`은 실제 값이 빈 문자열이다. `해당없음`이라는 별도 비어 있지 않은 선택값이 있는 항목과 구분한다. DOM의 기본 선택 상태는 실상품의 해당 여부를 입증하지 않는다.
- 색상·수량·사이즈는 필수 항목이다. 작성 중에는 빈값 저장을 허용하고 필수 미입력으로 표시한다.
- 기존 자동 재질 값이 목록에 없으면 원래 값과 출처를 유지하고 입력 오류로 표시한다. 예를 들어 `면`을 다른 재질이나 빈 문자열로 바꾸지 않는다.
- 이미지·법적·물류 구역의 현재 규격은 쿠플러스 참조 화면 기반이다. 이번 상품 페이지 DOM 확인으로 해당 구역까지 공식 검증된 것은 아니다.

## 추정·미확인

- 조회·Next 후 마지막 저장 시각 표시가 나타났으므로 임시 작성 상태가 저장되었을 가능성이 있다. 최종 제출이나 상품 등록 성공으로 해석하지 않는다.
- 최종 제출, 운영 상품 등록, 필수 서류의 법적 적합성, 다른 카테고리 호환성은 확인하지 않았다.
- 원산지나 KC 인증 해당 여부를 카테고리만으로 생성하지 않는다. 선택 목록은 입력 형식의 근거이며 상품 사실의 근거가 아니다.
