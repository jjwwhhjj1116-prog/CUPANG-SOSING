이메일뿐 아니라 역할·회사코드·회사명·승인 상태가 모두 맞아야 로그인과 기존 세션을 허용한다. 회사 정보는 계정 화면에서 변경할 수 없다. 관리자는 지정 회원의 이용 정지·재개를 관리할 수 있다. 공개 가입, 새 이메일 승인 및 관리자 승격 API는 제공하지 않는다.

로그인 화면은 아이디 저장과 자동 로그인 유지를 지원한다. 비밀번호는 브라우저 비밀번호 관리자용 current-password 필드에만 입력하며 웹 저장소에 저장하지 않는다. 일반 세션은 8시간, 자동 로그인은 30일이고 쿠키는 HttpOnly·SameSite=Strict·HTTPS Secure다. DB에는 세션 토큰의 SHA256만 저장한다. 매 요청마다 계정 정책과 승인 상태를 다시 검사한다.

비밀번호는 개별 salt + 서버 pepper HMAC + PBKDF2-SHA256 100,000회로 해시한다. pepper는 YOOFAM_PASSWORD_PEPPER Worker Secret으로만 공급한다. YOOFAM_AUTH_ENABLED=true로 회원 인증을 활성화한다. Cloudflare Access 외부 게이트가 있는 경우 이 로그인과 별도로 적용된다.

scripts/provision-members.mjs는 비공개 표준입력으로만 두 비밀번호와 pepper를 받아 ACL 제한 임시 SQL에 해시를 기록한다. 기존 관리자 ID를 검증하고 이메일의 기존 회원 ID를 유지한다. 지정 계정의 세션을 폐기하되 상품·설정·수집·이미지·R2 소유권은 변경하지 않는다. 적용 후 provisioned=1 두 행과 실제 로그인을 확인하고 임시 SQL을 제거한다. 비밀번호·pepper·세션 토큰은 저장소나 로그에 넣지 않는다.

암호 교체 직전에 시작한 로그인도 검증한 해시를 세션 INSERT 조건에 묶어 이전 비밀번호로 새 세션을 발급하지 못한다. 회사 교정 이전에 저장된 다른 회사의 견적서는 frozen/current profile 회사가 현재 회원과 다르면 409로 거절한다. 기존 원본을 새 회사 자료로 바꿔 표시하거나 전송하지 않는다.
