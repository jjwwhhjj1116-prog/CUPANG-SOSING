# 공식 견적서 다운로드 분류 관찰 — 2026-09-23

출처: 로그인된 Chrome https://supplier.coupang.com/qvt/registration 에서 최신 견적서 파일 다운로드 클릭 후 나타난 선택 창.

## 확인
- 검색 탭은 상품명 / 칸 카테고리 아이디로 나뉜다. 최대 6개 카테고리를 선택할 수 있다.
- 80719 코드 입력·검색 후 선택 결과는 나타나지 않았다. 코드 무효나 다른 코드 체계라고 확정할 수는 없다.
- 탐색으로 주방용품 → 주방수납/잡화 → 건조대/진열대/정리대 → 주방수납바구니/바스켓을 선택했다. 체크 상태와 선택된 경로, 활성화된 다운로드 버튼을 확인했다.
- 선택된 카테고리의 견적서 다운로드 버튼을 눌렀고 선택 창이 닫혔다. 파일 다운로드 완료 및 바이너리 확보는 확인하지 못했다.

## 미확인
- 칸 카테고리 아이디와 Couplus/개별등록 상품 카테고리 80719의 실제 코드 매핑.
- Excel 파일 원본, 시트·헤더·데이터 행·수식·유효성 검사 규칙.
- 다운로드 완료 확인을 위한 chrome://downloads/ 접근은 브라우저 URL 보안 정책이 거절했다. 우회하지 않았다.

## 반영
- 앱 견적 출력 화면에 공식 양식 확보 순서, 링크 및 바스켓의 이름으로 관찰한 탐색 경로를 제공한다. 이 안내는 코드 매핑 또는 양식 검증 성공을 의미하지 않는다.
- 다른 상품으로 전환할 때 견적 패널 상태가 재사용되지 않도록 상품/지정 프로필별로 초기화한다. 이전 상품의 미리보기·연결 설정을 새 상품에 표시하지 않는다.
