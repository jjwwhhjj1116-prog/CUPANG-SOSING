# 64497 다음 단계 이동과 MSRP 확인

## 확인
- 이전 관찰용 A / 64497 견적이 중간 저장 불러오기에 2026.09.24 09:24로 존재했다. 이전 단계의 임시저장 가능성은 실제 저장으로 확인됐다. 이 관찰용 견적만 다시 불러왔다.
- 옵션과 가격이 비어 있으면 상품정보의 다음 이동이 거절된다. 관찰용 옵션 W/1, 공급가1/판매가2, 바코드 없음, 제조사 A를 입력했다. 실제 상품값이나 기본설정으로 사용하지 않는다. 임시 입력 외 최종 전송은 실행하지 않았다.
- 이어서 ‘MSRP, OSRP 약관에 동의해주세요.’ 메시지가 표시됐다. 자세히보기는 권장가 설정 권한 또는 제조사로부터 해당 가격 정보를 받았다는 확인, 권장가/공식판매처가격의 의미를 안내한다.
- 약관 동의 버튼을 누르지 않았다. 사용자에게 Chrome에서 직접 확인·동의를 요청했다. 이미지/법적정보/물류 단계에는 도달하지 않았다.

## 구현과 검증 범위
- 배수로 계산한 MSRP는 가격 근거가 검증된 값이 아니라 초안임을 견적 필드에서 안내한다.
- 등록 준비 검사에서 최종 포함 옵션의 MSRP를 가격 근거 검토로 분류한다. 계산/저장 상품값과 수동값의 안내를 구분하며 수동 편집도 약관 동의로 취급하지 않는다.
- 공란/제외 옵션에는 MSRP 검토를 추가하지 않는다. 잘못된 숫자는 기존 입력 오류를 우선하고 검토 메시지를 중복 추가하지 않는다. 값과 저장 상태는 변경하지 않는다.
- 검사 항목의 fieldId=msrp, optionId는 기존 정확한 견적 항목 이동 기능에 연결된다. 외부 동의 완료 여부를 저장하거나 추정하지 않는다.
