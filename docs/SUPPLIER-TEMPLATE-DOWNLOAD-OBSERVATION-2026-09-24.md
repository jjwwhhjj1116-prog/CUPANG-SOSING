# 쿠플러스와 Supplier Hub 공식 견적 다운로드 분류 대조

관찰일: 2026-09-24. 기존 로그인 Chrome에서 표시된 UI를 읽었다. 운영 등록·파일 업로드·동의 체크·유료 실행은 하지 않았다.

## 확인

- 쿠플러스 https://www.couplus.co.kr/AIRocketReg : 로켓배송 AI상품등록 화면 진입. CLI 상태 팝업은 연결됨, v1.2.12 정상 동작 중, v1.3.2 업데이트 필요라고 표시했다. 이는 화면 보고이며 로컬 CLI 내부 프로토콜 검증은 아니다. 업데이트 버튼을 실행하지 않았다.
- 쿠플러스 상품 추가 → 빈 상품 대기열 → 상품 추가 → 카테고리 선택에서 주방용품 → 주방수납/정리 → 주방수납바구니/바스켓 말단 이름을 확인했다. 말단 클릭은 정확 일치 선택자에서 실패했고 선택 완료를 누르지 않았다. 등록번호80719 연결 근거는 기존 첨부 화면 및 이전 기록이다.
- Supplier Hub https://supplier.coupang.com/qvt/registration 에서 최신 견적서 파일 다운로드 팝업을 열었다. 최대6개 카테고리 선택, 상품명 검색/칸 카테고리 아이디 검색 탭을 확인했다.
- 공식 다운로드 카테고리 탐색에서 주방용품 → 주방수납/잡화 → 건조대/진열대/정리대 → 주방수납바구니/바스켓을 선택했다. 선택된 경로와 체크박스, 다운로드 버튼 활성화 확인.
- 선택된 카테고리의 견적서 다운로드 클릭 후 팝업이 닫히고 성공 및 “Generating quotation file. The file will be downloaded soon.” 표시를 확인했다.
- SourceFlow 운영 사이트는 jjwwhhjj1116@gmail.com 로그인 상태로 열렸으며 조회 화면의 상품은0건이다. 전송 API는 코드에서501 미연결 응답임을 재확인했다.

## 추정

- 동일한 말단 이름은 같은 상품군을 가리키는 것으로 보이지만, 두 트리의 코드 체계와 공식 Excel 내부 분류 일치를 확정하는 근거는 부족하다.

## 미확인

- 칸 카테고리 아이디80719 검색 후 검색 결과가 나타나지 않은 것을 관찰했다. 이것만으로80719가 잘못된 코드라고 단정하지 않는다.
- Excel 파일 생성 안내는 다운로드 파일의 바이트 확보와 다르다. 이번 실행 후 로컬 Downloads의 XLSX/XLSM/XLS 목록에서 신규 파일을 찾지 못했다. 파일명/실제 저장 위치/시트/머리글/분류 코드/매크로 여부는 미확인이다. 다른 과거 파일을 해당 공식 양식으로 사용하지 않았다.
- Supplier Hub 탭을 계속 열어둘 필요가 있는 내부 통신 경로, 전송 API/확장/CLI의 정확한 책임 경계, 실제 상품 접수 결과는 미확인이다.

## 구현 반영

카테고리 설정에 공식 견적 다운로드 링크·절차 및80719 참고용 관찰 경로를 표시한다. 등록 카테고리 경로를 다운로드 경로로 덮어쓰지 않으며, 파일 연결을 제출 검증 완료로 처리하지 않는다. 다른 카테고리에80719의 경로를 재사용하지 않는다.
