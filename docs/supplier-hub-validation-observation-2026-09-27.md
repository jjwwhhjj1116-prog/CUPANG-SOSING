# Supplier Hub 등록 및 검증 관찰 — 2026-09-27

기존 Chrome에서 로그인된 Supplier Hub의 표시된 화면을 읽었다. 신규 브라우저/프로필은 실행하지 않았다.

- 대시보드의 대량 상품 등록 링크에서 /qvt/registration이 열렸다.
- 최신 견적서 파일 다운로드 → 상품명 검색 `주방수납바구니` → `주방용품 > 주방수납/잡화 > 건조대/진열대/정리대 > 주방수납바구니/바스켓` 선택 → 견적서 다운로드 요청. 생성 성공 알림 및 다운로드 단계 체크가 표시됐다. 파일 바이너리/시트/셀과 저장 위치는 확인하지 못했다.
- 브라우저 도구가 chrome://downloads/를 허용 프로토콜 정책으로 거절했다. 우회하지 않았으며 사용자에게 생성 파일 경로를 요청했다.
- 검증 진행상태 표의 열: 견적서 명 / 견적서 등록일 / 검증 상태 / 검증 결과 / 견적서 ID. 실제 데이터 행은 없음.
- 화면 안내: 1달 이내 견적서 조회 가능; 업로드 후 최대 2시간 안에 검증 완료; 반려 시 상세내역 다운로드 후 수정·재제출; 완료 시 상품 등록 상태 확인에서 상품별 검증상태 확인.
- 업로드, 법적 해당여부 변경, 약관 동의, 파일 검증 실행 및 상품 등록은 수행하지 않았다.

## 구현 근거와 한계
등록 결과에서 견적서 명을 구분하므로 앱의 공통 출력 이름 quotation-filled를 최종 자료 지문 기반 YOOFAM-<64자리 SHA256>.확장자로 변경했다. 상품 ID, 저장된 상품/옵션/내용/카테고리/설정/견적 수정값은 기존 자료 지문에 포함된다. 같은 저장 자료는 같은 이름, 변경된 자료는 다른 이름이며 미리보기/ZIP/첨부 목록/HTML 링크가 일치한다. 이름은 대조용이며 접수 증거 또는 Supplier Hub의 허용 파일명 길이 검증을 뜻하지 않는다.
TSV가 기존 출력 엔진에서 지원되지만 첨부 목록의 파일명 검사에서 거절되던 오류도 수정했다. CSV/TSV는 검토 자료이고 Supplier Hub Excel 업로드 적합성은 별도이다.

전송 adapter 및 접수 확인은 아직 미구현이다. 검증 완료를 상품 등록 완료와 같다고 해석하지 않는다. 쿠플러스 탭은 로그인 화면이며, 현재 기본값 직접 대조는 로그인 이후 가능하다.
