## SEO 초안 입력 보존

같은 상품의 설명·이미지 등 다른 편집을 저장하면 상품 버전이 바뀌면서 SEO 생성 카드가 다시 마운트되고, 아직 생성 요청하지 않은 브랜드·특징·키워드 메모가 사라졌다. 상품 ID로 마운트를 유지하고 현재 버전의 자료를 다시 조회하되 동일 수집 원문이면 작성 중인 메모를 보존한다. 원문·참조·카테고리가 실제로 바뀌면 이전 요청을 새 원문에 실행하지 않는다.

생성 메모는 닫기·전송 전 확인에서 미저장 입력으로 감지한다. 생성 버튼 자신의 메모만 그 버튼의 검사에서 제외해 정상 초안 생성을 허용한다. 다른 편집기의 미저장 값과 작업은 계속 감지한다. 현재 버전·활성 단계·mount 확인, 오래된 콜백과 응답 차단, 요청 ID·상태 조회·응답 유실 복구는 유지한다. 실제 원문 변경·타 상품 전환·유료 생성 동의와 조회 실패 뒤 재시도도 검사했다.
