# 상품 추가 초안의 Google 옵션 번역 이어쓰기

상품 추가가 최초 SEO 초안 후 남은 옵션을 처리할 때, 이미 처리한 중국어 상품명·설명도 다시 Google 번역으로 보내던 문제를 수정했다. 다음 옵션 묶음은 최초 초안과 현재 수집 원문에 연결하고, 미번역 옵션값만 전송한다. 상품명·설명은 검토 문맥으로 보관하며 옵션 요청에 전송하지 않는다. 최초 SEO 번역의 필수 상품명 검사는 유지한다.

이어쓰기의 최초 작업 ID, 현재 상품·콘텐츠 버전, 옵션 버전, 수집 원문과 옵션 묶음 연결을 승인 및 실행 전에 확인한다. 승인·실행의 옵션 버전 비교 갱신도 적용한다. 클라이언트가 첫 SEO 작업을 옵션 작업으로 지정하거나 다른 작업·옵션 원문으로 바꾸면 실행하지 않는다.

Google로 설정을 변경하기 전에 Workers AI로 완료한 최초 SEO도 유지하면서 남은 옵션을 Google로 번역할 수 있다. 최초 작업의 검토 모델과 실제 결과 모델, 비어 있지 않은 SEO, 원문 문맥과 전체 SEO 범위를 확인한다. 새 옵션 작업에는 현재 Google 설정 검사를 적용한다. 기존 최초 작업과 이미 적용한 SEO를 수정하거나 다시 실행하지 않는다.

옵션 번역의 429 응답은 받은 결과와 제한 응답 상태를 부분 초안으로 보존한다. 누락 항목을 완료로 처리하거나 자동 재호출하지 않는다. 최초 필수 상품명 번역 자체가 실패한 경우의 수동 검토 경로도 유지한다. 완료 결과를 다시 확인할 때는 기존 결과를 재사용한다.

옵션 이어쓰기 결과는 옵션 적용 화면으로만 연결한다. SEO·표시사항 일괄 적용과 개별 내용 교체에는 사용할 수 없으며, 자동 작업의 SEO 완료 근거에도 포함하지 않는다. 직접 수정한 값과 제외 옵션은 기존 적용 규칙에 따라 보존한다.

## 검수와 배포

중복 상품명 요청 및 이전 Workers AI 설정과의 충돌을 수정 전 오프라인 응답으로 재현했다. 수정 후 번역·초안·옵션 복구·적용·자동 작업·화면 검사에서 중복을 제외한 테스트 209개가 통과했다. 50개 속성 이후 남은 6개 SKU의 옵션 묶음을 처리하면서 상품명·설명을 각각 한 번만 요청하는 검사를 포함한다. 승인·실행 중 옵션 버전 변경, 잘못된 작업 연결, 제한 응답, 완료 결과 재사용, SEO·표시사항 적용 차단도 검사했다. 실제 Google 또는 1688 요청을 실행한 검사는 아니다.

타입 오류는 없고 정적 검사는 오류 0개와 기존 경고 8개였다. 운영 빌드와 기존 마이그레이션 17개를 확인했다. 확장 다운로드 0.2.57·0.2.58은 파일 수·바이트·해시가 유지되므로 확장 새로고침이 필요하지 않다.

운영 배포 후 같은 Chrome의 기존 와이홉 견적서 입력값 72개와 수정 없는 저장 버튼 상태를 대조했다. 기존 상품의 저장·삭제·번역·재수집·전송은 실행하지 않았다. Supplier Hub의 현재 회사는 유앤채 A01526306이며 와이홉 A01464742 앱 상품을 이 회사로 전송하지 않았다. 비공개 화면·로그·배포 기록은 `outputs/step601-*`에 보관한다.

모든 카테고리의 쿠플러스 기본값 동등성, 신규 1688 수집, 단품 포장 실측값, 일치하는 회사로 실제 Supplier Hub 신규 최종 접수 검수는 남아 있다. 이번 수정과 검사 통과를 전체 작업 완료 또는 실제 접수 완료로 표시하지 않는다.
