## SEO 입력

상품명·검색태그·한국어 옵션명에 원본의 입력 안내를 적용했다. 검색태그는 3줄로 표시하며 원문 글자 수가 120자를 넘으면 주의, 140자를 넘으면 경고 색상으로 표시한다. 경고는 추가 저장 차단이나 자동 수정이 아니다.

기존 긴 상품명·검색태그와 명시적 공란을 유지한다. 검색태그 원문 입력 한도 5,050자, 저장 전 150자 단위의 완전한 태그 검토·정리, 견적서 태그 보존/함께 비우기 선택은 기존 자체 보호 기능으로 남겼다. 원본 textarea의 `maxlength=150`을 근거로 역사 데이터를 조용히 자르지 않는다. 원본 옵션명은 읽기 전용으로 남기고 한국어 이름만 개별 수정한다. 원본에 없는 일괄 이름 통일 동작은 추가하지 않았다.

수정한 공통 SEO와 정확한 옵션 이름만 하나의 명시 저장으로 반영한다. owner/product/source clock, 다른 저장값 비교, 숨은 단계·계정 ABA, 잘못되거나 유실된 ACK의 GET 확인, 직접 수정한 견적서 태그/공란 보호를 변경하지 않았다.

## 가격 화면

정책·옵션 표 아래에 원본의 상품 원가/공급 마진/쿠팡 마진 비율과 전체 옵션 가격 요약을 배치하고, 하단 저장 버튼을 가운데에 둔다. 최소 공급 마진 보장과 계산식 설명도 원본 문구로 보완했다. Stage2 원본에는 슬라이더나 기본 노출 MSRP 입력이 확인되지 않아 이를 새 원본 기능으로 추가하지 않았다. 기존 자체 고급 설정과 저장값은 유지한다.

비율은 원본처럼 `max(1, 100 - 공급 마진율 - 쿠팡 마진율)`과 두 설정 마진율의 표시다. 이것은 원가·공급가·판매가의 새로운 계산식이 아니다. 비어 있거나 유효하지 않은 마진 입력은 임의 비율로 바꾸지 않는다. 금액과 요약은 기존 `effectiveGridPrices` 계산을 사용한다. 검색·페이지·체크 선택과 관계없이 전체 포함 옵션 중 계산 가능한 행을 평균하며, 직접 수정한 공급가·판매가를 반영한다.

정책 카드와 하단 저장은 동일 `saveGrid`를 사용한다. 정책·옵션·견적 가격의 정확한 원본/버전/리비전/fingerprint를 확인하는 하나의 Stage2 저장과 불명확한 ACK 복구를 유지한다. 독립 소스 검토에서 이번 이동·표시 변경에 대한 추가 결함은 확인되지 않았다. 기존 정확한 숫자/마진 평균 회귀와 새 정책·직접 가격·필터·단일 원자 저장 회귀를 함께 확인한다.

## 여러 속성의 화면 수집

스크립트 SKU 자료가 없을 때만 현재 offer의 literal identity와 하나의 SKU 영역을 확인해 DOM 행을 보완한다. 하나의 변동 축과 명시된 단일 값 축은 실제 변동 타일 수만큼 보관하고, 그룹 순서대로 이름을 결합한다. 각 변동 타일에 표시된 단일 위안 가격만 사용한다. `균码` 같은 단일 축의 가격이나 상품 상단 가격을 다른 옵션 원가로 대입하지 않는다.

명시된 전체 조합 재고 행이 있으면 단일 변동 축에서도 그 행을 우선한다. 여러 변동 축은 실제로 관찰한 전체 조합 행의 유일성·전체 커버리지가 증명될 때만 허용한다. 축 수의 곱은 완전성 확인에만 쓰며 Cartesian 옵션을 생성하지 않는다. 원가 없는 조합은 누락시키지 않고 null로 남긴다. SKU·MOQ·재고는 근거 없이 만들지 않는다.

독립 검수에서 발견한 다음 속성명을 단일 값으로 오인하는 경우, 전체 조합 행을 무시하는 경우, 중첩 S/M 이름을 단일 값으로 합치는 경우를 차단하고 회귀를 추가했다. 부분·중복·불명확 조합, 다른 offer, 추천·후기, private 표시, 스크립트 SKU의 잘못된 선언은 계속 차단한다. 새 source API·외부 상세 URL·iframe 요청을 추가하지 않았다. 이전에 거절된 실제 1688 접근을 직접 또는 간접 경로로 재시도하지 않았다.

## 실제 코드 경로의 합성 연결 검증
