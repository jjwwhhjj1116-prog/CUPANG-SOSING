# COUPLUS 작성 규칙과 YOOFAM 검증 기준

2026-11-06 관찰 기준. 최근 한 달의 서로 다른 10개 카테고리, 36개 옵션과 실제 견적 화면을 대조했다. 현재 배포된 COUPLUS 클라이언트의 입력·정규화·검사 규칙을 독립 구현하는 작업이다. 비공개 서버의 RAG와 모델 내부 지침까지 확인했다는 의미는 아니다. 구현은 실제 새 수집본과 모델 결과로 계속 검증 중이며, Supplier Hub 실제 접수는 아직 확인되지 않았다.

## 단계와 반응 속도

기본 단계는 SEO, 가격, 대표이미지, 추가이미지, 상세이미지, 한글표시사항, 견적서다. 공식 카테고리가 사이즈표를 요구하면 상세이미지 다음에 사이즈표를 넣어 8단계로 표시한다. COUPLUS의 방문한 단계 이동은 메모리에 있는 데이터를 표시하며, 14회 관찰에서 추가 fetch/XHR이 없었다. 첫 DOM 변경은 약 6~59ms였다. 이는 사용 중인 탭의 관찰이며 초기 로딩이나 화면 그리기 완료 시간은 아니다.

YOOFAM의 수정 전 새 상품에서 8단계를 방문한 뒤 상품명 하나를 저장한 측정은 클릭 후 12초 동안 API 요청 48건이었다. 전체 상품·설정·작업 목록·카테고리 양식과 견적서의 중복 조회가 포함됐다. 저장한 상품만 갱신하고, 방문한 편집기를 보존하며, 다른 단계의 읽기를 줄이는 것이 개선 기준이다. 저장 응답이 불명확한 경우에는 원래 결과를 읽어 확인하고 쓰기를 반복하지 않는다.

실제 배포 후 같은 저장 동작의 12초 관찰은 요청 18건, 응답 본문 합계 10,215,568→848,787바이트였다. 이는 압축 전 응답 크기이며 실제 전송량과 구별한다. 저장 확인 시간은 845.5→885.3ms로 줄지 않았다. 후속 R4의 방문한 8단계 이동에서는 해당 상품 API가 0건이고 DOM 준비는 44.7~111.5ms였다. 별도 수집함 배경 조회는 이 수치에서 분리했다. 초기 방문, 이미지 해독·화면 그리기 완료, 빠른 연속 클릭까지 검증한 결과는 아니다.

## 새 원문과 생성 결과 검증 상태

10개 URL을 실제 1688 페이지에서 새로 수집해 총 408개 원본 SKU를 비교했다. 같은 날 앞서 읽은 COUPLUS 가격 자료와 SKU 집합은 모두 일치했고 396개 가격이 일치했다. 행주걸이 12개는 공개 페이지 가격과 COUPLUS의 분산판매 가격 출처가 달랐다. API 가격 출처가 연결되지 않은 상태에서 고정 할인율을 만들어 일치시키지 않는다. 324개 데스크매트 옵션도 원본에 전부 보존하고 검토 대상으로 고른 5개를 별도로 저장했다.

R5(`70027941`) 실제 새 실커튼 초안에서는 같은 상품에 저장된 추가 수집본을 한 번 연결해 속성 10개와 상세 이미지 25개를 보완했다. 원래 옵션·선택한 6개 옵션·고정 가격·수동 수정값은 보존됐다. 당시 견적의 옵션별 색상·치수는 맞았지만 소재 근거가 누락돼 소재 제안은 보류됐다. R6(`fe252200`)의 새 견적 작업에서는 원문 `涤纶（聚酯纤维）`가 `collection-source` 근거로 전달되는 것을 실제 확인했다. 다만 결과 처리는 재질 근거 오류로 실패했고, 새 SEO에도 잘못된 재질어가 추가됐다. 해당 작업들은 미적용 상태로 보존하며 재실행하지 않는다.

후속 v3 정책은 검증된 원문 재질의 표준 번역과 부적절한 대체값 처리를 보완한다. 이 문서 갱신 시점에는 독립 검토·배포 후 검증이 남아 있다. 확인된 기존 섬유 별칭만 사용하고, 문자열 전체가 해석되는 경우에만 한국어 표준명으로 정리한다. 원문의 `85.0%` 같은 숫자 토큰은 그대로 두며, 비율이 없는 원문에 `100%`를 추가하지 않는다. 미지원 재질·해석되지 않는 잔여어·`100D` 같은 다른 규격은 추측해 변환하지 않는다. 새 AI 작업의 검증 경계만 바꾸고 일반 수동 편집과 기존 작업의 정책은 유지한다.

## 자동 생성과 수정 우선순위

| 항목 | 확인한 작성 규칙 |
| --- | --- |
| 상품명 | 새 생성 지침은 자연스러운 한국어 70자 이내를 요청한다. 결과를 무조건 70자로 자르는 규칙은 아니다. 브랜드의 첫 항목을 앞에 한 번 붙이고, 선호 타겟·특징을 결과 뒤에 기계적으로 덧붙이지 않는다. 수동 편집의 기존 제한은 별도로 유지한다. |
| 검색태그 | 타겟 검색어, 쿠팡 관련 검색어, 자동완성 순서로 후보를 얻는다. 관련어는 선호 정보이며 소재·규격의 사실 근거가 아니다. 불필요한 기호·단독 자모를 정리하고 순서를 보존해 중복을 제거한다. 전체 정리 후보는 보존하고, 견적서에는 쉼표와 공백을 포함해 150자에 들어가는 앞부분의 완전한 태그만 넣는다. |
| 옵션 번역 | 선택한 옵션의 ID에 결과를 연결한다. 처음 20개는 SEO와 함께 생성하고 나머지는 20개 단위로 처리한다. 일부 응답이 없거나 순서가 달라도 다른 옵션에 값을 붙이지 않는다. 사용자 수정과 명시적 공란은 보호한다. |
| 가격 | 환율·마진으로 계산하는 일반 경로와 사용자가 선택한 고정 소싱 판매가·공급가·매입원가를 적용하는 경로를 구분한다. 고정 기준 CNY는 최초 선택 집합에 묶는다. 더 비싼 실제 옵션은 같은 기준에서 가산 계산한다. 원본 수집 가격은 덮어쓰지 않는다. |
| 소싱 마진 기준 | 고정 가격의 통과 기준은 현재 계정의 root `rocketMarginGate`다. 마진율만, 마진액만, 둘 다, 둘 중 하나의 네 모드를 지원한다. 설정이 없을 때만 기본 25%를 사용한다. 상품별 저장값이나 수집 당시 설정이 현재 계정 기준을 대신하지 않는다. |
| 대표·추가·상세 | 수집한 대표이미지 사용이 기본이며 AI 편집은 선택이다. 편집한 결과는 선택한 이미지와 견적서 슬롯에 연결한다. 원본과 다른 옵션의 이미지는 보존한다. |
| 재질 표준 번역 | 새 v3에서는 원문 전체가 지원되는 섬유·명시된 비율로 확인될 때 원문 기준의 표준 한국어 값을 사용한다. 원문이 불명확하면 경고와 원문을 보존한다. 모델이 만든 미확인 재질어를 검증된 사실로 채택하지 않는다. |
| 한글표시사항 | 내용량의 정상 생성 기본 표기는 단품 `1개`, 묶음 `수량개`다. 소재·종류의 불명확한 내용은 `상세정보참조`로 정리한다. 이 기본 표기를 공급자가 확인한 물리적 수량이나 소재로 승격하지 않는다. |

현재 원가·할인·선택 옵션·저장 가격 정책이 과거와 다르면 같은 URL도 다른 금액을 낼 수 있다. 과거의 할인 전 금액이나 사용자가 선택한 매입원가를 새 수집 원문인 것처럼 바꾸지 않는다. 옵션 CNY만 수정한 경우 자동 계산값을 수동 견적값으로 저장해 다음 재계산을 막지 않는다.

## 이미지 편집과 원문 제거

대표·상세 편집은 텍스트, 글꼴·크기·정렬·굵기·기울임·행간, 단색·그라데이션, 테두리·그림자·각도, 지우개·브러시·자르기, 확대·이동, 실행 취소·다시 실행과 PNG 저장을 제공한다. 저장 대상은 현재 상품·옵션·이미지에 묶고 원본은 보존한다. 실제 신규 양말의 상세 번역·교정본은 저장 후 공통 행과 8개 옵션의 견적 이미지 키에 연결됐다. 이 확인은 모든 폰트·효과의 픽셀 일치나 전체 자동 번역 품질을 보장하지 않는다.

실제 소재표 이미지에서는 인식 문구의 영역 밖 원문 획이 합성본에 남았다. 후속 보완은 새 인식 실행의 단색 문구 패널에서 연결된 글자 획만 제한된 주변 영역으로 추적하며, 사진·상품표시·다른 문구를 침범하면 보정하지 않는다. 기존 저장본·캐시·재조회는 바꾸지 않는다. 같은 원본의 로컬 회귀에서는 검사 대상 잔획 542개를 포함했고 사진과 새 제거 영역 밖 픽셀은 그대로였다. 실제 상품에서의 기본 자동 결과와 로컬 원본 재생 검증을 구별한다.

## 견적서 작성 지침

1. 현재 공식 카테고리 양식의 그룹, 항목명, 자료형, 단위, 필수 조건, 허용값을 먼저 읽는다. 표시 여부와 필수 여부는 별개다. 숨김 항목 자동 작성이 꺼져 있어도 공식 필수 항목의 생성·검사를 생략하지 않는다.
2. 사용자 직접 입력, 현재 저장된 상품 사실, 자동 초안, 항목별 기본 표기의 출처를 구분한다. 사용자 입력·공란·삭제를 자동 생성으로 덮어쓰지 않는다. 자동 초안은 관련 원문이나 옵션이 바뀌면 다시 검토한다.
3. `해당사항없음`과 `상세정보참조`는 모든 칸의 공통 대체값이 아니다. 법정 고시의 미해당 여부, 설명 참조가 가능한 항목, 숫자와 필수 선택 항목을 구분한다. 사용자 요청으로 미해당이 확인된 인증서·시험성적서 처리는 실제 인증 보유라는 주장으로 바꾸지 않는다.
4. 필수 값이 없거나 한자·중문, 잘못된 선택값, 유효하지 않은 숫자가 남으면 명확한 오류로 남긴다. `null`이나 참조 문구를 넣고 성공으로 표시하지 않는다. 보호된 사용자 공란도 필수 검사를 면제하지 않는다.
5. NUMBER 항목은 현재 양식과 지원 단위에 맞게 정리한다. 확인되지 않은 수치를 만들거나 단위 표기의 숫자를 임의로 배율 변환하지 않는다. 필수 숫자는 추측값이나 참조 문구로 채우지 않는다.
6. 수량 응답의 추가 구성은 정확한 상품 속성 `구성품`에만 연결한다. 비슷한 이름의 법정 고시 칸에 옮겨 적지 않는다. 수동값이나 이미 채운 값은 보존하고 버린 제안은 알린다.
7. SEO, 가격, 대표·상세이미지, 표시사항을 수정한 뒤 저장값·견적 화면·다운로드·Supplier Hub용 본문을 대조한다. 오래된 자동 초안이 새 수정값을 되돌리지 않아야 한다.

10개 참조의 내부 견적 projection과 실제 저장 native 문서에는 197개 고시 값의 차이가 있었다. 실제 견적 화면은 native 문서와 일치했다. 이 차이를 모든 카테고리의 자동 작성 기본값으로 복제하지 않는다. 오래된 이미지 연결이나 충돌 규격도 작성 규칙으로 일반화하지 않는다.

## 접수 판정

새로 지정한 검증 대상만 전송한다. 기존 상품과 접수 완료 문서는 생성·업로드·수정·재전송하지 않는다. 작업 개시와 등록 전송은 별도 동작이다. 문서번호나 검증 요청번호가 생긴 것만으로 접수 완료를 표시하지 않고, Supplier Hub 최종 상태와 저장된 접수 결과를 함께 확인한다.
