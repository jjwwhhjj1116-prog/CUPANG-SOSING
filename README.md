# SourceFlow

1688 상품을 쿠팡 로켓배송 제안 자료로 준비하는 웹 작업 공간입니다. 기존 사이트·UI·데이터를 보존하며 개발 중입니다. **지정한 실상품의 자동수집부터 Supplier Hub 접수까지 검증한 완성 서비스는 아닙니다.** 이어서 작업할 때 [HANDOFF.md](HANDOFF.md)를 끝까지 읽으세요.

## 운영 접속

[SourceFlow 열기](https://sourceflow.jjwwhhjj1116.workers.dev) — 허용 계정으로 Cloudflare Access 로그인이 필요합니다. 2026-09-24 실제 배포, 로그인 후 작업 화면 및 D1 읽기를 확인했습니다. 배포 성공은 아래 미완성 수집·전송 기능의 완료를 뜻하지 않습니다.

## 구현된 흐름

1. **카테고리 선택 → URL 입력**: 관찰한 쿠플러스 분류를 단계별로 탐색·검색하고 확인된 Supplier Hub 코드와 연결합니다. 카테고리별 XLSX·CSV·TSV 원본과 열 연결을 저장·재사용하며, 확인된 필드명과 일치하는 열은 자동 연결 초안을 만듭니다. URL 최대 50개를 정규화하고 카테고리·기본설정·특징·키워드의 당시 값을 D1에 보관합니다. 같은 활성 요청은 중복 생성하지 않습니다.
2. **상품 작업 7단계**: SEO → 가격 → 대표 이미지 → 추가 이미지 → 상세 이미지 → 한글 표시사항 → 견적서. 이전·다음 이동과 번역·옵션 보조 작업을 제공합니다. 입력 출처와 revision을 기록하고 동시 수정 충돌을 감지하며 탭 이동 중 편집 초안을 보존합니다.
3. **옵션별 가격**: 원문/한국어 옵션명, SKU, CNY 원가, 구성 수량, MOQ, 치수·무게, 이미지, 견적 포함 여부를 저장합니다. 옵션 원가×구성 수량에 상품 가격 정책을 적용합니다. 대표 상품 가격과 옵션 가격은 구분됩니다. 쿠플러스 산식과의 정확한 일치는 미검증입니다.
4. **번역·SEO 실행기**: OpenAI Responses API 구조화 출력으로 원문 기반 한국어 초안을 생성하는 코드가 있습니다. 전송 원문·모델·출력 한도를 검토하고 유료 요청을 승인한 뒤 별도로 실행합니다. 결과를 검토해 선택한 항목에만 적용하며 기존 콘텐츠에 자동 덮어쓰지 않습니다.
5. **원본 이미지 가공 실행기**: 소유 상품의 PNG/JPEG/WebP 1장으로 이미지 문구 번역·대표/상세 이미지 초안을 요청하는 코드가 있습니다. 원본 SHA·프롬프트·모델·크기·품질 승인, 단일 실행, 새 PNG 보관, 편집 경합 시 무료 재첨부를 지원합니다. 번역 정확성이나 법적 적합성의 검증은 별도입니다.
6. **이미지·표시사항 편집**: R2 원본을 보존하면서 대표·추가·상세·사이즈·라벨 역할과 순서를 지정합니다. 역할별 필터와 큰 미리보기를 제공하며, 저장된 치수와 표시사항으로 PNG를 조판해 다운로드하거나 상품에 첨부할 수 있습니다. 미입력 사실은 추정하지 않습니다. 자료를 직접 수정해도 자동 수집·AI 작업·운영 등록 완료로 바뀌지 않습니다.
7. **실제 양식 출력**: 저장한 Excel 원본에서 선택한 시트의 매핑 셀만 채웁니다. 다른 시트·스타일·비대상 셀은 보존하고 수식/병합 영역 충돌은 거절합니다. 견적 미리보기, 필수값 누락 표시, 이미지 파일명과 일치하는 ZIP을 제공합니다. CSV/TSV는 머리글과 매핑 자료로 새 사본을 만듭니다.
8. **작업 이력·중복 방지**: 단계별 상태·근거, 입력 변경에 따른 무효화, SQLite 원자적 갱신, 유료 호출 단일 실행, 결과 불확실 시 자동 재호출 금지를 적용합니다. 선택 상품의 무료 단계를 순차 처리할 수 있습니다.
9. **카테고리별 견적 편집**: 시작·상품·이미지·법적정보·물류 5개 영역에서 저장된 SEO·가격·설정·이미지를 자동 연결합니다. 옵션별 수정 > 상품 공통 수정 > 자동값 순서이며, 수정 해제·빈 값 보존·전체 옵션 적용 미리보기를 제공합니다. 저장된 수정은 CSV/JSON/연결된 Excel과 첨부 ZIP에 반영됩니다. 주방수납/정리 22개 카테고리의 상품 속성·선택 목록과 미리보기 상품고시 이름을 공식 화면에서 대조했습니다. 새 카테고리 속성의 미확인 값은 공란으로 두며, 공급가보다 낮은 판매가는 검토 오류로 표시합니다.
10. **날짜별 상품관리**: 상품과 수집 요청을 오늘·7일·1개월·전체·직접 지정 기간으로 찾고 전체 원본 URL을 확인·복사합니다. KST 날짜와 검색 조건을 유지하며 다음 페이지로 이전 기록을 조회합니다.

완료된 상품 속성 번역을 불러오거나 다른 번역 결과로 바꾸면, 사용자가 서버에 저장한 동일 카테고리의 연결 규칙을 자동 조회해 견적 항목을 선택합니다. 직접 수정한 값과 공란은 보존하며, 변경 전·후를 확인한 후 초안 반영과 견적 저장으로 확정합니다. 포함된 옵션 중 같은 속성을 적용할 대상을 직접 선택하고, 옵션별 변경 전·후 미리보기를 거쳐 일괄 초안으로 반영할 수 있습니다. 제외 옵션과 수동 수정값은 보존하며, 서로 다른 옵션의 재질·크기를 동일하다고 추정하지 않습니다. 이 규칙은 쿠플러스 전체 기본값을 자동 확보한 자료가 아닙니다.

## 아직 실연결 검증이 필요한 부분

- **1688 자동수집 실행기**: 수집 요청은 보관되지만 원문·SKU·가격·이미지를 자동 확보하는 공급원은 연결되지 않았습니다. 현재 번역 입력을 자동수집의 대체 완료로 설명하면 안 됩니다.
- **전체 카테고리와 Excel 규격**: 주방수납/정리 하위 22개 코드·상품 속성을 확인했으며 전체 말단 분류, 이미지·인증·물류 입력 규격은 미확인입니다. 이 PC에서 내려받은 Supplier Hub 공식 Excel 원본의 바이트·열 규격도 미확인입니다. [22개 카테고리 확인 결과](docs/SUPPLIER-HUB-CATEGORY-SCHEMAS-2026-09-23.md)를 참고하세요. 합성 양식 테스트 성공은 공식 접수 호환 증거가 아닙니다.
- **AI 서비스 실제 호출**: 서버 비밀값·이용 가능한 모델 설정과 사용자 유료 승인 후 실제 품질·비용 검증이 필요합니다. 개발 검증은 모의 API만 사용했습니다.
- **Supplier Hub 연결·제안·접수 결과**: 확장·열린 Hub 탭·CLI·서버의 전체 실행 경로는 미확인입니다. `POST /api/supplier-hub`는 여전히 501을 반환하며 전송하지 않습니다.
- 이미지 번역·배경 제거·번역 지침은 작업 목적에 따라 실제 요청에 반영되며, 검토 화면에서 적용 여부를 확인합니다. 설정 변경 시 기존 승인은 다시 검토해야 합니다. 확인된 권리자 문구가 없는 카피라이트, 상하단 이미지 자동 합성, 여러 이미지의 일괄 처리는 남아 있습니다. 박스 입수는 물류 정보이며 판매 묶음 수량에 자동 대입하지 않습니다.

기존 완료 표시를 가진 데이터는 삭제하지 않았습니다. 상태 문자열만으로 업무 완료를 판정하지 마세요. 유료 실행·운영 등록·배포는 구체적 대상과 결과물을 검토하고 사용자 확인을 받은 다음 실행합니다.

## 로컬 실행과 검증

Node >=22.13.0. 기존 lockfile을 보존하세요.

```sh
npm ci
npm run dev
npm test
npx tsc --noEmit --incremental false
npm run lint
npm run build
```

`npm test`는 실제 모듈·SQLite SQL·모의 HTTP·독립 ZIP 파서를 사용하며 유료 API나 운영 DB를 호출하지 않습니다. Node 내장 SQLite의 실험 기능 경고가 출력될 수 있습니다. 최종 실행 결과는 HANDOFF 최신 절에 기록합니다.

로컬 서버의 D1/R2까지 확인하려면 아래 명령을 명시적으로 실행합니다. **이 명령은 `[LOCAL TEST]` 합성 상품/파일을 만들거나 갱신합니다.** 외부 1688 페이지는 방문하지 않으며 실제 상품 수집 검증이 아닙니다.

```sh
node tests/smoke-local.mjs --allow-test-records
node tests/smoke-files.mjs --allow-test-records
```

브라우저에서 위 합성 상품의 사이즈표 PNG를 생성·첨부한 후 `node tests/smoke-documents.mjs`로 R2 파일과 견적 ZIP의 바이트 일치 여부를 확인할 수 있습니다. 옵션 일괄 수정은 선택 → 전후 가격 미리보기 → 적용/취소 → 저장 순서이며 마지막 일괄 변경을 저장 전에 되돌릴 수 있습니다.

검증 결과와 생성 ZIP은 Git에서 제외된 `outputs/`에 저장됩니다. 기존 검증용 offer ID `123456789`와 상품명에 `[LOCAL TEST]`가 붙은 데이터는 실상품으로 취급하지 않습니다.

## 서버 설정

Cloudflare Workers + D1 `DB` + R2 `FILES` 구조입니다. 운영에서는 Cloudflare Access JWT의 서명·issuer·audience·만료를 검증하며 신뢰되지 않은 사용자 헤더나 `local-demo`로 접근하지 않습니다. [Cloudflare 연결 문서](docs/CLOUDFLARE.md)를 참고하세요. 전용 D1과 비공개 R2, Zero Trust Free 팀을 준비했습니다. Access 애플리케이션 정책과 Worker 배포는 아직 완료되지 않았으며 최신 상태는 HANDOFF 16절을 확인하세요.

비밀값은 서버에만 설정합니다. 로컬 Cloudflare는 Git에서 제외된 `.dev.vars`를 사용하고 `.env.example`의 항목을 참고하세요.

| 설정 | 용도 |
| --- | --- |
| `CLOUDFLARE_ACCESS_TEAM_DOMAIN`, `CLOUDFLARE_ACCESS_AUD` | 운영 작업 공간 로그인 검증 |
| `OPENAI_API_KEY` | 서버 측 OpenAI API 비밀 키 |
| `SOURCEFLOW_TEXT_MODEL` | 사용 권한이 있는 Structured Outputs 지원 모델 ID |
| `SOURCEFLOW_TEXT_MAX_OUTPUT_TOKENS` | 256~8000 출력 상한 |
| `SOURCEFLOW_IMAGE_MODEL` | 사용 권한이 있는 Images Edits 지원 모델 ID |

설정만으로 유료 호출이 시작되지는 않습니다. 승인한 작업은 모델·입력·제품 revision에 묶이며 실행 중복을 막습니다. 유료 응답 후 저장 장애가 생기면 결과가 불확실한 상태로 남길 수 있으므로 새 요청을 만들기 전에 이력과 제공자 사용량을 확인해야 합니다.

`.openai/hosting.json`의 기존 project_id `appgprj_6a8d4a6c78908191acecd48b7e0d1620`를 유지합니다. 새 Sites 프로젝트를 만들지 마세요. Vite의 로컬 D1 ID를 운영 리소스로 간주하거나 생성된 wrangler 설정을 그대로 배포하지 마세요. 로컬 자료는 다른 PC나 Cloudflare로 자동 이전되지 않습니다.

`db/migrations/0001_sourceflow_bootstrap.sql`부터 `0006_collection_images.sql`까지 런타임 17개 테이블·10개 명시적 인덱스를 관리합니다. `node scripts/check-db-schema.mjs`는 메모리 SQLite에서 런타임 DDL과 비교하며 실제 DB에 적용하지 않습니다. 기존 Drizzle `db/schema.ts`는 두 테이블만 기술하므로 `db:generate`만으로 전체 스키마를 관리할 수 없습니다.

운영 준비에 남은 항목: Access 앱 정책·AUD 연결, 운영 빌드·배포와 통합 검증, 운영 데이터 이관, 의존성 보안 업데이트. 전용 D1에 세 migration을 적용했고 기존 다른 앱의 DB는 변경하지 않았습니다. 기존 npm audit 결과 17건(critical 1/high 12/moderate 4)은 강제 업데이트하지 않았으며 최신 재평가가 필요합니다.

## 참조 분석의 범위

로그인된 쿠플러스·Supplier Hub 화면과 공식 배포 CLI 1.3.2의 정적 코드를 분석했습니다. 설치 CLI 1.2.12 및 확장 10.83의 실제 동작과 동일하다고 단정하지 않습니다. Supplier Hub를 열어둔 탭/세션/확장 메시지와 최종 접수 결과를 추가로 검증해야 합니다.

지정 실상품 `1073686239310`은 브라우저 도구의 사이트 정책 때문에 열지 못했습니다. 이것은 1688 서버 자체 차단을 관찰한 결과가 아니며, 제작 서비스의 수집 가능성을 판정하는 증거도 아닙니다. 다른 브라우저·CLI·프록시로 우회하지 않았습니다. 독립 서비스에 사용 권한이 있는 수집 경로와 실제 응답이 필요하며, 쿠플러스 비공개 서버를 임의로 공급원으로 사용하지 않습니다.


등록 전송의 선택 상품 검사: 저장된 최종 견적값의 누락·가격 오류·이미지 연결을 확인하고 같은 카테고리의 수정 화면으로 이동합니다. 검사 결과는 운영 접수 성공을 의미하지 않으며 실제 Supplier Hub 전송 연결은 미구현입니다.

### 공통 상세 상단·하단 이미지
기본설정에서 이미지를 업로드하고 사용 스위치를 켠 뒤 설정을 저장합니다. 이후 새로 접수한 수집 요청은 당시 파일 선택을 보관하며, 원문을 상품으로 반영할 때 상단→본문→하단 순서로 연결합니다. 기존 상품과 기존 요청은 변경하지 않습니다. 상품 상세 이미지 단계에서 개별 수정할 수 있습니다. 선택 해제는 원본 파일을 삭제하지 않습니다. 실제 수집 공급원 연결은 별도 미완성 항목입니다.
