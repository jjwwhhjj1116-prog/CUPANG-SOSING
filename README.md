# SourceFlow

1688 상품 URL을 시작점으로 쿠팡 로켓배송 상품 제안에 필요한 가격, SEO, 이미지, 한글표시사항, 상세 작업, 공급 견적서를 한 화면에서 준비하는 자동화 워크스페이스입니다.

## 구현된 흐름

- 1688 URL 단건·다건 대기열 등록
- 환율, 공급 마진, 쿠팡 마진, 최소 마진에 따른 공급가·판매가·MSRP 계산
- AI 작업 단계와 상품별 상태 관리
- 대표·추가 이미지 후보 선택, 배경 제거·번역 작업 상태, 직접 이미지 업로드
- 한글표시사항 작성
- Supplier Hub 제안용 견적서와 PDF 인쇄
- 실제 전송 직전 확인 절차와 Supplier Hub 서버 어댑터
- D1 기반 상품·설정 저장, R2 기반 이미지 저장, 사용자별 데이터 분리

## 로컬 실행

```bash
npm install
npm run dev
```

배포 빌드는 `npm run build`, 데이터베이스 마이그레이션 생성은 `npm run db:generate`를 사용합니다.

## Supplier Hub 연동

실제 전송에는 Supplier Hub가 공식 제공한 HTTP 엔드포인트와 인증 키가 필요합니다. `.env.example`의 두 값을 런타임 비밀값으로 설정하면 `/api/supplier-hub` 어댑터가 전송을 수행합니다. 값이 없을 때는 외부 전송 없이 안전하게 미리보기 모드로 동작합니다.

1688 원본 상품의 상세 데이터 자동 수집은 로그인 세션 또는 공식 수집 커넥터가 필요한 영역입니다. 현재 앱은 URL 등록 이후의 가격·콘텐츠·견적 파이프라인을 완성했으며, 수집기는 별도 커넥터로 교체할 수 있게 분리되어 있습니다.
