# SourceFlow

> **현재 상태: UI 시제품 / 실제 자동화 미완성.** AI 생성·이미지 변환·1688 수집·Supplier Hub 등록은 아직 구현 또는 검증되지 않았습니다. 이전의 전체 파이프라인 완료 설명을 정정합니다. 다른 PC에서 시작할 때는 [업무 인수인계 지시서](HANDOFF.md)를 먼저 읽으세요.

1688 상품 URL을 시작점으로 쿠팡 로켓배송 상품 제안에 필요한 가격, SEO, 이미지, 한글표시사항, 상세 작업, 공급 견적서를 한 화면에서 준비하는 자동화 워크스페이스입니다.

## 현재 코드 구성 (동작 완료 목록이 아님)

- 1688 URL 단건·다건 대기열 등록
- 환율, 공급 마진, 쿠팡 마진, 최소 마진에 따른 공급가·판매가·MSRP 계산
- AI 작업 단계와 상품별 상태 관리
- 대표·추가 이미지 후보 선택, 배경 제거·번역 작업 상태, 직접 이미지 업로드
- 한글표시사항 작성
- Supplier Hub 제안용 견적서와 PDF 인쇄
- 실제 전송 직전 확인 절차와 Supplier Hub 서버 어댑터
- D1 기반 상품·설정 저장, R2 기반 이미지 저장, 사용자별 데이터 분리

## 로컬 실행

```bash
npm install
npm run dev
```

배포 빌드는 `npm run build`, 데이터베이스 마이그레이션 생성은 `npm run db:generate`를 사용합니다.

## Supplier Hub 연동

현재 `/api/supplier-hub`는 검증되지 않은 임시 POST 코드입니다. 공식 API의 존재나 인증·전송 규격을 확인하지 않았으므로 `.env.example`의 값을 채우면 실제 연동이 완성된다고 가정하면 안 됩니다. 사용자는 Supplier Hub 탭과 쿠플러스 확장프로그램이 필요하다고 설명했습니다. 사무실 PC에서 확장과 로그인된 탭의 실제 통신 흐름을 먼저 분석해야 합니다.

현재 1688 상품 수집기는 없으며 원가와 상품 정보를 수동 입력합니다. AI·이미지 버튼은 실제 처리 없이 상태를 완료로 바꾸는 부분이 있습니다. 가격 산식은 원본 대조가 필요하고 견적서는 임의 HTML 양식입니다. 세부 미완료 사항, 관찰 근거와 후속 작업은 HANDOFF.md에 기록했습니다.
